## Rubeus.exe: choose the operation and read the result

Inspect and use the saved Kerberos ticket commands.

### What the result establishes

Identify whether you are inspecting tickets, requesting a ticket, importing one or exercising a delegation path.

### Prerequisites and common failures

A ticket's principal, service, realm, lifetime and logon-session placement matter; possessing a ticket does not grant rights absent from its identity.

Run in: **Windows PowerShell**. Kerberoasting requests tickets; use the authorized lab scope.

## klist: choose the operation and read the result

Inspect tickets available to the current logon session or Kerberos cache.

### What the result establishes

Record principal, realm, service names, ticket times and cache/logon-session identity.

### Prerequisites and common failures

Windows and MIT Kerberos klist are different programs; a ticket visible in one cache is not necessarily used by another client or process.

### Example 1: Windows session

Run in: **Windows cmd.exe or PowerShell**.

```text
klist
```

## Existing notes and worked examples

**Run on:** a Windows lab host, from PowerShell or Command Prompt, in the directory containing `Rubeus.exe`.

```powershell
.\Rubeus.exe
```

Running it without a task displays usage. Choose the task that matches what you already have: credentials, a ticket, or a service account to investigate. There is no separate Rubeus server or graphical interface to start.

## Common problems

- **Executable not found:** check `Get-Location` and `Test-Path .\Rubeus.exe`.
- **Kerberos request fails:** verify domain DNS, time, the account identity, and ticket validity before changing options.
- **Feature differs from the notes:** check the help for the build you have; the full references preserve examples from your saved lessons.
