**Run on:** a Windows lab host, from PowerShell or Command Prompt, in the directory containing `Rubeus.exe`.

```powershell
.\Rubeus.exe
```

Running it without a task displays usage. Choose the task that matches what you already have: credentials, a ticket, or a service account to investigate. There is no separate Rubeus server or graphical interface to start.

## Common problems

- **Executable not found:** check `Get-Location` and `Test-Path .\Rubeus.exe`.
- **Kerberos request fails:** verify domain DNS, time, the account identity, and ticket validity before changing options.
- **Feature differs from the notes:** check the help for the build you have; the full references preserve examples from your saved lessons.
