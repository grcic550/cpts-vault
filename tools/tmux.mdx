## Keep listeners and shells in named tmux windows

```bash
tmux new -s lab
tmux new-window -n listener
tmux new-window -n enumeration
tmux ls
tmux attach -t lab
```

The default prefix is `Ctrl-b`. Follow it with `c` for a new window, a window number to switch, `%` for a vertical split, `"` for a horizontal split, or `d` to detach. Detaching keeps the session's processes alive; killing a window can stop its listener or tunnel.
