## wmiexec.py: choose the operation and read the result

Execute through WMI/DCOM; needs RPC access and permissions, plus SMB for default output.

### What the result establishes

Separate successful WMI execution from successful retrieval of stdout; a blank response can be an output-transport problem.

### Prerequisites and common failures

RPC endpoint negotiation, DCOM permissions and the default SMB output path must work; it is not a full interactive terminal.

### Example 1: Password (prompted)

Run in: **Kali**.

```bash
impacket-wmiexec 'DOMAIN/USER@TARGET_IP'
```

### Example 2: NT hash

Run in: **Kali**.

```bash
impacket-wmiexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP'
```

## atexec.py: choose the operation and read the result

Run one command through Task Scheduler over SMB; requires remote task creation rights.

### What the result establishes

A scheduled-task result proves the chosen task action ran under its actual task identity.

### Prerequisites and common failures

Remote task creation permissions and output retrieval are separate checks; interactive prompts are unsuitable for a one-command task.

### Example 1: Password (prompted)

Run in: **Kali**.

```bash
impacket-atexec 'DOMAIN/USER@TARGET_IP' 'whoami'
```

### Example 2: NT hash

Run in: **Kali**.

```bash
impacket-atexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP' 'whoami'
```

## dcomexec.py: choose the operation and read the result

Execute using a remote COM object; requires DCOM rights, RPC access and a supported object.

### What the result establishes

Check the selected COM object, resulting identity and whether the action returned output.

### Prerequisites and common failures

DCOM/RPC access and an available supported object are prerequisites; behavior differs by host configuration.

### Example 1: Password (prompted)

Run in: **Kali**.

```bash
impacket-dcomexec 'DOMAIN/USER@TARGET_IP' 'whoami'
```

### Example 2: NT hash

Run in: **Kali**.

```bash
impacket-dcomexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP' 'whoami'
```

## Choose a tool

| Tool names | Service / ports | What it does | Required access / main limitation |
| --- | --- | --- | --- |
| `psexec.py` / `impacket-psexec` | SMB, TCP 445 | Uploads and starts a service executable; normally SYSTEM | Service creation and writable share; usually local admin. |
| `smbexec.py` / `impacket-smbexec` | SMB + service-control RPC over named pipes, normally TCP 445 | Executes commands through a service | Service-control rights and output-share access; semi-interactive. |
| `wmiexec.py` / `impacket-wmiexec` | DCOM/WMI, TCP 135 + dynamic RPC; normally TCP 445 for output | Executes through WMI as the supplied account | WMI/DCOM permissions; standard admin setup and output-share access. |
| `atexec.py` / `impacket-atexec` | Task Scheduler RPC over SMB, normally TCP 445 | Runs one command as a scheduled task | Remote task creation and output retrieval rights; not an interactive shell. |
| `dcomexec.py` / `impacket-dcomexec` | DCOM, TCP 135 + dynamic RPC; normally TCP 445 for output | Uses an available COM object for command execution | DCOM permissions, usable COM object and output-share access; version-dependent. |
| `evil-winrm` | WinRM, TCP 5985 / 5986 | PowerShell remoting session | WinRM enabled and endpoint authorization; not necessarily local admin. |
| `xfreerdp3` / `xfreerdp` | RDP, TCP/UDP 3389 | Graphical desktop | Remote logon rights and applicable policy/NLA requirements. |
| `nxc` / `netexec` | Protocol chosen by you | Authentication checks and optional command execution | Protocol-specific permissions; a successful login alone does not prove admin. |

For WMI/DCOM, an open 135 alone does not prove the negotiated RPC endpoint is reachable. Default Impacket output retrieval also uses SMB. These methods leave observable activity; “no service executable” does not mean no artifacts.

## wmiexec.py

```bash
# Password prompt, then a semi-interactive command interface
impacket-wmiexec 'example.local/administrator@192.0.2.10'

# Single command, using an NT hash
impacket-wmiexec -hashes ':NT_HASH' 'example.local/administrator@192.0.2.10' 'whoami'
```

WMI creates the process. Default output is written to a remote share and read back. A command can execute while output retrieval fails; check RPC, SMB and share access separately. [Full WMI notes](/enumeration/windows-remote-management-protocols-cheat-sheet#wmi-windows-management-instrumentation).

## smbexec.py

```bash
impacket-smbexec 'example.local/administrator@192.0.2.10'
impacket-smbexec -hashes ':NT_HASH' 'example.local/administrator@192.0.2.10'
```

Uses the Service Control Manager through SMB named pipes. Its interface is semi-interactive; do not assume persistent shell state. Inspect `help`, use absolute paths and confirm results. Service creation and temporary output can be blocked even if authentication succeeds.

## atexec.py

```bash
impacket-atexec 'example.local/administrator@192.0.2.10' 'whoami'
```

Runs a supplied command through Task Scheduler. It is useful when you need a command result, not a full terminal. Check task authorization and the output retrieval path when it returns an error.

## dcomexec.py

```bash
impacket-dcomexec 'example.local/administrator@192.0.2.10' 'whoami'
```

Depends on DCOM permissions and an appropriate remote COM object. An unavailable object or DCOM policy can prevent it from working on a particular Windows version; do not treat it as a universal fallback.

## NetExec command execution

```bash
# One target and one known credential; replace PASSWORD
nxc smb 192.0.2.10 -d example.local -u administrator -p 'PASSWORD' -x 'whoami'
```

NetExec has multiple execution methods. Inspect your installed version's `nxc smb -h` and the official guide before forcing `--exec-method`; firewall and endpoint policies can affect each method differently. [NetExec quick reference](/tools/netexec).

## Failures to separate

1. **Reachability:** route and every required protocol/port, including RPC dynamic endpoints.
2. **Authentication:** account domain, password/hash/ticket and account status.
3. **Authorization:** remote login, share, service, WMI/DCOM or scheduled-task rights.
4. **Execution/output:** the process may run but output retrieval or cleanup may fail.

Record the exact error and which stage failed. [AD troubleshooting](/active-directory/troubleshooting).
