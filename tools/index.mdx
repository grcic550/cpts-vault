An open port identifies a possible service, not a permission level. Confirm the service, account and authorization before choosing an execution method.

## SMB

**TCP 445; legacy NetBIOS TCP 139** · Start by listing accessible shares. Remote execution needs additional administrative rights.

[Full service notes](/enumeration/smb-enumeration-server-message-block)

| Tool and reference | Use it for | First command or next step |
| --- | --- | --- |
| [smbclient](/commands/smbclient) | List shares; password prompt | `smbclient -L //192.0.2.10 -U example.local/student` |
| [smbmap](/commands/smbmap) | Inspect share permissions | `smbmap -h` |
| [nxc / netexec / CrackMapExec](/commands/netexec) | SMB authentication, shares and authorized execution | `nxc smb -h` |
| [psexec.py / impacket-psexec](/commands/psexec) | Remote shell using a service; normally local admin | `impacket-psexec 'example.local/administrator@192.0.2.10'` |
| [smbexec.py / impacket-smbexec](/commands/smbexec) | Service-based command interface | `impacket-smbexec 'example.local/administrator@192.0.2.10'` |
| [atexec.py / impacket-atexec](/commands/atexec) | One command through Task Scheduler | `impacket-atexec 'example.local/administrator@192.0.2.10' 'whoami'` |
| [impacket-smbclient / smbclient.py](/commands/smbclient) | Impacket SMB client and authentication options | `impacket-smbclient -h` |
| [rpcclient / enum4linux-ng](/commands/rpcclient) | Domain and server enumeration over SMB/RPC | `rpcclient -U example.local/student 192.0.2.10` |

## How this directory is organized

The lookup order is service → task → command → prerequisite or failure. Original module notes remain linked. Public CPTS pass reviews informed the structure, while tool syntax was checked against project documentation.

- [viv4ldi: organize notes around the situation and keep tools findable](https://yusufsaka007.github.io/certs/htb-cpts-review/)
- [Ballpoint: keep tool/version fixes alongside module notes](https://ballpoint.fr/en/blog/lessons-learned-first-certification-cpts-hackthebox)
- [Radiant Sec: explain what commands and arguments do](https://radiantsec.io/blog/htb-cpts-review/)
- [zagnox public CPTS notes: service sections as a browsing pattern](https://github.com/zagnox/CPTS-cheatsheet)

These are personal study experiences, not official exam instructions or a claim that a particular tool is required. Reviewed 2026-09-19.
