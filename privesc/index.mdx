## 🧭 Decision tree (what to try first)

### Linux
1. `sudo -l` → if NOPASSWD → GTFOBins lookup
2. `find / -perm -4000 -type f 2>/dev/null` → SUID binary list → GTFOBins lookup
3. `getcap -r /` → capability abuse (`cap_setuid`, `cap_dac_read_search`, etc.)
4. `cat /etc/crontab` + `ls -la /etc/cron.*` → writable script in cron → inject reverse shell
5. `uname -a` → kernel exploit (DirtyPipe, DirtyCow) — last resort, only if above fails

### Windows
1. `whoami /priv` → `SeImpersonatePrivilege` / `SeAssignPrimaryTokenPrivilege` → JuicyPotato / PrintSpoofer / GodPotato
2. `whoami /groups` → `BUILTIN\Administrators` (UAC) → bypass UAC; `DnsAdmins` → DLL injection; `Backup Operators` → SAM dump
3. `net user` & recent edits in `C:\Users\*\AppData` → credential hunting (unattend.xml, PowerShell history, browser data)
4. Service permission check (winPEAS "[+] Interesting Services" section) → service hijack
5. Unquoted service paths (`wmic service get name,pathname,startmode`) → binary planting
6. Kernel exploit via Windows-Exploit-Suggester / WES-NG — last resort
