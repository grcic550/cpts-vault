# Archive

These are preserved materials, not the active study workspace.

- **Original Vault 2026-09-07.tar.gz** — original note/site files before organization. Dependency folders and build output are excluded; the preserved legacy project still contains them.
- **original-files.json** — SHA-256 checksums for every file in that backup.
- **moved-files.json** — old-to-new path lookup.
- **Mintlify Snapshot/** — the former `docs` directory, including its repository history. Edit `../cpts-vault-site/` for current site changes.
- **Legacy Web Vault/** — the old `cpts-next` visual project, career-guide pages, and supporting assets. Its missing HTML entry points predate this organization.
- **Empty Captures/** — empty placeholder notes and test files, preserved for reference.

Extract the backup into a separate folder if you need an old version, then copy only the file you want. Do not extract over the current vault.
