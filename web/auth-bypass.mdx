Weak auth logic, defaults, and injection all get you in.

```text
- Default creds: admin:admin, admin:password, tomcat:tomcat, root:root
- SQLi login bypass:  ' OR '1'='1'-- -   as username
- Response/param tamper: role=user -> role=admin, forced browsing to /admin
- JWT: alg=none, weak HMAC secret (crack with hashcat -m 16500), kid path traversal
- IDOR: change the id in the request to access other users' objects
```
