Use one folder per lab or engagement. Keep observations and supporting evidence together.

```text
engagement-name/
  scope.md
  notes/
    hosts/
    attack-path.md
    questions.md
  scans/
  evidence/
    screenshots/
    command-output/
  loot/
  tools/
  report/
  cleanup.md
```

Record the target, user context, time, command, and output filename when capturing evidence. Link evidence from the host note; record changes to reverse in `cleanup.md`.

Use the [box note template](/templates/box-note) and [report template](/templates/pentest-report).
