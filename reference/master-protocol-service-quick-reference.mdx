## File Transfer Protocols

<Info>
**"I need to move files to/from a target"**

**→ Deep dive:** [File Transfers Cheat Sheet](/post-exploitation/file-transfers-cheat-sheet)
</Info>

| Protocol | Port | What It Does | Key Command |
|----------|------|-------------|-------------|
| **FTP** | 21 | Plaintext file transfer | `ftp <IP>` |
| **FTPS** | 990 | FTP over TLS | `openssl s_client -connect <IP>:21 -starttls ftp` |
| **SFTP** | 22 | File transfer over SSH | `sftp <user>@<IP>` |
| **SCP** | 22 | Secure copy over SSH | `scp file.txt <user>@<IP>:/path/` |
| **SMB** | 445 | Windows file sharing | `smbclient //<IP>/share` |
| **NFS** | 2049 | Unix/Linux file sharing | `mount -t nfs <IP>:/ ./target/` |
| **TFTP** | 69 | Trivial file transfer (no auth) | `tftp <IP>` |
| **HTTP/S** | 80/443 | Web-based file download/upload | `wget` / `curl` |

### Quick Decision

```
Windows target → SMB (445)
Linux target   → SCP/SFTP (22) or NFS (2049)
No auth needed → FTP anonymous or TFTP
Web server     → wget / curl
```

## Remote Access Protocols

<Info>
**"I need a shell or desktop on the target"**

**→ Deep dive:** [Linux Remote Management Protocols Cheat Sheet](/enumeration/linux-remote-management-protocols-cheat-sheet) · [Windows Remote Management Protocols Cheat Sheet](/enumeration/windows-remote-management-protocols-cheat-sheet)
</Info>

### Linux Remote Access

| Protocol/Tool | Port | Type | Command |
|--------------|------|------|---------|
| **SSH** | 22 | Encrypted shell | `ssh <user>@<IP>` |
| **SSH (key-based)** | 22 | Key auth | `ssh -i private.key <user>@<IP>` |
| **Telnet** | 23 | Plaintext shell (insecure) | `telnet <IP>` |

### Windows Remote Access

| Protocol/Tool | Port | Type | Command |
|--------------|------|------|---------|
| **RDP** | 3389 | GUI desktop | `xfreerdp /u:<user> /p:<pass> /v:<IP>` |
| **WinRM** | 5985/5986 | PowerShell remoting | `evil-winrm -i <IP> -u <user> -p <pass>` |
| **WMI** | 135 | Command execution | `wmiexec.py <user>:<pass>@<IP> "cmd"` |
| **PsExec** | 445 | Remote exec via SMB | `psexec.py <user>:<pass>@<IP>` |

### Quick Decision

```
Linux shell    → SSH (22)
Windows shell  → Evil-WinRM (5985) or PsExec (445)
Windows GUI    → RDP (3389)
Windows cmd    → WMI (135)
```

## Email Protocols

<Info>
**"I need to enumerate or interact with mail"**

</Info>

| Protocol | Port (Plain) | Port (Encrypted) | Direction | What It Does |
|----------|-------------|-------------------|-----------|-------------|
| **SMTP** | 25 | 465/587 | Sending | Send/relay emails | 
| **POP3** | 110 | 995 | Receiving | Download emails (removes from server) |
| **IMAP** | 143 | 993 | Receiving | Access emails (stays on server) |

### Signature moves & deep dive

> **→ Full enumeration:** [SMTP Enumeration (Simple Mail Transfer Protocol)](/enumeration/smtp-enumeration-simple-mail-transfer-protocol) (sending / user enum) · [Email Enumeration & Manipulation (POP3 - IMAP)](/enumeration/email-enumeration-manipulation-pop3-imap) (reading mail).

- **SMTP user enum:** `telnet <IP> 25` then `VRFY <user>` / `EXPN <list>`
- **Read mail over TLS:** `openssl s_client -connect <IP>:993` (IMAP) or `:995` (POP3); or `curl -k 'imaps://<IP>' --user <user>:<pass>`

### Quick Decision

```
Enumerate users → SMTP (25) VRFY/EXPN
Read emails     → IMAP (143/993) or POP3 (110/995)
Send email      → SMTP (25/587)
```

## DNS

<Info>
**"I need to find domains, subdomains, or resolve names"**

</Info>

| Record | Purpose |
|--------|---------|
| **A** | Domain → IPv4 |
| **AAAA** | Domain → IPv6 |
| **MX** | Mail servers |
| **NS** | Nameservers |
| **TXT** | SPF, DKIM, misc info |
| **CNAME** | Alias to another domain |
| **PTR** | IP → Domain (reverse lookup) |
| **SOA** | Zone authority info |

**Port:** UDP/TCP 53

### Signature moves & deep dive

> **→ Full enumeration:** [DNS Enumeration (Domain Name System)](/enumeration/dns-enumeration-domain-name-system) (records, AXFR/IXFR mechanics, AD `SRV` records) · [DNS & Web Recon Cheat Sheet](/recon/dns-web-recon-cheat-sheet) (subdomains, vhosts, CT logs).

- **Dump records:** `dig any <domain> @<nameserver>`
- **Zone transfer (jackpot):** `dig axfr <domain> @<nameserver>`
- **Reverse lookup:** `dig -x <IP>` · **Subdomain brute:** `dnsenum --dnsserver <ns> --enum -f wordlist.txt <domain>`

## Network Monitoring & Management

<Info>
**"I found SNMP or IPMI on a target"**

</Info>

| Protocol | Port | What It Does | Why It Matters |
|----------|------|-------------|----------------|
| **SNMP** | UDP 161 | Monitor/manage network devices | Often misconfigured — leaks system info, running processes, interfaces |
| **IPMI** | UDP 623 | Remote hardware management | Can dump password hashes |

### Signature moves & deep dive

> **→ Full enumeration:** [SNMP Enumeration (Simple Network Management Protocol)](/enumeration/snmp-enumeration-simple-network-management-protocol) · [IPMI (Intelligent Platform Management Interface) Penetration Testing Cheat Sheet](/enumeration/ipmi-intelligent-platform-management-interface-penetration-testing-cheat-sheet)

- **SNMP — try default community:** `snmpwalk -v2c -c public <IP>`
- **SNMP — brute community strings:** `onesixtyone -c community-strings.list <IP>` · **brute OIDs:** `braa public@<IP>:.1.*`
- **IPMI — dump password hashes:** Metasploit `auxiliary/scanner/ipmi/ipmi_dumphashes` (version: `ipmi_version`)

## Mental Model — "What Do I Use When?"

<Tip>
**Think by situation, not by protocol name**

</Tip>

```
"I found an open port"
├── Is it a file share?    → SMB (445), NFS (2049), FTP (21)
├── Is it remote access?   → SSH (22), RDP (3389), WinRM (5985)
├── Is it a web server?    → HTTP (80/443) → fingerprint → fuzz
├── Is it email?           → SMTP (25), IMAP (143), POP3 (110)
├── Is it a database?      → MySQL (3306), MSSQL (1433), Oracle (1521)
├── Is it monitoring?      → SNMP (161), IPMI (623)
└── Not sure?              → nmap -sV -sC <IP> -p <port>

"I need to get files off the target"
├── Linux → scp/sftp (22)
├── Windows → SMB (445) or evil-winrm download
├── Web → wget/curl
└── Simple → python3 -m http.server (on target)

"I need to get files onto the target"
├── Linux → scp/sftp (22) or wget from attacker
├── Windows → SMB, certutil, PowerShell wget
├── Web upload → if upload form exists
└── Simple → python3 -m http.server (on attacker)

"I need a shell"
├── Linux → SSH (22)
├── Windows → Evil-WinRM (5985), PsExec (445), RDP (3389)
└── Either → reverse shell via exploit
```
