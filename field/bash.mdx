## find: choose the operation and read the result

Search Linux paths by name, type or permissions.

### What the result establishes

Narrow by directory, type, owner or permission and inspect the returned path before acting on it.

### Prerequisites and common failures

Traversal permissions, mounted filesystems and filename whitespace affect results; -exec actions can modify every match if used carelessly.

Run in: **Linux target**.

```bash

find / -perm -4000 -type f 2>/dev/null
find . -type f -mmin -10
```

## Kali / Linux

```bash
lab_target='MS01.example.test'
printf '%s\n' "$lab_target"
while IFS= read -r host; do
  printf 'Host: %s\n' "$host"
done < hosts.txt
```

| Pattern | Use / pitfall |
| --- | --- |
| "$name" | Expand one value without word splitting or wildcard expansion. |
| 'literal' | Keep dollar signs and most shell syntax literal. |
| command > file | Replaces the output file; use a distinct derived-output path. |
| command >> file | Appends; can duplicate evidence if repeated. |
| left \| right | Sends stdout onward; an earlier failure can be hidden without pipefail. |
| command 2> errors.txt | Keeps stderr separate from the ordinary output. |
