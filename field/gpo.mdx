## Windows — GroupPolicy module

```powershell
Import-Module GroupPolicy
Get-GPO -All | Select-Object DisplayName,Id,GpoStatus
Get-GPPermission -Name 'GPO_NAME' -All
Get-GPOReport -Name 'GPO_NAME' -ReportType Html -Path .\gpo-report.html
```

For the local machine's applied policies:

```cmd
gpresult /r /scope computer
```

Run the computer-scope check elevated. Use the report to inspect links, filters, and settings; an ACL entry alone does not prove that a host will process the policy.

## Prerequisites often missed

- Editing the AD policy object and editing policy files in SYSVOL are different checks.
- Creating a policy does not grant permission to link it to an OU.
- A linked policy can be filtered, disabled, or superseded; user and computer settings have different scope.
- Refreshing policy is distinct from establishing a new user logon.
