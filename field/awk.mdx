## awk: choose the operation and read the result

Extract fields or filter lines in text output.

### What the result establishes

Choose the actual field separator and inspect sample records before applying a field-based extraction.

### Prerequisites and common failures

Whitespace splitting, CSV quoting and missing fields are not interchangeable; shell quoting can change the awk program before it runs.

### Example 1: First whitespace-separated field

Run in: **Kali**.

```bash
awk '{print $1}' INPUT.txt
```

### Example 2: Colon-delimited first field

Run in: **Kali**.

```bash
awk -F: '{print $1}' INPUT.txt
```

### Example 3: Unique nonempty lines

Run in: **Kali**. Write to a separate output file so you retain the original evidence.

```bash
awk 'NF && !seen[$0]++' INPUT.txt > UNIQUE.txt
```

## Kali / Linux

```bash
awk '{print $1}' INPUT.txt
awk -F: '{print $1}' PASSWD_FILE
awk 'NF && !seen[$0]++' INPUT.txt > UNIQUE.txt
awk 'tolower($0) ~ /error/ {print NR ":" $0}' LOG.txt
```

| Detail | Meaning |
| --- | --- |
| $1 / $2 | First / second field; whitespace is the default separator. |
| -F: | Use a colon delimiter, such as a passwd-format file. |
| NR | Current input line number. |
| Single quotes | Keep the shell from expanding awk's dollar expressions. |

Keep derived username lists and extracted values in separate files. Confirm the delimiter and inspect sample output before feeding a list to another tool.
