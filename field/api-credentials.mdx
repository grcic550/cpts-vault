## Read an identity endpoint in the lab

```bash
read -rs LAB_TOKEN
curl --fail-with-body -H "Authorization: Bearer $LAB_TOKEN" 'https://LAB_API_HOST/api/me'
unset LAB_TOKEN
```

The endpoint and authentication scheme must match that API's documentation; `/api/me` is an example, not a universal route. Do not send a discovered key to a third-party “validator”.

## Interpret the result

| Result | Check |
| --- | --- |
| 200 | Which identity and endpoint succeeded? This does not prove broad permission. |
| 401 | Token validity, authentication scheme, expiry, and target environment. |
| 403 | Scope, policy, resource access, and endpoint restrictions; it is not conclusive proof of a valid token. |
| 404 | URL/version/resource and whether the service deliberately hides unauthorized resources. |

Record a redacted credential identifier and the minimum evidence needed for scope. Provider-specific instructions are in the linked reference; only test destinations inside the assessment scope.
