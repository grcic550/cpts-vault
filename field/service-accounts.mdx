## Follow identity, membership and resource permission

A username becomes useful when you know what its groups and object rights allow it to access. Record stable identifiers and distinguished names, then trace the relationship to a specific host, share, service or directory object. Group names are hints; effective permissions are evidence.

### Query the identity and its groups

```powershell
Get-ADUser USERNAME -Properties MemberOf,Description,ServicePrincipalName,PasswordLastSet
Get-ADPrincipalGroupMembership USERNAME | Select-Object Name,GroupScope,GroupCategory
Get-ADGroup GROUP_NAME -Properties Members,MemberOf,Description
Get-ADGroupMember GROUP_NAME -Recursive
```

Recursive membership answers a different question from a group's direct members. Retain direct relationships when explaining a path. Compare directory state with the running process token:

```powershell
whoami /user
whoami /groups
```

A newly added membership may need a fresh authentication context. Built-in local groups on a workstation/server are also distinct from domain groups with similar names.

### Inspect service accounts as accounts with a purpose

```powershell
Get-ADUser -Filter {ServicePrincipalName -like '*'} -Properties ServicePrincipalName,Description,MemberOf,PasswordLastSet
Get-ADServiceAccount -Filter * -Properties PrincipalsAllowedToRetrieveManagedPassword,ServicePrincipalNames
```

A service account may be a normal user, a computer account or a managed account. Its SPNs, retrieval permissions, group memberships and object ACLs determine which next checks make sense. Do not treat readable gMSA metadata as permission to retrieve its managed password.

### Connect policy to actual scope

```powershell
Get-GPO -All | Select-Object DisplayName,Id,GpoStatus
Get-GPInheritance -Target 'OU=Workstations,DC=example,DC=local'
Get-GPOReport -Name 'POLICY_NAME' -ReportType Html -Path .\policy-report.html
```

The GroupPolicy module is required. Substitute the real OU distinguished name. Check links, enforced/block-inheritance behavior, security filtering, WMI filtering and the setting itself. Read access to a GPO is not permission to modify it, and modification is not proof that a selected host applies it.

### Validate the destination

For a membership that grants access to a file share, verify the share. For a host-admin relationship, inspect the host's relevant local group and test the intended management protocol. For an ACL edge, resolve the exact right and object type before selecting a change.

```bash
nxc smb TARGET_IP -d DOMAIN_FQDN -u USERNAME -p 'PASSWORD' --shares
smbclient //TARGET_FQDN/KNOWN_SHARE -U 'DOMAIN_FQDN/USERNAME'
```

Preserve the identity, membership chain, target permission and observed result together. If a graph path fails, test each edge in order; stale collection data or an absent network path can explain the failure without invalidating every relationship.

## Windows — AD module

```powershell
Get-ADServiceAccount -Filter * -Properties PrincipalsAllowedToRetrieveManagedPassword,ServicePrincipalNames |
  Select-Object Name,PrincipalsAllowedToRetrieveManagedPassword,ServicePrincipalNames
Get-ADUser -LDAPFilter '(servicePrincipalName=*)' -Properties ServicePrincipalName |
  Select-Object SamAccountName,ServicePrincipalName
```

## Choose the right branch

| Result | Interpretation / next step |
| --- | --- |
| Ordinary user with an SPN | See the existing Kerberoasting notes. Cracking feasibility depends on password strength and encryption type. |
| Managed service account | Managed passwords are designed to be long and rotated; do not equate an SPN with an easily crackable password. |
| gMSA retrieval principals | Resolve the permitted principals and effective group membership before expecting access to msDS-ManagedPassword. |
| Service runs as an account | Inspect local service configuration and that account's actual rights; the name alone does not imply admin. |

A readable gMSA object does not imply that its managed-password attribute is readable. An empty result can be an ACL or connectivity issue rather than a missing account.
