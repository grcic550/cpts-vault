## Current operation: Count repeated adjacent lines after sorting

**Run in:** Kali. **Requires:** One observation per line; sorting groups equal values before uniq counts them.

```bash
LC_ALL=C sort observations.txt | uniq -c | sort -nr
```

**Read the result:** Use counts or unique lines after arranging duplicates together when the task requires it.

**If Counts differ because strings vary by case or hidden characters:** uniq collapses adjacent duplicates; it does not remove every repeated line from an unsorted file.
