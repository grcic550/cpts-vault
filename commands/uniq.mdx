## 4. Reading & filtering output (the pentest workhorses)

**Notebook example**

```bash
cmd | grep foo                 # keep lines matching foo
cmd | grep -v foo              # drop lines matching foo
cmd | grep -E "80|443"         # match 80 OR 443 (regex)
cmd | awk '{print $1}'         # print 1st column
cmd | cut -d: -f1 /etc/passwd  # split on ":" take field 1
cmd | sort | uniq -c | sort -rn  # count & rank unique lines
cmd | wc -l                    # count lines
cmd | tee out.txt              # show on screen AND save to file
cmd > out.txt                  # save (overwrite)
cmd >> out.txt                 # append
cmd 2>/dev/null                # discard errors
cmd &>/dev/null                # discard everything
```
