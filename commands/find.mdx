## Locate SUID files on the current root filesystem

**Run in:** Linux target. **Requires:** Read/traverse access to the filesystem; -xdev deliberately omits other mounted filesystems and hidden errors limit coverage.

```bash
find / -xdev -type f -perm -4000 -print 2>/dev/null
```

**What the result establishes:** Narrow by directory, type, owner or permission and inspect the returned path before acting on it.

**Next check:** Inspect owner, mount options, binary version and how that program handles privileges; enumerate relevant other mounts separately.

## Commands

**Linux target**

```bash
find / -name "*.conf" 2>/dev/null
find / -perm -4000 -type f 2>/dev/null
find . -type f -mmin -10
```

## If it fails

| Symptom | Check |
| --- | --- |
| A SUID file is present but does not yield elevated behavior | Traversal permissions, mounted filesystems and filename whitespace affect results; -exec actions can modify every match if used carelessly. |
