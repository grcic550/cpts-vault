## Inspect environment variables in the current process context

**Run in:** Linux target. **Requires:** A shell in the context whose environment matters; the second command checks a specific Kerberos cache variable.

```bash
env
printenv KRB5CCNAME
```

**What the result establishes:** Inspect variables that influence the current process, including paths, proxies and application settings.

**Next check:** Check how the process was launched and verify the referenced file; an environment value is not proof the consuming program is using it.

## Identify Current ccache

**Notebook example**

```bash
env | grep KRB5
```

## If it fails

| Symptom | Check |
| --- | --- |

### Identifying Your Shell

**Shells, Payloads, and Interactive TTYs**

```bash
# Linux — check running processes
ps
#   PID TTY      TIME CMD
#  4232 pts/1    00:00:00 bash     ← this tells you it's bash

# Linux — check SHELL environment variable
env | grep SHELL
# SHELL=/bin/bash

# PowerShell — version check (works on both Windows and Linux)
$PSVersionTable
# If this returns version info → you're in PowerShell
# If it errors → you're in cmd.exe or bash
```
