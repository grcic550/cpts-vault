## Take ownership of one controlled lab file

**Run in:** Elevated Windows cmd.exe. **Requires:** A disposable lab file, the required ownership privilege and a record of its original owner and ACL.

```console
takeown /f "C:\Lab\owned-test.txt"
```

**What the result establishes:** Record the original owner and inspect how ownership changes affect the subsequent permission operation.

**Next check:** Inspect and deliberately adjust only the required DACL right if justified; ownership alone does not grant data access. Restore the recorded owner/ACL after the exercise.

## D. SeTakeOwnership

**Notebook example**

```cmd
takeown /f C:\path\to\protected.file
icacls C:\path\to\protected.file /grant %username%:F
```

## If it fails

| Symptom | Check |
| --- | --- |
| Ownership changes but reading or writing is still denied | Ownership is not identical to full file access, and taking ownership does not by itself rewrite every deny or access entry. |
