## Current operation: Inspect established dnscat2 sessions

**Run in:** Inside the dnscat2 server console. **Requires:** A running dnscat2 server and a client session whose numeric ID is taken from windows output; DNS routing/delegation must already be configured.

```bash
windows
window -i SESSION_ID
```

**Read the result:** Verify the DNS query path and established session, then check the specific forwarded service separately.

**If The client appears but a command or forwarding session fails:** A working DNS resolution path is not necessarily a reliable tunnel; domain delegation, polling, MTU and resolver behavior affect performance.

**Next check:** Check the selected window type and DNS path, then use that command window's supported operations; a DNS exchange alone is not a working tunnel.
