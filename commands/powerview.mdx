## Read one domain user's directory relationships

**Run in:** Windows PowerShell. **Requires:** The intended PowerView implementation loaded in a domain-authenticated session with directory connectivity.

```powershell
Import-Module .\PowerView.ps1
Get-DomainUser -Identity USER
```

**What the result establishes:** Read object identities, distinguished names, memberships and resolved ACL rights as separate relationships.

**Next check:** Confirm the module generation and exact object DN; request memberships or ACLs separately to test a specific relationship.

## Commands

**Windows PowerShell**

```powershell
Import-Module .\PowerView.ps1
Get-DomainUser -Identity USER
Get-DomainComputer
Get-DomainGroupMember -Identity "Domain Admins"
```
