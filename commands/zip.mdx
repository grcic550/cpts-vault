## Package collection files from a dedicated directory

**Run in:** Kali, in the collection directory. **Requires:** A directory containing only the intended artifacts and a writable parent directory; output is placed outside the input tree.

```bash
zip -r ../collection.zip .
```

**What the result establishes:** Confirm which files entered the archive and inspect the resulting member names.

**Next check:** List the archive and compare the collection manifest before import; retain timestamps and collection scope with the package.
