## Record Windows addresses and DNS settings

**Run in:** Windows cmd.exe. **Requires:** A Windows shell on the host whose connectivity you are investigating.

```console
ipconfig /all
```

**What the result establishes:** Map interface addresses, gateways, DNS servers and domain suffixes to the host's network position.

**Next check:** Identify the active adapter and gateway; test resolution against its configured DNS server.

## If it fails

| Symptom | Check |
| --- | --- |
| An adapter is disconnected or has an unexpected DNS suffix | A disconnected adapter or stale DNS suffix can mislead you; record which adapter carries the route to the target. |
