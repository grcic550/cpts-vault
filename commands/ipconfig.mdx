## ipconfig: choose the operation and read the result

Show Windows interface and DNS settings.

### What the result establishes

Map interface addresses, gateways, DNS servers and domain suffixes to the host's network position.

### Prerequisites and common failures

A disconnected adapter or stale DNS suffix can mislead you; record which adapter carries the route to the target.

### Example 1: Commands

Run in: **Windows cmd.exe**.

```bash
ipconfig /all
```
