## Inspect one file's owner and access entries

**Run in:** Windows PowerShell. **Requires:** A real file or directory path and permission to read its security descriptor.

```powershell
Get-Acl -LiteralPath 'C:\APP\service.exe' | Format-List Owner,AccessToString
```

**What the result establishes:** Resolve principals and inspect inheritance, allow/deny entries and the exact rights on the selected object.

**Next check:** Resolve the current token, deny entries and inheritance; AD object ACLs require the AD provider and a directory object path instead.

## If it fails

| Symptom | Check |
| --- | --- |
| An inherited ACE appears useful but access is still denied | A readable ACL is not a writable ACL; filesystem, registry and directory object permissions have different semantics. |
