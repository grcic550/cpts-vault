## Get-Acl: choose the operation and read the result

Commands and examples collected from your Get-Acl notes.

### What the result establishes

Resolve principals and inspect inheritance, allow/deny entries and the exact rights on the selected object.

### Prerequisites and common failures

A readable ACL is not a writable ACL; filesystem, registry and directory object permissions have different semantics.

### Example 1: A Useful foreach Loop

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```powershell
PS C:\htb> foreach($line in [System.IO.File]::ReadLines("C:\Users\htb-student\Desktop\ad_users.txt")) {get-acl  "AD:\$(Get-ADUser $line)" | Select-Object Path -ExpandProperty Access | Where-Object {$_.IdentityReference -match 'INLANEFREIGHT\\wley'}}
```
