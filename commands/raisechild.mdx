## Current operation: Exercise a privileged child-to-parent trust workflow

**Run in:** Kali. **Requires:** An explicitly controlled child-domain administrative lab context and the relevant parent trust; the workflow performs privileged credential/ticket operations.

```bash
impacket-raiseChild 'CHILD_FQDN/CHILD_ADMIN'
```

**Read the result:** Read the starting credentials, source domain and intended trust transition before interpreting any resulting ticket or credential artifact.

**If The trust transition fails despite child-domain access:** This is a privileged child-domain escalation workflow with strong prerequisites, not a way for any child-domain user to become a parent administrator.

**Next check:** Verify the actual trust direction, domain identifiers, key material and required rights; ordinary child-domain membership is not sufficient.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
