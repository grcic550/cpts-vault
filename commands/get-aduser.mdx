## Current operation: Inspect a user's non-default directory attributes

**Run in:** Windows PowerShell. **Requires:** The ActiveDirectory module and a DC/authentication context that can read the account.

```powershell
Import-Module ActiveDirectory
Get-ADUser -Identity USER -Properties MemberOf,ServicePrincipalName,Enabled
```

**Read the result:** Request the attributes relevant to the hypothesis and retain the account's SID/distinguished name with its readable name.

**If A property is absent from a default query:** Default properties are limited; an omitted property is not proof it is unset, and directory state can differ from an existing logon token.

**Next check:** Request it explicitly and retain the account SID/DN; compare memberships with the current token before inferring access.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
