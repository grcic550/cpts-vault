## Inspect a user's non-default directory attributes

**Run in:** Windows PowerShell. **Requires:** The ActiveDirectory module and a DC/authentication context that can read the account.

```powershell
Import-Module ActiveDirectory
Get-ADUser -Identity USER -Properties MemberOf,ServicePrincipalName,Enabled
```

**What the result establishes:** Request the attributes relevant to the hypothesis and retain the account's SID/distinguished name with its readable name.

**Next check:** Request it explicitly and retain the account SID/DN; compare memberships with the current token before inferring access.

## Commands

**Windows PowerShell**

```powershell
Import-Module ActiveDirectory
Get-ADUser -Filter * | Select-Object SamAccountName
Get-ADUser -Identity USER -Properties *
```

## If it fails

| Symptom | Check |
| --- | --- |
| A property is absent from a default query | Default properties are limited; an omitted property is not proof it is unset, and directory state can differ from an existing logon token. |
