## Verbose task list

**Windows — cmd.exe**

```cmd
schtasks /query /fo LIST /v
```

Inspect Task To Run and Run As User; labels depend on the OS language.

## Inspect one task

**Windows — cmd.exe**

```cmd
schtasks /query /tn "\TASK_NAME" /xml
```

Task permissions may restrict what you can inspect.

**Windows Post-Exploitation: Field Reference**

