## mount: choose the operation and read the result

Mount or unmount a permitted NFS export.

### What the result establishes

Confirm the remote export, local mountpoint, selected filesystem and actual mounted options before reading data.

### Prerequisites and common failures

Use read-only inspection where appropriate; client restrictions, UID/GID mapping, root squashing and protocol versions affect access.

### Example 1: Commands

Run in: **Kali**.

```bash
mkdir -p /tmp/nfs
sudo mount -t nfs TARGET_IP:/EXPORT /tmp/nfs -o nolock
ls -la /tmp/nfs
sudo umount /tmp/nfs
```

### Example 2: 3. Clean up

Run in: **Saved lab example**.


### NFS (Port 2049)

**Footprinting: Service-by-Service Lab Workflow**

```bash
# List available shares
showmount -e <IP>

# Mount a share
mkdir /tmp/target-NFS
sudo mount -t nfs <IP>:/<share> /tmp/target-NFS

# Browse (use sudo — NFS permissions may block normal user)
sudo ls -la /tmp/target-NFS/<folder>
sudo cat /tmp/target-NFS/<folder>/file.txt

# Unmount when done (important — stale mounts freeze your terminal)
sudo umount -f /tmp/target-NFS
sudo umount -l /tmp/target-NFS   # if -f doesn't work
```
