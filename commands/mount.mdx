<Accordion title="NFS (Port 2049)">

### NFS (Port 2049)

**Footprinting: Service-by-Service Lab Workflow**

```bash
# List available shares
showmount -e <IP>

# Mount a share
mkdir /tmp/target-NFS
sudo mount -t nfs <IP>:/<share> /tmp/target-NFS

# Browse (use sudo — NFS permissions may block normal user)
sudo ls -la /tmp/target-NFS/<folder>
sudo cat /tmp/target-NFS/<folder>/file.txt

# Unmount when done (important — stale mounts freeze your terminal)
sudo umount -f /tmp/target-NFS
sudo umount -l /tmp/target-NFS   # if -f doesn't work
```
