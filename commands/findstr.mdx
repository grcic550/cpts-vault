## Search configuration files

**Windows — cmd.exe**

```cmd
findstr /si /n /c:"password" *.xml *.ini *.txt *.config
```

/s searches subdirectories, /i ignores case, /n shows line numbers. Start in the directory you intend to search.

## Filter piped output

**Windows — cmd.exe**

```cmd
systeminfo | findstr /B /C:"OS Name" /C:"OS Version"
```

Output labels vary with the Windows language.
