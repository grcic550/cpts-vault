## Inspect the current daemon

**Kali**

```bash
docker context show
docker ps
```

## Inspect a container

**Kali**

```bash
docker inspect CONTAINER_NAME
```

Check mounts, capabilities, namespaces, and privileged status in context; root inside a container is not automatically host root.
