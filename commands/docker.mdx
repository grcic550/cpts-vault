## Inspect the selected Docker daemon and one container

**Run in:** Linux host with Docker CLI. **Requires:** Permission to reach the selected Docker daemon and a real container name; the active context may be remote.

```bash
docker context show
docker ps
docker inspect CONTAINER_NAME
```

**What the result establishes:** Identify whether you are talking to a local socket or remote daemon and inspect current container boundaries.

**Next check:** Check context, socket/endpoint and group/token access; inspect mounts and privileges before inferring any host boundary crossing.

## Inspect the current daemon

**Kali**

```bash
docker context show
docker ps
```

## Inspect a container

**Kali**

```bash
docker inspect CONTAINER_NAME
```

Check mounts, capabilities, namespaces, and privileged status in context; root inside a container is not automatically host root.

## If it fails

| Symptom | Check |
| --- | --- |
| The CLI is present but cannot access the daemon | Access to a privileged host daemon is materially different from merely running inside a container; mounts and namespace sharing determine exposure. |
