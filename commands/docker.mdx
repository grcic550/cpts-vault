## Docker: choose the operation and read the result

Inspect the Docker daemon, containers, and mounts.

### What the result establishes

Identify whether you are talking to a local socket or remote daemon and inspect current container boundaries.

### Prerequisites and common failures

Access to a privileged host daemon is materially different from merely running inside a container; mounts and namespace sharing determine exposure.

Permission to access the selected Docker daemon. Check the context before interpreting its host or containers.

### Example 1: Inspect the current daemon

Run in: **Kali**.

```bash
docker context show
docker ps
```

### Example 2: Inspect a container

Run in: **Kali**. Check mounts, capabilities, namespaces, and privileged status in context; root inside a container is not automatically host root.

```bash
docker inspect CONTAINER_NAME
```
