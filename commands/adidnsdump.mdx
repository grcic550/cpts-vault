## Current operation: Read AD-integrated DNS records

**Run in:** Kali. **Requires:** Authenticated directory access to a DC and the intended DNS zone context.

```bash
adidnsdump -u 'DOMAIN\USER' -p 'PASSWORD' DC_FQDN
```

**Read the result:** Use directory-visible DNS records to discover candidate internal names and resolve them through the appropriate lab DNS server.

**If A record name appears without a readable address:** A record can be stale or unreadable; an empty value is not necessarily proof that the named host is absent.

**Next check:** Resolve the candidate through the lab DNS server and distinguish unreadable or stale records from live services.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
