## adidnsdump: choose the operation and read the result

Commands and examples collected from your adidnsdump notes.

### What the result establishes

Use directory-visible DNS records to discover candidate internal names and resolve them through the appropriate lab DNS server.

### Prerequisites and common failures

A record can be stale or unreadable; an empty value is not necessarily proof that the named host is absent.

### Example 1: Using adidnsdump

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```shellsession
grcic550@htb[/htb]$ adidnsdump -u inlanefreight\\forend ldap://172.16.5.5

Password:

[-] Connecting to host...
[-] Binding to host
[+] Bind OK
[-] Querying zone for records
[+] Found 27 records
```
