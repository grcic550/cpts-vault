**Requires:** GroupPolicy module for the PowerShell commands; domain connectivity and rights to read the policy.

## List policies

**Windows PowerShell**

```powershell
Import-Module GroupPolicy
Get-GPO -All | Select-Object DisplayName,Id,GpoStatus
```

## Inspect permissions

**Windows PowerShell**

```powershell
Get-GPPermission -Name 'GPO_NAME' -All
```

## Applied computer policy

**Elevated Windows cmd.exe or PowerShell**

```text
gpresult /r /scope computer
```
