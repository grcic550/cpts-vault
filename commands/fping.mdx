## Current operation: Probe a bounded IPv4 range

**Run in:** Kali. **Requires:** A confirmed lab CIDR and permission to probe it; raw ICMP capability may be required.

```bash
fping -a -g LAB_CIDR
```

**Read the result:** Use responsive addresses as initial live-host candidates and preserve which probe was used.

**If No echo replies are received:** Hosts can block ICMP while serving TCP applications, so a silent address is not conclusively down.

**Next check:** Retain the probe result and try relevant TCP service discovery; silence does not establish that every host is down.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
