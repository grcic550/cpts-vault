## Probe a bounded IPv4 range

**Run in:** Kali. **Requires:** A confirmed lab CIDR and permission to probe it; raw ICMP capability may be required.

```bash
fping -a -g LAB_CIDR
```

**What the result establishes:** Use responsive addresses as initial live-host candidates and preserve which probe was used.

**Next check:** Retain the probe result and try relevant TCP service discovery; silence does not establish that every host is down.

## Tools and techniques

**Notebook example**

```bash
fping -asqg 172.16.5.0/23
```

## If it fails

| Symptom | Check |
| --- | --- |
| No echo replies are received | Hosts can block ICMP while serving TCP applications, so a silent address is not conclusively down. |
