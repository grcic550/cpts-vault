## Commands

**Kali**

```bash
ldapsearch -x -H ldap://DC_IP -D 'USER@DOMAIN' -W -b 'DC=example,DC=local' '(sAMAccountName=USER)'
```

Replace the base DN DC=example,DC=local with your domain DN. -W prompts for the password.
