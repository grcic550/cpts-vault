## Read one user through an explicit LDAP search

**Run in:** Kali. **Requires:** A trusted LDAPS certificate, valid bind identity and the real naming context in place of the example base DN.

```bash
ldapsearch -x -H ldaps://DC_FQDN -D 'USER@DOMAIN_FQDN' -W -b 'DC=example,DC=local' '(sAMAccountName=USER)' distinguishedName memberOf
```

**What the result establishes:** Inspect bind success, naming context, filter, requested attributes and result completeness separately.

**Next check:** Check base DN, filter, requested attributes and object ACLs; distinguish an empty query from a failed bind.

## Commands

**Kali**

```bash
ldapsearch -x -H ldap://DC_IP -D 'USER@DOMAIN' -W -b 'DC=example,DC=local' '(sAMAccountName=USER)'
```

Replace the base DN DC=example,DC=local with your domain DN. -W prompts for the password.

## If it fails

| Symptom | Check |
| --- | --- |
| Bind works but the search returns no matching object | LDAP/LDAPS, simple bind and SASL/Kerberos are different choices; certificate trust, signing policy, paging and object ACLs affect results. |

### Ldap

**Active Directory Enumeration Commands**

```bash
ldapsearch -x -H ldap://<DC_IP> -D '<USER>@<DOMAIN>' -w '<PASSWORD>' -b 'DC=domain,DC=local' '(sAMAccountName=<USER>)'
    # Query LDAP for a specific user's AD object

ldapsearch -x -H ldap://<DC_IP> -D '<USER>@<DOMAIN>' -w '<PASSWORD>' -b 'DC=domain,DC=local' '(objectClass=user)'
    # Enumerate AD user objects

ldapsearch -x -H ldap://<DC_IP> -D '<USER>@<DOMAIN>' -w '<PASSWORD>' -b 'DC=domain,DC=local' '(sAMAccountName=<USER>)' memberOf
    # Show the AD groups a specific user belongs to
```

### Work from Linux with the same identity

**Active Directory Enumeration: Quick Reference**

```bash
dig @DC_IP _ldap._tcp.dc._msdcs.DOMAIN_FQDN SRV
nxc smb DC_IP -d DOMAIN_FQDN -u USERNAME -p 'PASSWORD' --users
nxc smb TARGET_IP -d DOMAIN_FQDN -u USERNAME -p 'PASSWORD' --shares
ldapsearch -x -H ldaps://DC_FQDN -D 'USERNAME@DOMAIN_FQDN' -W \
  -b 'DC=example,DC=local' '(objectClass=user)' sAMAccountName description memberOf
```
