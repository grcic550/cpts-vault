## ldapsearch: choose the operation and read the result

Query an LDAP directory from Linux.

### What the result establishes

Inspect bind success, naming context, filter, requested attributes and result completeness separately.

### Prerequisites and common failures

LDAP/LDAPS, simple bind and SASL/Kerberos are different choices; certificate trust, signing policy, paging and object ACLs affect results.

### Example 1: Commands

Run in: **Kali**. Replace the base DN DC=example,DC=local with your domain DN. -W prompts for the password.

```bash
ldapsearch -x -H ldap://DC_IP -D 'USER@DOMAIN' -W -b 'DC=example,DC=local' '(sAMAccountName=USER)'
```

### Example 2: using ldap search

Run in: **Saved lab example**.

```bash
grcic550@htb[/htb]$ ldapsearch -h 172.16.5.5 -x -b "DC=INLANEFREIGHT,DC=LOCAL" -s sub "(&(objectclass=user))"  | grep sAMAccountName: | cut -f2 -d" "
```

### Example 3: Ldap

Run in: **Saved lab example**.

```bash
ldapsearch -x -H ldap://<DC_IP> -D '<USER>@<DOMAIN>' -w '<PASSWORD>' -b 'DC=domain,DC=local' '(sAMAccountName=<USER>)'
    # Query LDAP for a specific user's AD object

ldapsearch -x -H ldap://<DC_IP> -D '<USER>@<DOMAIN>' -w '<PASSWORD>' -b 'DC=domain,DC=local' '(objectClass=user)'
    # Enumerate AD user objects

ldapsearch -x -H ldap://<DC_IP> -D '<USER>@<DOMAIN>' -w '<PASSWORD>' -b 'DC=domain,DC=local' '(sAMAccountName=<USER>)' memberOf
    # Show the AD groups a specific user belongs to
```
