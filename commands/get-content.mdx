## Read a file

**Windows PowerShell**

```powershell
Get-Content C:\PATH\FILE.txt
```

## Read saved history

**Windows PowerShell**

```powershell
Get-Content (Get-PSReadLineOption).HistorySavePath
```

PSReadLine/history may be absent in noninteractive sessions.
