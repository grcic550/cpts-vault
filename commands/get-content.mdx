## Get-Content: choose the operation and read the result

Read a text file or the current user’s saved PowerShell history.

### What the result establishes

Choose a bounded preview, tail or raw read according to the file you are inspecting.

### Prerequisites and common failures

Large or binary files should not be dumped into a terminal; text encoding and multiline representation can change how data appears.

### Example 1: Read a file

Run in: **Windows PowerShell**.

```powershell
Get-Content C:\PATH\FILE.txt
```

### Example 2: Read saved history

Run in: **Windows PowerShell**. PSReadLine/history may be absent in noninteractive sessions.

```powershell
Get-Content (Get-PSReadLineOption).HistorySavePath
```
