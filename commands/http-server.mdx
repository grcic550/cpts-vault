## Serve a dedicated folder over a chosen interface

**Run in:** Kali. **Requires:** Python 3, a prepared transfer directory and an address assigned to Kali that the target can reach.

```bash
python3 -m http.server 8000 --bind KALI_IP --directory ./transfer
```

**What the result establishes:** The server log proves an HTTP request reached this listener; confirm the returned file separately.

**Next check:** Check listener address, port, route and firewall, then request a known filename; this server does not implement file uploads.

## Commands

**Kali**

```bash
python3 -m http.server 8000
```

Run from the folder containing the files to share.

## If it fails

| Symptom | Check |
| --- | --- |
| The process runs but no client request appears | The current directory is what gets served. Binding an interface and choosing a reachable callback address are distinct decisions. |
