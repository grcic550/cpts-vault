## Current operation: Read credentials from a specified Firefox profile

**Run in:** Kali, in the firefox_decrypt checkout. **Requires:** A matching profile set including key database and login records, required NSS libraries and the primary password if configured.

```bash
python3 firefox_decrypt.py /path/to/firefox/profile
```

**Read the result:** Keep the browser profile and login database/key material together, and associate recovered entries with their sites.

**If The profile is found but decryption fails:** Profile encryption or a primary password can prevent decryption; a saved password may be stale or unrelated to system authentication.

**Next check:** Verify that key4.db and logins.json belong together and check dependency/password errors before testing any returned credential.
