Replace UPPER_CASE values with your lab values.

**Requires:** WinRM access and an authorized account. Prefer the host FQDN with working domain DNS; an IP address may require a different trust/authentication setup.

## Check and connect

**Windows PowerShell**

```powershell
Test-WSMan HOST_FQDN
Enter-PSSession -ComputerName HOST_FQDN -Credential DOMAIN\USER
```

## Run a command

**Windows PowerShell**

```powershell
Invoke-Command -ComputerName HOST_FQDN -Credential DOMAIN\USER -ScriptBlock { whoami }
```
