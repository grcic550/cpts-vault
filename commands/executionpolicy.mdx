## Inspect execution policy by scope

**Run in:** Windows PowerShell. **Requires:** The actual PowerShell process in which a script fails.

```powershell
Get-ExecutionPolicy -List
```

**What the result establishes:** Use the effective policy and its scope as context for script loading behavior.

**Next check:** Check higher-priority policy and the exact error; execution policy is distinct from application control, language mode and antivirus enforcement.

## If it fails

| Symptom | Check |
| --- | --- |
| A permissive process policy does not allow the script to execute | Execution policy is not a security boundary or a grant of administrator rights; other controls may still prevent execution. |
