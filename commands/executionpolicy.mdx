## Current operation: Inspect execution policy by scope

**Run in:** Windows PowerShell. **Requires:** The actual PowerShell process in which a script fails.

```powershell
Get-ExecutionPolicy -List
```

**Read the result:** Use the effective policy and its scope as context for script loading behavior.

**If A permissive process policy does not allow the script to execute:** Execution policy is not a security boundary or a grant of administrator rights; other controls may still prevent execution.

**Next check:** Check higher-priority policy and the exact error; execution policy is distinct from application control, language mode and antivirus enforcement.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
