## Test an NT hash against a wordlist

**Run in:** Kali. **Requires:** An actual NT hash in the expected format and a usable compute backend; mode 1000 is not NetNTLMv2 or Kerberos.

```bash
hashcat -m 1000 -a 0 ntlm.hash wordlist.txt
hashcat -m 1000 ntlm.hash --show
```

**What the result establishes:** Identify the artifact format and hash mode first; read recovered versus exhausted status and use --show on the original hash file.

**Next check:** Identify the artifact type and formatting first, then choose a justified wordlist/rule strategy; exhausted candidates do not prove the password is strong.

## Commands

**Kali**

```bash
hashcat -m HASH_MODE hashes.txt /usr/share/wordlists/rockyou.txt
hashcat -m HASH_MODE hashes.txt --show
# Common modes: NTLM 1000; NetNTLMv2 5600; Kerberoast 13100; AS-REP 18200
```

## If it fails

| Symptom | Check |
| --- | --- |
| The parser rejects the file or all candidates are exhausted | An exhausted wordlist does not prove the password is strong or the hash invalid; the wrong mode, encoding or malformed input can invalidate the attempt. |
