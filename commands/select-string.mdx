### Example 1: Search a file

Run in: **Windows PowerShell**.

```powershell
Select-String -Path C:\PATH\FILE.txt -Pattern "password"
```

### Example 2: Search configuration files

Run in: **Windows PowerShell**.

```powershell
Get-ChildItem -Path C:\PATH -Recurse -File -Include *.config,*.xml,*.ini -ErrorAction SilentlyContinue | Select-String -Pattern "password"
```
