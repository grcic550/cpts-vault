<Accordion title="2. Listing and reading shares">

### 2. Listing and reading shares

**SMB Enumeration and Shares**

```bash
smbclient -L //<IP>/ -N                         # -N = no password; list shares via null session
smbclient //<IP>/<share> -U '<user>%<pass>'     # connect to a share interactively
#   inside smbclient:  ls / cd <dir> / get <file> / mget * / recurse ON; ls
smbmap -H <IP> -u <user> -p '<pass>'            # list shares WITH permissions in one view
smbmap -H <IP> -u <user> -p '<pass>' -R <share> # recurse a share and show the file tree
```
