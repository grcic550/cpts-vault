## Identify a SQL login through a bounded query

**Run in:** Client with sqlcmd installed. **Requires:** SQL authentication accepted by the instance; supply the password at the prompt. TLS trust behavior depends on the installed client.

```bash
sqlcmd -S TARGET_IP -U USER -Q "SELECT SYSTEM_USER, DB_NAME();"
```

**What the result establishes:** Establish the server instance, authentication mode, database and effective login, then run bounded queries.

**Next check:** Resolve hostname/certificate trust and client options first; then inspect the effective SQL principal and database.

## Commands

**Client with sqlcmd installed**

```bash
sqlcmd -S TARGET_IP -U USER -P "PASSWORD"
# Current Windows account
sqlcmd -S MS01 -E
```

## If it fails

| Symptom | Check |
| --- | --- |
| TLS connection fails before credentials are checked | SQL logins and Windows authentication are different; newer client generations can have different TLS defaults and option behavior. |
