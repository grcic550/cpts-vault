## Current operation: Identify a SQL login through a bounded query

**Run in:** Client with sqlcmd installed. **Requires:** SQL authentication accepted by the instance; supply the password at the prompt. TLS trust behavior depends on the installed client.

```bash
sqlcmd -S TARGET_IP -U USER -Q "SELECT SYSTEM_USER, DB_NAME();"
```

**Read the result:** Establish the server instance, authentication mode, database and effective login, then run bounded queries.

**If TLS connection fails before credentials are checked:** SQL logins and Windows authentication are different; newer client generations can have different TLS defaults and option behavior.

**Next check:** Resolve hostname/certificate trust and client options first; then inspect the effective SQL principal and database.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
