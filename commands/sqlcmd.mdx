**Footprinting: Service-by-Service Lab Workflow**

```bash
# Connect remotely (Impacket)
mssqlclient.py <user>:'<pass>'@<IP>
mssqlclient.py <user>:'<pass>'@<IP> -port <port>

# Connect locally on Windows (sqlcmd)
sqlcmd -S <server> -U sa -P "<pass>"
sqlcmd -S <server> -E                  # Windows auth (no password)

# Useful queries
SELECT name FROM sys.databases;
GO
USE <database>;
GO
SELECT * FROM INFORMATION_SCHEMA.TABLES;
GO
SELECT * FROM <table>;
GO

# Enable OS command execution (as sa)
enable_xp_cmdshell
xp_cmdshell whoami
xp_cmdshell dir C:\Users
```

Context from the notebook: Lesson learned:   sa  login failed because the account was locked. Used Administrator's Windows account (password reuse from  important.txt ) to open admin CMD, then  sqlcmd -S WINMEDIUM -E  with Windows auth worked. The  accounts  database had user credentials.

```text
sqlcmd -S WINMEDIUM -E
```
