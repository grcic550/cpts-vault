## Current operation: Ask the domain resolver for an address

**Run in:** Windows PowerShell. **Requires:** Observed host FQDN and the resolver that serves the lab domain.

```powershell
Resolve-DnsName -Name HOST_FQDN -Server DC_IP -Type A
```

**Read the result:** Read the returned record type, answer and responding resolver; distinguish authoritative data from cached results.

**If The default resolver answers differently:** An A record is not an SRV record, and a hostname resolving on one machine does not prove it resolves on your pivot.

**Next check:** Record the returned address and resolver; use SRV queries separately when locating domain services.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.

### Example 1: Commands

Run in: **Windows PowerShell**. Replace DOMAIN and DC_IP with the lab domain and its DNS/DC address.

```powershell
Resolve-DnsName -Name MS01 -Type A
Resolve-DnsName -Name MS01.DOMAIN -Server DC_IP -Type A
(Resolve-DnsName -Name MS01.DOMAIN -Server DC_IP -Type A).IPAddress
```
