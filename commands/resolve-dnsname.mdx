## Ask the domain resolver for an address

**Run in:** Windows PowerShell. **Requires:** Observed host FQDN and the resolver that serves the lab domain.

```powershell
Resolve-DnsName -Name HOST_FQDN -Server DC_IP -Type A
```

**What the result establishes:** Read the returned record type, answer and responding resolver; distinguish authoritative data from cached results.

**Next check:** Record the returned address and resolver; use SRV queries separately when locating domain services.

## Commands

**Windows PowerShell**

```powershell
Resolve-DnsName -Name MS01 -Type A
Resolve-DnsName -Name MS01.DOMAIN -Server DC_IP -Type A
(Resolve-DnsName -Name MS01.DOMAIN -Server DC_IP -Type A).IPAddress
```

Replace DOMAIN and DC_IP with the lab domain and its DNS/DC address.

## If it fails

| Symptom | Check |
| --- | --- |
| The default resolver answers differently | An A record is not an SRV record, and a hostname resolving on one machine does not prove it resolves on your pivot. |
