## Obtain and select a TGT cache

**Run in:** Kali with MIT Kerberos utilities. **Requires:** A supported account credential, correct realm/DC and the actual cache filename printed by getTGT.

```bash
impacket-getTGT 'DOMAIN_FQDN/USER' -dc-ip DC_IP
export KRB5CCNAME="$PWD/USER.ccache"
klist
```

**What the result establishes:** Confirm the cache contains a TGT for the intended principal/realm and note its expiry.

**Next check:** Confirm the generated filename, principal and expiry, then use a Kerberos-aware service client with the matching hostname.

## Commands

**Kali**

```bash
impacket-getTGT 'DOMAIN/USER:PASSWORD'
export KRB5CCNAME=USER.ccache
```

## If it fails

| Symptom | Check |
| --- | --- |
| The cache exists but no valid TGT appears | A TGT is not a service ticket. The supplied password, NT hash or AES key must match the mechanism and account. |
