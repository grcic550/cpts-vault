## Read a specific application configuration file

**Run in:** Linux target. **Requires:** The actual readable text file and a reason to inspect its service configuration.

```bash
cat -- /opt/APP/app.conf
```

**What the result establishes:** Inspect the selected file and preserve surrounding lines that give a value its meaning.

**Next check:** Trace the active service's configuration path and environment source; do not treat a sample setting as a confirmed credential.

## Exploitation steps

**Notebook example**

```bash
cd /root
cat root.txt
```

Saved as written; may include lab values or terminal output.

## If it fails

| Symptom | Check |
| --- | --- |
