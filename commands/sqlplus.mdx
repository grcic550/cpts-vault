## Current operation: Connect to a named Oracle service

**Run in:** Oracle SQL*Plus client. **Requires:** Oracle client, reachable listener and the observed service name; password is prompted.

```bash
sqlplus USER@TARGET_IP/SERVICE_NAME
```

**Read the result:** Identify the Oracle service/SID and selected account before interpreting catalog or role queries.

**If The listener is reachable but the service name is rejected:** A TNS listener response does not guarantee the guessed service name or credentials are valid; privileged SYSDBA access is a separate role.

**Next check:** Verify listener/service details before retrying the account; once connected, inspect the effective schema and privileges.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
