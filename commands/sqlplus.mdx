## sqlplus: choose the operation and read the result

Connect to an Oracle database.

### What the result establishes

Identify the Oracle service/SID and selected account before interpreting catalog or role queries.

### Prerequisites and common failures

A TNS listener response does not guarantee the guessed service name or credentials are valid; privileged SYSDBA access is a separate role.

### Example 1: Commands

Run in: **Client with Oracle tools**.

```bash
sqlplus USER/PASSWORD@TARGET_IP/SERVICE_NAME
```

### Example 2: Connecting (SQL*Plus)

Run in: **Saved lab example**.

```bash
sqlplus <user>/<pass>@<IP>/<SID>                # standard login
sqlplus scott/tiger@10.129.204.235/XE

sqlplus <user>/<pass>@<IP>/<SID> as sysdba      # escalate to DBA at login if allowed
```
