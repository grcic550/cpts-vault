## Connect to a named Oracle service

**Run in:** Oracle SQL*Plus client. **Requires:** Oracle client, reachable listener and the observed service name; password is prompted.

```bash
sqlplus USER@TARGET_IP/SERVICE_NAME
```

**What the result establishes:** Identify the Oracle service/SID and selected account before interpreting catalog or role queries.

**Next check:** Verify listener/service details before retrying the account; once connected, inspect the effective schema and privileges.

## Commands

**Client with Oracle tools**

```bash
sqlplus USER/PASSWORD@TARGET_IP/SERVICE_NAME
```

## If it fails

| Symptom | Check |
| --- | --- |
| The listener is reachable but the service name is rejected | A TNS listener response does not guarantee the guessed service name or credentials are valid; privileged SYSDBA access is a separate role. |
