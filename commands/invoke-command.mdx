## Invoke-Command: choose the operation and read the result

Commands and examples collected from your Invoke-Command notes.

### What the result establishes

Inspect the remote computer and identity that produced the returned objects.

### Prerequisites and common failures

PowerShell remoting, endpoint authorization and second-hop authentication are distinct; local credentials are not automatically delegated onward.

### Find Credentials in Network Shares

**Find Credentials in Network Shares**

```bash
# the domain prefix (most reliable signal)
grep -ri "DOMAINNAME\\\\" .

# UPN format
grep -riE "[a-z]+@domain\.local" .

# runas / net use / Invoke-Command patterns - operators leak creds in commands
grep -riE "runas|net use|Invoke-Command|New-PSSession|ConvertTo-SecureString" .

# anything with "service account" / "svc_" in filenames
find . -iname "*svc*" -o -iname "*service*account*"
```
