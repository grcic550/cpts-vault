## Current operation: Check one Windows TCP connection

**Run in:** Windows PowerShell. **Requires:** A hostname resolvable from this Windows host and the intended service port.

```powershell
Test-NetConnection -ComputerName HOST_FQDN -Port 445
```

**Read the result:** Use TcpTestSucceeded to establish a TCP connection to the selected port from this Windows host.

**If TcpTestSucceeded is false:** A successful TCP handshake is not application authentication, and failure can be routing, firewall or service state rather than bad credentials.

**Next check:** Check the selected address and route, then listener/firewall state; if true, use the SMB client with the intended identity.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
