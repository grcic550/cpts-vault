## Check one Windows TCP connection

**Run in:** Windows PowerShell. **Requires:** A hostname resolvable from this Windows host and the intended service port.

```powershell
Test-NetConnection -ComputerName HOST_FQDN -Port 445
```

**What the result establishes:** Use TcpTestSucceeded to establish a TCP connection to the selected port from this Windows host.

**Next check:** Check the selected address and route, then listener/firewall state; if true, use the SMB client with the intended identity.

## Commands

**Windows PowerShell**

```powershell
Test-NetConnection -ComputerName MS01 -Port 445
```

## If it fails

| Symptom | Check |
| --- | --- |
| TcpTestSucceeded is false | A successful TCP handshake is not application authentication, and failure can be routing, firewall or service state rather than bad credentials. |
