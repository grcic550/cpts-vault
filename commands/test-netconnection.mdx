## Test-NetConnection: choose the operation and read the result

Check whether a TCP service is reachable.

### What the result establishes

Use TcpTestSucceeded to establish a TCP connection to the selected port from this Windows host.

### Prerequisites and common failures

A successful TCP handshake is not application authentication, and failure can be routing, firewall or service state rather than bad credentials.

### Example 1: Commands

Run in: **Windows PowerShell**.

```powershell
Test-NetConnection -ComputerName MS01 -Port 445
```

### Example 2: PowerShell Remoting (WinRM) Transfers

Run in: **Saved lab example**.

```powershell
# Test connectivity
Test-NetConnection -ComputerName DATABASE01 -Port 5985

# Create a session
$Session = New-PSSession -ComputerName DATABASE01

# Copy file TO remote machine
Copy-Item -Path C:\samplefile.txt -ToSession $Session -Destination C:\Users\Administrator\Desktop\

# Copy file FROM remote machine
Copy-Item -Path "C:\Users\Administrator\Desktop\DATABASE.txt" -Destination C:\ -FromSession $Session
```
