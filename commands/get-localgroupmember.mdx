**Requires:** Microsoft.PowerShell.LocalAccounts module. Use matching 64-bit PowerShell on 64-bit Windows.

## Local administrators

**Windows PowerShell**

```powershell
Get-LocalGroupMember -Group 'Administrators' | Format-Table Name,PrincipalSource
```

Use the localized group name on non-English systems.

## Find available group names

**Windows PowerShell**

```powershell
Get-LocalGroup
```

## If it fails

| Symptom | Check |
| --- | --- |
| Cmdlet unavailable | Use net localgroup to list groups, then net localgroup "GROUP_NAME". Domain membership is a separate query. |
