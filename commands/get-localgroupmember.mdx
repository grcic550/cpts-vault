## Current operation: Resolve local Administrators membership

**Run in:** Windows PowerShell. **Requires:** The LocalAccounts module on a supported Windows host; the well-known SID avoids localized group-name assumptions.

```powershell
Get-LocalGroupMember -SID 'S-1-5-32-544'
```

**Read the result:** Record members and resolved principal sources for the selected local group.

**If A domain principal is listed but its current token is restricted:** Domain groups can grant indirect access, and current tokens can predate membership changes; a failed SID resolution can hide a member's display name.

**Next check:** Resolve nested domain membership and inspect whoami /all in the actual session; group membership does not prove an elevated process.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.

