## Get-LocalGroupMember: choose the operation and read the result

List members of a local Windows group.

### What the result establishes

Record members and resolved principal sources for the selected local group.

### Prerequisites and common failures

Domain groups can grant indirect access, and current tokens can predate membership changes; a failed SID resolution can hide a member's display name.

Microsoft.PowerShell.LocalAccounts module. Use matching 64-bit PowerShell on 64-bit Windows.

### Example 1: Local administrators

Run in: **Windows PowerShell**. Use the localized group name on non-English systems.

```powershell
Get-LocalGroupMember -Group 'Administrators' | Format-Table Name,PrincipalSource
```

### Example 2: Find available group names

Run in: **Windows PowerShell**.

```powershell
Get-LocalGroup
```

**Cmdlet unavailable** — Use net localgroup to list groups, then net localgroup "GROUP_NAME". Domain membership is a separate query.
