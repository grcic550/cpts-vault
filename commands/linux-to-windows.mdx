## Current operation: Download a served file from Kali to Windows

**Run in:** Windows PowerShell. **Requires:** Kali is serving the intended directory with python3 -m http.server 8000; Windows can reach that address and write the destination.

```powershell
Invoke-WebRequest -UseBasicParsing 'http://KALI_IP:8000/file.bin' -OutFile 'C:\Users\Public\file.bin'
Get-FileHash 'C:\Users\Public\file.bin' -Algorithm SHA256
```

**Read the result:** Confirm the downloaded object is the intended file rather than an HTML error/login page, then compare its hash.

**If The result is empty or contains an HTML error page:** PowerShell and curl.exe are different clients; quoting, TLS trust, proxy configuration and the current working directory can change the result.

**Next check:** Check the requested URL and server log, then compare the hash to the original before using the file.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
