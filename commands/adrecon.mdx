## Export an authenticated AD inventory

**Run in:** Windows PowerShell. **Requires:** The intended ADRecon script and dependencies, a domain-authenticated session and a writable collection directory.

```powershell
.\ADRecon.ps1
```

**What the result establishes:** Check collection errors and report sections, then use object names and attributes for targeted follow-up queries.

**Next check:** Retain the error log and collection time; use targeted directory queries to fill a specific missing relationship.
