## Get-Service: choose the operation and read the result

List Windows services and their current state.

### What the result establishes

Inspect state and correlate an interesting service with its executable path and execution identity.

### Prerequisites and common failures

Get-Service alone does not show every security property; service-control ACLs and filesystem permissions require separate checks.

### Example 1: List services

Run in: **Windows PowerShell**.

```powershell
Get-Service
```

### Example 2: Inspect one service

Run in: **Windows PowerShell**. Use sc.exe qc SERVICE_NAME to inspect the binary path and service account.

```powershell
Get-Service -Name 'SERVICE_NAME' | Format-List Name,DisplayName,Status,StartType
```
