## List services

**Windows PowerShell**

```powershell
Get-Service
```

## Inspect one service

**Windows PowerShell**

```powershell
Get-Service -Name 'SERVICE_NAME' | Format-List Name,DisplayName,Status,StartType
```

Use sc.exe qc SERVICE_NAME to inspect the binary path and service account.
