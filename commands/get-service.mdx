## Inspect one service's status and startup mode

**Run in:** Windows PowerShell. **Requires:** A real service name and permission to read the service manager.

```powershell
Get-Service -Name 'SERVICE_NAME' | Format-List Name,DisplayName,Status,StartType
```

**What the result establishes:** Inspect state and correlate an interesting service with its executable path and execution identity.

**Next check:** Resolve the actual service name and query executable/account settings with Get-CimInstance or sc.exe qc before testing permissions.

## List services

**Windows PowerShell**

```powershell
Get-Service
```

## If it fails

| Symptom | Check |
| --- | --- |
| The service is stopped or its display name differs from its service name | Get-Service alone does not show every security property; service-control ACLs and filesystem permissions require separate checks. |
