## Collect local Windows configuration leads

**Run in:** Windows PowerShell. **Requires:** A locally available PowerUp script and compatible PowerShell context; review the selected build before use.

```powershell
Import-Module .\PowerUp.ps1
Invoke-AllChecks
```

**What the result establishes:** Read each finding's exact writable object and proposed action before verifying it manually.

**Next check:** Manually confirm effective permissions, service identity and a trigger; Invoke-AllChecks findings are hypotheses, not automatic exploit results.
