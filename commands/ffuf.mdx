## Current operation: Compare virtual-host responses against a baseline

**Run in:** Kali. **Requires:** A reachable application, hostname candidates and the measured size of a known nonexistent virtual host response.

```bash
ffuf -w names.txt -u http://TARGET_IP/ -H 'Host: FUZZ.DOMAIN_FQDN' -mc all -fs BASELINE_SIZE
```

**Read the result:** Compare hits with a known-missing baseline and inspect the actual responses before accepting status/size filters.

**If Every candidate looks identical or useful responses disappear:** Wildcard routes, authentication redirects and identical lengths can hide real pages or create false positives; FUZZ placement defines what is tested.

**Next check:** Revisit the filter using an invalid control; confirm a distinct host manually with the same Host header and session.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
