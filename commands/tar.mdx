## Current operation: List an archive before extracting it

**Run in:** Kali. **Requires:** A readable archive recognized by the installed tar implementation.

```bash
tar -tf archive.tar
```

**Read the result:** List archive members before extracting and verify the destination and preserved metadata.

**If The file is corrupt or member paths are unexpected:** Archive paths and symlinks can affect where files land; extracting is a filesystem write, unlike listing contents.

**Next check:** Confirm archive type and inspect member names, then extract into a dedicated directory with appropriate ownership expectations.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
