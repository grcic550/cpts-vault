## Test a prepared hash artifact with John Jumbo

**Run in:** Kali. **Requires:** A supported hash artifact; encrypted containers may need a matching converter before John can parse them.

```bash
john --wordlist=wordlist.txt hashes.txt
john --show hashes.txt
```

**What the result establishes:** Confirm the loaded hash format, selected wordlist/rules and whether the pot file already contains a result.

**Next check:** Confirm the source artifact and supported format, then select the exact format when auto-detection is ambiguous.

## Commands

**Kali**

```bash
john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
john --show hashes.txt
```

## If it fails

| Symptom | Check |
| --- | --- |
| No hashes load or an unintended format is selected | A format warning or zero hashes loaded needs input-format investigation; do not treat it as a failed password search. |
