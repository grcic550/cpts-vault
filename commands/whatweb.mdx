<Accordion title="Complete Recon Methodology">

### Complete Recon Methodology

**DNS and Web Reconnaissance: Full Workflow**

```text
Passive Recon (no target contact)
├── CT logs (crt.sh) → subdomains that ever had a cert
├── Google dorking → exposed files, login pages, config leaks
├── DNS enumeration → public DNS records
├── WHOIS / Shodan → infrastructure intel
├── .well-known URIs → security.txt, openid-config
└── theHarvester → emails, hosts from public sources

Active Recon (direct target interaction)
├── Zone transfer attempt (dig axfr) → dump DNS if misconfigured
├── VHost fuzzing (ffuf/gobuster) → hidden vhosts
├── Fingerprinting (WhatWeb/Nikto/Nmap) → tech stack
├── WAF detection (wafw00f) → security layer check
├── Web crawling (Scrapy/Burp/ZAP) → site map, links, files
├── robots.txt / sitemap.xml → hidden paths, structure
└── Directory brute force → unlisted pages

Post-Discovery
├── Add found vhosts/subdomains to /etc/hosts
├── Run CMS-specific scanners (WPScan, JoomScan)
├── Analyse extracted data (emails, comments, JS files)
├── Enumerate each attack surface
└── Prioritise dev/staging environments (weaker security)
```

### Web Enumeration: Quick Commands

**Web Enumeration: Quick Commands**

```bash
# Fingerprint
whatweb http://$IP
curl -sI http://$IP            # headers, server, redirects
# Directory / file discovery
feroxbuster -u http://$IP -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt -x php,txt,html
gobuster dir -u http://$IP -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt -x php,txt
# Virtual host (subdomain) discovery — match on response size to filter noise
ffuf -H "Host: FUZZ.$DOMAIN" -u http://$IP -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -fs <size>
```
