## Inspect ZIP members and test integrity

**Run in:** Kali. **Requires:** A readable ZIP file and its password if encrypted.

```bash
unzip -l archive.zip
unzip -t archive.zip
```

**What the result establishes:** Inspect archive entries, extraction destination and password/encryption errors separately.

**Next check:** Review member paths and extract into a dedicated directory; successful decompression does not establish that the contents are relevant or trusted.

## BloodHound rejects the ZIP

**Notebook example**

## If it fails

| Symptom | Check |
