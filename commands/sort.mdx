## Deduplicate a text list into a separate output

**Run in:** Kali. **Requires:** A complete newline-delimited list and a different output path; lexical order is sufficient for this task.

```bash
LC_ALL=C sort -u candidates.txt > candidates.unique.txt
```

**What the result establishes:** Choose lexical, numeric or field-based ordering according to the data's meaning.

**Next check:** Preserve the raw list, define normalization deliberately and compare counts before using candidates in an authentication test.
