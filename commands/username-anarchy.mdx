## Generate candidate usernames from known names

**Run in:** Kali, in the username-anarchy checkout. **Requires:** A bounded list of names relevant to the lab and the expected input format.

```bash
./username-anarchy -i names.txt
```

**What the result establishes:** Treat generated naming permutations as candidates and validate them with a suitable scoped account-discovery method.

**Next check:** Compare against a confirmed username/email pattern and narrow the output before checking validity; generated candidates are not discovered accounts.

## If it fails

| Symptom | Check |
| --- | --- |
| Generated names do not match the observed organization convention | A generated string is not proof of a real account; naming conventions and duplicate people can produce many false candidates. |
