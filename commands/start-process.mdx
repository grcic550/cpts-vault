## Current operation: Start a process and collect its exit status

**Run in:** Windows PowerShell. **Requires:** A valid executable path and permission to launch it in the current session.

```powershell
$p = Start-Process -FilePath 'C:\Windows\System32\cmd.exe' -ArgumentList '/c whoami' -Wait -PassThru
$p.ExitCode
```

**Read the result:** Confirm the launched executable, arguments, working directory and resulting process identity.

**If The process exits but no expected output is captured:** Argument parsing occurs separately from the calling shell; requesting alternate credentials or elevation does not guarantee success.

**Next check:** Use explicit output redirection when needed; -PassThru returns a process object, not stdout, and launching does not imply elevation.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
