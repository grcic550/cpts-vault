## Copy one remote file into a local evidence directory

**Run in:** Kali. **Requires:** SSH authentication and read access to the remote file; modern OpenSSH scp commonly uses SFTP.

```bash
scp USER@HOST_FQDN:/path/file.txt ./file.txt
```

**What the result establishes:** Confirm transfer direction, remote path interpretation, exit status and the destination file's digest.

**Next check:** Check remote path and SFTP support; use legacy SCP mode only when the server requires it and compare the received file's digest.

## Commands

**Kali**

```bash
scp ./file.zip USER@TARGET_IP:/tmp/file.zip
scp USER@TARGET_IP:/tmp/file.zip ./file.zip
```

## If it fails

| Symptom | Check |
| --- | --- |
| SSH login works but the transfer subsystem fails | Local shell expansion and remote path quoting differ; a readable source does not imply a writable destination directory. |

### Pulling files FROM the target to Kali (the hard direction)

**Pivoting and File Transfer: Field Reference**

```bash

#    on the internal host:
net use \\172.16.119.13\share /user:u p

#    DMZ -> Kali:

# 3) Reverse forward (ligolo listener_add or chisel/ssh -R), then smbserver/nc ON Kali

```
