## accesschk.exe: choose the operation and read the result

Commands and examples collected from your accesschk.exe notes.

### What the result establishes

Tie reported rights to the exact user/group and object type being checked.

### Prerequisites and common failures

Service-configuration access, executable write access and directory write access are distinct conditions; examine each part of a proposed path.
