## Current operation: Inspect file capabilities in relevant executable directories

**Run in:** Linux target. **Requires:** The libcap utility and accessible directories; permission errors are omitted and other paths need separate checks.

```bash
getcap -r /usr/bin /usr/sbin /opt 2>/dev/null
```

**Read the result:** Read the specific capability and effective/permitted bits on the executable, then check how the program uses them.

**If A capability is present but the binary cannot exercise it as expected:** A capability label alone is not an exploit; executable behavior, user namespace and mount settings affect its impact.

**Next check:** Inspect the exact capability set, file owner, mount restrictions and program behavior; a capability name alone does not prove an escalation.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
