## Inspect file capabilities in relevant executable directories

**Run in:** Linux target. **Requires:** The libcap utility and accessible directories; permission errors are omitted and other paths need separate checks.

```bash
getcap -r /usr/bin /usr/sbin /opt 2>/dev/null
```

**What the result establishes:** Read the specific capability and effective/permitted bits on the executable, then check how the program uses them.

**Next check:** Inspect the exact capability set, file owner, mount restrictions and program behavior; a capability name alone does not prove an escalation.

## Interesting capabilities

**Notebook example**


## If it fails

| Symptom | Check |
| --- | --- |
| A capability is present but the binary cannot exercise it as expected | A capability label alone is not an exploit; executable behavior, user namespace and mount settings affect its impact. |
