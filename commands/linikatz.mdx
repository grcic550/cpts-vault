## Collect Linux AD credential artifacts in a controlled lab

**Run in:** Linux domain-integrated lab host. **Requires:** The intended script, root-level file access and a host using supported AD integration components; collection can copy sensitive artifacts locally.

```bash
sudo ./linikatz.sh
```

**What the result establishes:** Identify the integration stack and credential cache or key material returned for the Linux host.

**Next check:** Inspect the actual SSSD, Samba or Kerberos configuration and its artifact paths; root on Linux does not by itself establish a domain account's rights.

## If it fails

| Symptom | Check |
| --- | --- |
| The script finds no supported integration or cache material | Domain-joined Linux systems use different authentication stacks; required privileges and artifact formats vary by deployment. |
