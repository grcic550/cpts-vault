## Inspect the effective Linux identity and groups

**Run in:** Linux target. **Requires:** A shell and a real account name for the second query.

```bash
id
id USER
```

**What the result establishes:** Record the real/effective UID and supplementary groups for the current process.

**Next check:** Use the current process's id output for access decisions; a new login may be needed for membership changes to affect a token.

## Current identity

**Kali / Linux**

```bash
id
```

## Named account

**Kali / Linux**

```bash
id USER
```

Existing processes may retain earlier groups until a new login.

## If it fails

| Symptom | Check |
| --- | --- |
| The account database lists a group absent from this process | Group membership only matters when linked to an actual file, socket, sudo rule or service right; it is not itself an escalation. |
