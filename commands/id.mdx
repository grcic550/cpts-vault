## id: choose the operation and read the result

Show the current Linux user ID and group memberships.

### What the result establishes

Record the real/effective UID and supplementary groups for the current process.

### Prerequisites and common failures

Group membership only matters when linked to an actual file, socket, sudo rule or service right; it is not itself an escalation.

### Example 1: Current identity

Run in: **Kali / Linux**.

```bash
id
```

### Example 2: Named account

Run in: **Kali / Linux**. Existing processes may retain earlier groups until a new login.

```bash
id USER
```
