## 2john converters: choose the operation and read the result

Convert a protected file to a format John can read.

### What the result establishes

The extractor's output is the cracking input, not the original archive/document/database file.

### Prerequisites and common failures

Choose the extractor matching the file type and inspect stdout versus diagnostics before saving the hash text.

### Example 1: Commands

Run in: **Kali**.

```bash
ssh2john id_rsa > ssh.hash
zip2john file.zip > zip.hash
keepass2john file.kdbx > keepass.hash
john --wordlist=/usr/share/wordlists/rockyou.txt ssh.hash
```

### Example 2: *2john converters

Run in: **Saved lab example**.

```bash

zip2john secret.zip > h
```
