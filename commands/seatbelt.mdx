## Collect Windows system context with Seatbelt

**Run in:** Windows PowerShell. **Requires:** A compatible Seatbelt build and a Windows session; some collection commands need elevated rights.

```powershell
.\Seatbelt.exe -group=system
```

**What the result establishes:** Pick the relevant collection group and tie findings to the current user or machine context.

**Next check:** Record collection scope and access errors; follow a relevant result with a direct service, registry or ACL query.

## Host survey

**Windows PowerShell**

```powershell
.\Seatbelt.exe -group=all
```

## System checks to a file

**Windows PowerShell**

```powershell
.\Seatbelt.exe -group=system -outputfile="C:\Temp\system.txt"
```

The output directory must exist.

## If it fails

| Symptom | Check |
| --- | --- |
| A check is empty or denied while other collectors succeed | Some checks need elevation or particular APIs; a missing result can reflect permissions rather than an absent setting. |
