## GetADUsers.py: choose the operation and read the result

Commands and examples collected from your GetADUsers.py notes.

### What the result establishes

Retain username, account state and the requested attributes as candidate leads for directory enumeration.

### Prerequisites and common failures

LDAP query rights and domain selection matter; discovering a username does not validate its password or logon permissions.

### Example 1: Users

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```bash
nxc smb <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN> --users
    # Enumerate domain users

nxc ldap <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN> --users
    # Enumerate users through LDAP

GetADUsers.py -all -dc-ip <DC_IP> '<DOMAIN>/<USER>:<PASSWORD>'
    # Query AD for domain users

net rpc user info <USER> -U '<DOMAIN>/<USER>%<PASSWORD>' -S <DC_IP>
    # Show information and group memberships for a user
```
