## Enumerate domain user account information

**Run in:** Kali. **Requires:** A valid directory account and the intended domain; the password is prompted.

```bash
impacket-GetADUsers -all -dc-ip DC_IP 'DOMAIN_FQDN/USER'
```

**What the result establishes:** Retain username, account state and the requested attributes as candidate leads for directory enumeration.

**Next check:** Inspect account state and protocol-specific access; directory discovery is not credential validation.

## Users

**Notebook example**

```bash
nxc smb <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN> --users
    # Enumerate domain users

nxc ldap <DC_IP> -u <USER> -p '<PASSWORD>' -d <DOMAIN> --users
    # Enumerate users through LDAP

GetADUsers.py -all -dc-ip <DC_IP> '<DOMAIN>/<USER>:<PASSWORD>'
    # Query AD for domain users

net rpc user info <USER> -U '<DOMAIN>/<USER>%<PASSWORD>' -S <DC_IP>
    # Show information and group memberships for a user
```
