## Current operation: Enumerate domain user account information

**Run in:** Kali. **Requires:** A valid directory account and the intended domain; the password is prompted.

```bash
impacket-GetADUsers -all -dc-ip DC_IP 'DOMAIN_FQDN/USER'
```

**Read the result:** Retain username, account state and the requested attributes as candidate leads for directory enumeration.

**If A username is listed but login does not work:** LDAP query rights and domain selection matter; discovering a username does not validate its password or logon permissions.

**Next check:** Inspect account state and protocol-specific access; directory discovery is not credential validation.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
