## Run a single task action and inspect its identity

**Run in:** Kali. **Requires:** Remote scheduled-task rights and access to the task output mechanism; the password is prompted.

```bash
impacket-atexec 'DOMAIN/USER@TARGET_IP' 'whoami'
```

**What the result establishes:** A scheduled-task result proves the chosen task action ran under its actual task identity.

**Next check:** Check task action, completion and output retrieval separately; use explicit paths for a subsequent command.

## NT hash

**Kali**

```bash
impacket-atexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP' 'whoami'
```

## If it fails

| Symptom | Check |
| --- | --- |
| Task registration succeeds but no command output is returned | Remote task creation permissions and output retrieval are separate checks; interactive prompts are unsuitable for a one-command task. |
