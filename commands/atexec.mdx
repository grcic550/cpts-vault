## atexec.py: choose the operation and read the result

Run one command through Task Scheduler over SMB; requires remote task creation rights.

### What the result establishes

A scheduled-task result proves the chosen task action ran under its actual task identity.

### Prerequisites and common failures

Remote task creation permissions and output retrieval are separate checks; interactive prompts are unsuitable for a one-command task.

### Example 1: Password (prompted)

Run in: **Kali**.

```bash
impacket-atexec 'DOMAIN/USER@TARGET_IP' 'whoami'
```

### Example 2: NT hash

Run in: **Kali**.

```bash
impacket-atexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP' 'whoami'
```
