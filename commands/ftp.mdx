<Accordion title="Enumeration workflow">

### Enumeration workflow

**FTP Enumeration and File Access**

```bash
ftp <IP>                       # connect
# once logged in:
ls            # list files — but this hides dotfiles
ls -la        # ALWAYS do this — reveals hidden files like .ssh, .bash_history
pwd           # where am I
cd <dir>      # navigate
get <file>    # download one file
mget *        # download everything in the current dir
binary        # switch to binary mode before pulling non-text files (images, archives, keys)
lcd /tmp      # set the LOCAL download directory (fixes "Permission denied" on download)
put <file>    # UPLOAD a file (if you have write access — see below)
bye           # quit
```

**FTP Enumeration and File Access**

```bash
wget -r ftp://anonymous:anonymous@<IP>/        # recursively mirror the whole server
```

**FTP Enumeration and File Access**

Context from the notebook: Always  ls -la .  A directory that looks empty with  ls  often hides a  .ssh  folder with  id_rsa , or a  .bash_history  leaking commands and passwords.

```text
ls -la
```

**FTP Enumeration and File Access**

Context from the notebook: If  get  fails with "Permission denied," it's a  local  problem  — your client can't write to the current local folder. Run  lcd /tmp  first, then download.

```text
lcd /tmp
```
