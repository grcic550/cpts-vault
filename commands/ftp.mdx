## Current operation: Separate login from listing and download

**Run in:** FTP client shell. **Requires:** A reachable FTP service and a permitted account or supported anonymous login; enter interactive commands after connecting.

```bash
ftp TARGET_IP
# After login, inside ftp:
binary
ls
get REMOTE_FILE LOCAL_FILE
```

**Read the result:** Separate control-channel login from directory listing and data transfer, then inspect file ownership and permissions.

**If Login succeeds but listing or transfer hangs:** Passive/active data connections have different network requirements; a successful login with a failed listing can be a data-channel problem.

**Next check:** Check the FTP data-connection mode/path, then verify the local file size and contents before following its clues.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
