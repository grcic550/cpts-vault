## Read managed-password material available to this principal

**Run in:** Kali, in the gMSADumper checkout. **Requires:** A gMSA deployment and an identity with the required managed-password retrieval right; ordinary metadata read access is separate.

```bash
python3 gMSADumper.py -u USER -p 'PASSWORD' -d DOMAIN_FQDN -l DC_FQDN
```

**What the result establishes:** Associate any returned managed-password material with its gMSA identity and the principal permitted to retrieve it.

**Next check:** Inspect the configured reader principals and effective membership; retain the gMSA identity with any returned artifact.

## If it fails

| Symptom | Check |
| --- | --- |
| The account is found but its password blob is unavailable | Readable directory metadata is different from permission to retrieve managed-password data; inspect the relevant access configuration. |
