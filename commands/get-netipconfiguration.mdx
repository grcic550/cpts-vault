## Current operation: Record Windows interface, gateway and DNS context

**Run in:** Windows PowerShell. **Requires:** A Windows PowerShell session on the source host.

```powershell
Get-NetIPConfiguration -Detailed
```

**Read the result:** Identify the active interface, address, gateway and DNS configuration on the Windows host.

**If An adapter has no gateway or uses the wrong resolver:** A configured adapter is not necessarily the egress path; combine this with route and service-connectivity checks.

**Next check:** Identify the active interface and inspect its route and DNS resolution before choosing a pivot or changing credentials.
