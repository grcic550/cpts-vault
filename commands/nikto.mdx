## Collect web-server configuration leads

**Run in:** Kali. **Requires:** A confirmed application endpoint and an appropriate request scope/rate for the lab.

```bash
nikto -h http://HOST_FQDN/
```

**What the result establishes:** Validate individual paths, headers and server behaviors reported by the scan.

**Next check:** Replay the exact request and inspect the response; treat scanner findings as leads rather than confirmed vulnerabilities.

## Nikto

**Notebook example**

```bash
# Full scan
nikto -h <target>

# Fingerprinting only (Software Identification modules)
nikto -h <target> -Tuning b
```

## If it fails

| Symptom | Check |
| --- | --- |
| A reported issue cannot be reproduced manually | Automated findings may be false positives caused by wildcard responses, authentication or custom error pages; compare a nonexistent path. |
