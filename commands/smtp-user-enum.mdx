## Current operation: Compare SMTP username responses

**Run in:** Kali. **Requires:** SMTP reachability and a bounded username list; support for VRFY depends on the server.

```bash
smtp-user-enum -M VRFY -U users.txt -t TARGET_IP
```

**Read the result:** Treat differences between SMTP responses as enumeration leads that need manual confirmation.

**If Every candidate gets the same response:** VRFY, EXPN and RCPT behavior differs by server and anti-abuse controls; an accepted recipient may be a catch-all response.

**Next check:** Compare a known invalid identity and another supported SMTP method; do not treat uniform responses as a validated user list.
