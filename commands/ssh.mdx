## ssh: choose the operation and read the result

Open an SSH session or forward a port.

### What the result establishes

Verify the server host key, selected account and actual remote identity before interpreting shell behavior.

### Prerequisites and common failures

A valid account may be restricted to SFTP, a forced command or forwarding only; local and remote forwarding directions are easy to confuse.

# Remote (-R): make a Kali service reachable FROM the pivot side (reverse)
