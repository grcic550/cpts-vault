## Build a wordlist from the observed application

**Run in:** Kali. **Requires:** The intended application URL and a bounded crawl depth; session-only or JavaScript-rendered content may not be visible.

```bash
cewl https://HOST_FQDN/ -d 2 -m 6 --lowercase -w application-words.txt
```

**What the result establishes:** Inspect the generated wordlist for relevant words, duplicates and accidental unrelated content.

**Next check:** Check what pages were actually fetched, remove unrelated boilerplate, and use the list only for the task and rate policy you selected.

### Scrape Target-Specific Password Base Words (CeWL)

**Login Brute Forcing**

```bash
# Crawl target site to depth 2, minimum word length 5, lowercase included
cewl -d 2 -m 5 --lowercase -w cewl_words.txt http://TARGET_IP/

# Mutate base words with Hashcat best64 rules for realistic passwords (Word2024!, etc.)
hashcat --force cewl_words.txt -r /usr/share/hashcat/rules/best64.rule --stdout | sort -u > mutated_passwords.txt
```
