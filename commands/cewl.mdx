## Current operation: Build a wordlist from the observed application

**Run in:** Kali. **Requires:** The intended application URL and a bounded crawl depth; session-only or JavaScript-rendered content may not be visible.

```bash
cewl https://HOST_FQDN/ -d 2 -m 6 --lowercase -w application-words.txt
```

**Read the result:** Inspect the generated wordlist for relevant words, duplicates and accidental unrelated content.

**If The output contains only login text or generic navigation:** Crawling depth, authentication and domain boundaries affect collection; a site-derived word is only a password candidate, not a credential.

**Next check:** Check what pages were actually fetched, remove unrelated boilerplate, and use the list only for the task and rate policy you selected.
