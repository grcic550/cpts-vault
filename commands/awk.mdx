## First whitespace-separated field

**Kali**

```bash
awk '{print $1}' INPUT.txt
```

## Colon-delimited first field

**Kali**

```bash
awk -F: '{print $1}' INPUT.txt
```

## Unique nonempty lines

**Kali**

```bash
awk 'NF && !seen[$0]++' INPUT.txt > UNIQUE.txt
```

Write to a separate output file so you retain the original evidence.
