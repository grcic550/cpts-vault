## Extract account names from colon-delimited records

**Run in:** Linux target. **Requires:** Read access to a passwd-format file; this operation reads names, not password hashes.

```bash
awk -F: '{print $1}' /etc/passwd
```

**What the result establishes:** Choose the actual field separator and inspect sample records before applying a field-based extraction.

**Next check:** Inspect UID, shell and account state in the original record before treating a name as a usable identity.

## First whitespace-separated field

**Kali**

```bash
awk '{print $1}' INPUT.txt
```

## Colon-delimited first field

**Kali**

```bash
awk -F: '{print $1}' INPUT.txt
```

## Unique nonempty lines

**Kali**

```bash
awk 'NF && !seen[$0]++' INPUT.txt > UNIQUE.txt
```

Write to a separate output file so you retain the original evidence.

## If it fails

| Symptom | Check |
| --- | --- |
| An extracted service name is mistaken for an interactive login | Whitespace splitting, CSV quoting and missing fields are not interchangeable; shell quoting can change the awk program before it runs. |

### 4. Reading & filtering output (the pentest workhorses)

**Kali Terminal, tmux, zsh, and Vim**

```bash
cmd | grep foo                 # keep lines matching foo
cmd | grep -v foo              # drop lines matching foo
cmd | grep -E "80|443"         # match 80 OR 443 (regex)
cmd | awk '{print $1}'         # print 1st column
cmd | cut -d: -f1 /etc/passwd  # split on ":" take field 1
cmd | sort | uniq -c | sort -rn  # count & rank unique lines
cmd | wc -l                    # count lines
cmd | tee out.txt              # show on screen AND save to file
cmd > out.txt                  # save (overwrite)
cmd >> out.txt                 # append
cmd 2>/dev/null                # discard errors
cmd &>/dev/null                # discard everything
```

### Bypassing Weak IP Rate Limiting via Spoofed Headers

**Login Brute Forcing**

