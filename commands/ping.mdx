## ping: choose the operation and read the result

Commands and examples collected from your ping notes.

### What the result establishes

A reply establishes ICMP reachability from the current host at that moment.

### Prerequisites and common failures

No reply can reflect filtering, routing or rate limits; it is not proof that a TCP service is unavailable.

### 6. Networking / pentest quick commands

**Kali Terminal, tmux, zsh, and Vim**

```bash
ip a                # show interfaces & IPs (replaces ifconfig)
ip a show tun0      # just the VPN interface (HTB/CPTS uses tun0)
ip route            # routing table
ss -tulpn           # listening ports (replaces netstat)
ping -c 4 10.10.10.10
curl -s http://target/ | less       # fetch a page
curl -I http://target/               # headers only
wget http://target/file              # download a file
nc -lvnp 4444       # netcat listener (catch reverse shells)
python3 -m http.server 80            # quick web server to transfer files
```

### Fingerprinting

**Shells, Payloads, and Interactive TTYs**

```bash

# Nmap OS detection
sudo nmap -v -O <target_ip>

sudo nmap -v <target_ip> --script banner.nse

# Full enumeration
nmap -v -A <target_ip>
```
