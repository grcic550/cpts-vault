## Check ICMP reachability from the current host

**Run in:** Linux shell. **Requires:** A Linux shell and the intended destination; Windows uses different count syntax.

```bash
ping -c 2 TARGET_IP
```

**What the result establishes:** A reply establishes ICMP reachability from the current host at that moment.

**Next check:** Use protocol-specific checks for the service; record where ICMP is filtered rather than abandoning the target.

## 10. Test domain-controller connectivity

**Notebook example**

```bash
ping -c 2 DC_IP
```

Saved as written; may include lab values or terminal output.

## If it fails

| Symptom | Check |
| --- | --- |
| ICMP fails while a TCP service is reachable | No reply can reflect filtering, routing or rate limits; it is not proof that a TCP service is unavailable. |
