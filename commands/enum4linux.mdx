## Collect SMB and RPC enumeration with enum4linux-ng

**Run in:** Kali. **Requires:** The enum4linux-ng implementation, reachable SMB/RPC and a lab target; this first pass uses its unauthenticated behavior.

```bash
enum4linux-ng -A TARGET_IP
```

**What the result establishes:** Read individual SMB/RPC findings and their authentication context instead of treating a tool summary as one success or failure.

**Next check:** Repeat only relevant checks with known credentials, and confirm important results with the corresponding SMB or RPC client.

## If it fails

| Symptom | Check |
| --- | --- |
| Anonymous checks fail or return partial domain details | Legacy enum4linux and enum4linux-ng differ; a partially populated report may reflect protocol restrictions, missing dependencies or denied calls. |

### Decide what to do next

**Active Directory Enumeration: Quick Reference**

```bash
# From Linux, unauthenticated / low-priv
nxc smb $DC -u '' -p ''                       # null session
enum4linux-ng -A $DC
rpcclient -U '' -N $DC -c enumdomusers
# Authenticated sweep
nxc smb $DC -u USER -p PASS --users --groups --shares --pass-pol
nxc ldap $DC -u USER -p PASS --bloodhound -c all --dns-server $DC
```
