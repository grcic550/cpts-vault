## enum4linux-ng: choose the operation and read the result

Enumerate SMB and RPC information.

### What the result establishes

Read individual SMB/RPC findings and their authentication context instead of treating a tool summary as one success or failure.

### Prerequisites and common failures

Legacy enum4linux and enum4linux-ng differ; a partially populated report may reflect protocol restrictions, missing dependencies or denied calls.

### Example 1: Commands

Run in: **Kali**.

```bash
enum4linux-ng -A TARGET_IP
```
