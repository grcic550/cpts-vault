## Test one FTP account against a bounded candidate list

**Run in:** Kali. **Requires:** FTP reachability, a known username and a permitted candidate/rate policy; the file contains password candidates.

```bash
medusa -u USER -P candidates.txt -h TARGET_IP -M ftp
```

**What the result establishes:** Separate connection errors, authentication failures and a verified successful account/service combination.

**Next check:** Confirm the protocol and one known control request before interpreting the candidate results.
