## Connect and identify the current database account

**Run in:** Kali, then the MySQL prompt. **Requires:** Reachable MySQL/MariaDB and a valid database account; enter the SQL statements inside its prompt.

```bash
mysql -h TARGET_IP -u USER -p
# In the MySQL prompt:
SELECT USER(), CURRENT_USER();
SHOW DATABASES;
```

**What the result establishes:** Identify version, current database, effective user and grants before selecting schemas, tables and columns.

**Next check:** Inspect accessible schemas and object grants; database access does not establish filesystem or OS privileges.

## Commands

**Kali / MySQL prompt**


## If it fails

| Symptom | Check |
| --- | --- |
| Login works but a database is absent or denied | SQL access, FILE privilege, server filesystem access and OS execution are separate capabilities; avoid assuming a remote DB shares the web host's filesystem. |

<Accordion title="Mental Model — &quot;What Do I Use When?&quot;">

### Mental Model — "What Do I Use When?"

**Ports, Protocols, and Services by Purpose**

```text
"I found an open port"
├── Is it a file share?    → SMB (445), NFS (2049), FTP (21)
├── Is it remote access?   → SSH (22), RDP (3389), WinRM (5985)
├── Is it a web server?    → HTTP (80/443) → fingerprint → fuzz
├── Is it email?           → SMTP (25), IMAP (143), POP3 (110)
├── Is it a database?      → MySQL (3306), MSSQL (1433), Oracle (1521)
├── Is it monitoring?      → SNMP (161), IPMI (623)
└── Not sure?              → nmap -sV -sC <IP> -p <port>

"I need to get files off the target"
├── Linux → scp/sftp (22)
├── Windows → SMB (445) or evil-winrm download
├── Web → wget/curl
└── Simple → python3 -m http.server (on target)

"I need to get files onto the target"
├── Linux → scp/sftp (22) or wget from attacker
├── Windows → SMB, certutil, PowerShell wget
├── Web upload → if upload form exists
└── Simple → python3 -m http.server (on attacker)

"I need a shell"
├── Linux → SSH (22)
├── Windows → Evil-WinRM (5985), PsExec (445), RDP (3389)
└── Either → reverse shell via exploit
```
