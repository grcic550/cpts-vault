**Requires:** Run a compatible SharpHound collector from a domain-authenticated Windows session with DC connectivity; upload its ZIP to the matching BloodHound instance.

## Commands

**Windows PowerShell**

```powershell
.\SharpHound.exe -c All --zipfilename COLLECTION
```

Transfer the output ZIP to Kali and upload it with BloodHound Quick Upload. Run as your domain account; host collection needs additional reachability/permissions.
