## Collect directory and host relationships from Windows

**Run in:** Windows PowerShell. **Requires:** A collector matching the BloodHound server, a domain-authenticated session and access to the requested services.

```powershell
.\SharpHound.exe -c All --zipfilename COLLECTION.zip
```

**What the result establishes:** Confirm the output location, collection scope and collection errors before judging the resulting graph.

**Next check:** Inspect collection errors and object coverage before importing; treat absent edges as uncollected until their source was checked.

## Commands

**Windows PowerShell**

```powershell
.\SharpHound.exe -c All --zipfilename COLLECTION
```

Transfer the output ZIP to Kali and upload it with BloodHound Quick Upload. Run as your domain account; host collection needs additional reachability/permissions.

## If it fails

| Symptom | Check |
| --- | --- |
| Some collection methods fail while the archive is still produced | The executable must match the server's supported collector generation; missing sessions or local groups can reflect collection permissions. |
