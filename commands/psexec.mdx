**Requires:** Valid administrator credentials, SMB access, and writable admin shares/service creation rights on the Windows host.

## Verify remote service execution identity

**Run in:** Kali. **Requires:** A credential accepted by the target, SMB access and rights to write the administrative share and create a service.

```bash
impacket-psexec 'DOMAIN/USER@TARGET_IP' whoami
```

**What the result establishes:** The returned identity belongs to a service-created process on the remote host; verify it with whoami before using local paths or privileges.

**Next check:** Check administrative-share and service-control access separately; record the returned identity before choosing any privileged action.

## Password (prompted)

**Kali**

```bash
impacket-psexec 'DOMAIN/USER@TARGET_IP'
```

## NT hash

**Kali**

```bash
impacket-psexec -hashes ':NT_HASH' 'DOMAIN/USER@TARGET_IP'
```

## If it fails

| Symptom | Check |
| --- | --- |
| Authentication succeeds but service creation or output fails | A valid login is insufficient: service creation, writable administrative shares, SMB connectivity and endpoint policy all affect this method. |

### Mental Model — "What Do I Use When?"

**Ports, Protocols, and Services by Purpose**

```text
"I found an open port"
├── Is it a file share?    → SMB (445), NFS (2049), FTP (21)
├── Is it remote access?   → SSH (22), RDP (3389), WinRM (5985)
├── Is it a web server?    → HTTP (80/443) → fingerprint → fuzz
├── Is it email?           → SMTP (25), IMAP (143), POP3 (110)
├── Is it a database?      → MySQL (3306), MSSQL (1433), Oracle (1521)
├── Is it monitoring?      → SNMP (161), IPMI (623)
└── Not sure?              → nmap -sV -sC <IP> -p <port>

"I need to get files off the target"
├── Linux → scp/sftp (22)
├── Windows → SMB (445) or evil-winrm download
├── Web → wget/curl
└── Simple → python3 -m http.server (on target)

"I need to get files onto the target"
├── Linux → scp/sftp (22) or wget from attacker
├── Windows → SMB, certutil, PowerShell wget
├── Web upload → if upload form exists
└── Simple → python3 -m http.server (on attacker)

"I need a shell"
├── Linux → SSH (22)
├── Windows → Evil-WinRM (5985), PsExec (445), RDP (3389)
└── Either → reverse shell via exploit
```
