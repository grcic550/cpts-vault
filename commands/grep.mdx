## Search a bounded application directory with source lines

**Run in:** Linux target. **Requires:** A real readable application directory; -I skips binary files and permission errors may leave gaps.

```bash
grep -RniI -- 'password' /opt/APP
```

**What the result establishes:** Retain filenames and line numbers so each match can be checked in context.

**Next check:** Inspect surrounding configuration and identify the service/account using it before testing a candidate secret.

## Commands

**Linux target**

```bash
grep -ri "password" /etc 2>/dev/null
grep -n "PATTERN" file.txt
```

## If it fails

| Symptom | Check |
| --- | --- |
| Matches are placeholders, comments or stale settings | Regex and literal searches differ; quoting, binary files and recursive scope can produce missing or misleading matches. |
