## Current operation: Inventory readable files in a named domain

**Run in:** Windows PowerShell. **Requires:** A Windows domain context with share visibility, a writable output path and the intended collection scope.

```powershell
.\Snaffler.exe -s -d DOMAIN_FQDN -o snaffler.log -v data
```

**Read the result:** Prioritize readable files by their share, path, owner and match context, then verify selected findings manually.

**Next check:** Return to the specific readable share/path and verify the content, identity and permission before treating a match as actionable.
