## kinit: choose the operation and read the result

Obtain a native Kerberos ticket and inspect the resulting cache.

### What the result establishes

Confirm the requested principal/realm and the resulting credential cache before using a Kerberos-aware client.

### Prerequisites and common failures

Realm/KDC configuration, DNS and clock agreement matter; successful TGT acquisition does not authorize every service.

Reachable KDC, correct realm, working name resolution and matching time.

### Example 1: Password prompt

Run in: **Kali**. Use your actual Kerberos realm, commonly uppercase. Native Kerberos needs appropriate realm/KDC discovery or configuration.

```bash
kinit USER@REALM
klist
```
