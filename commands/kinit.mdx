## Acquire a Kerberos TGT in the selected realm

**Run in:** Kali with MIT Kerberos. **Requires:** A configured realm/KDC, correct time and a supported credential; the password is prompted.

```bash
kinit USER@REALM
klist
```

**What the result establishes:** Confirm the requested principal/realm and the resulting credential cache before using a Kerberos-aware client.

**Next check:** Separate KDC discovery from credential failure, then inspect principal/expiry before using the cache with a service client.

## If it fails

| Symptom | Check |
| --- | --- |
| The realm cannot be contacted or preauthentication fails | Realm/KDC configuration, DNS and clock agreement matter; successful TGT acquisition does not authorize every service. |
