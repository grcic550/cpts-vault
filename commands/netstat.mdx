## Connections and PIDs

**Windows — cmd.exe**

```cmd
netstat -ano
```

TCP LISTENING identifies a listener; UDP has no equivalent state column.

## TCP listeners

**Windows — cmd.exe**

```cmd
netstat -ano -p tcp | findstr LISTENING
```

LISTENING is the English output label. Inspect unfiltered output on other language installations.

## If it fails

| Symptom | Check |
| --- | --- |
| A port is listening but remote access fails | Check its bind address, firewall and routing. A listener on 127.0.0.1 is local-only. |
