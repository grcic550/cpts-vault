## cmdkey: choose the operation and read the result

List saved Windows credential entries. Listing does not display their passwords.

### What the result establishes

A listed target identifies a saved-credential entry and its scope.

### Prerequisites and common failures

Listing entries does not reveal their password, and reuse is constrained by target matching and the current user context.

### Example 1: List entries

Run in: **Windows cmd.exe or PowerShell**.

```text
cmdkey /list
```

### PHASE B — PrivEsc enumeration

**Windows Post-Exploitation: Field Reference**

```cmd
:: Unquoted service paths (space in path + no quotes = hijack)
wmic service get name,displayname,pathname,startmode | findstr /i "auto" | findstr /iv "c:\windows\\" | findstr /iv """
:: AlwaysInstallElevated (any .msi runs as SYSTEM if both keys = 1)
```
