## List stored Windows credential targets

**Run in:** Windows cmd.exe. **Requires:** The Windows user context whose Credential Manager entries you want to inspect.

```console
cmdkey /list
```

**What the result establishes:** A listed target identifies a saved-credential entry and its scope.

**Next check:** Match the target name, credential type and consuming application; the listing does not reveal the password.

## If it fails

| Symptom | Check |
| --- | --- |
| An entry exists but the proposed login does not use it | Listing entries does not reveal their password, and reuse is constrained by target matching and the current user context. |
