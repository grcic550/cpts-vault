## Test one parameter in a captured request

**Run in:** Kali. **Requires:** A saved HTTP request that works unchanged, a selected parameter and valid session/CSRF handling.

```bash
sqlmap -r request.txt -p PARAMETER --batch
```

**What the result establishes:** Preserve a valid authenticated request and select the input before interpreting confirmed technique and DBMS evidence.

**Next check:** Repair the request baseline before interpreting injection results; confirm reported technique and DBMS before selecting enumeration options.

## Commands

**Kali**

```bash
sqlmap -r request.txt --batch
sqlmap -r request.txt --dbs
sqlmap -r request.txt -D DATABASE --tables
```

## If it fails

| Symptom | Check |
| --- | --- |
| The replay is redirected to login or responses vary unpredictably | An expired session or CSRF failure cannot be repaired by increasing level/risk; database access and OS execution remain separate outcomes. |
