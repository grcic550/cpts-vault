## Collect domain-controller data for BloodHound CE

**Run in:** Kali. **Requires:** A CE-compatible collector, domain credentials and correct domain DNS/DC hostname; provide the prompted credential.

```bash
bloodhound-ce-python -u USER -d DOMAIN_FQDN -ns DC_IP -dc DC_FQDN -c DCOnly --zip
```

**What the result establishes:** A collection ZIP is the artifact to import; check that its generation matches the BloodHound server and that expected objects appear.

**Next check:** DCOnly does not collect those host details; choose additional methods only when their host connectivity and permission requirements are met.

## Commands

**Kali**

```bash
bloodhound-ce-python -u 'USER' -d 'DOMAIN' -ns DC_IP -dc DC_FQDN -c DCOnly --zip
# Include host data when required and reachable
bloodhound-ce-python -u 'USER' -d 'DOMAIN' -ns DC_IP -dc DC_FQDN -c All --zip
```

Upload the output ZIP to BloodHound CE. DC_FQDN is a hostname; DC_IP is an IP address.

## If it fails

| Symptom | Check |
| --- | --- |
| The ZIP imports but sessions or local groups are absent | DCOnly omits host-derived detail; All can require additional reachability and permissions. DNS resolution and a DC hostname are distinct from its IP. |
