## Commands

**Kali**

```bash
bloodhound-ce-python -u 'USER' -d 'DOMAIN' -ns DC_IP -dc DC_FQDN -c DCOnly --zip
# Include host data when required and reachable
bloodhound-ce-python -u 'USER' -d 'DOMAIN' -ns DC_IP -dc DC_FQDN -c All --zip
```

Upload the output ZIP to BloodHound CE. DC_FQDN is a hostname; DC_IP is an IP address.
