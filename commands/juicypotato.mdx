## Run a bounded JuicyPotatoNG identity test

**Run in:** Windows cmd.exe. **Requires:** The NG implementation specifically, its required token privileges and a compatible COM/Windows environment; classic JuicyPotato options differ.

```console
JuicyPotatoNG.exe -t * -p "C:\Windows\System32\cmd.exe" -a "/c whoami"
```

**What the result establishes:** Check impersonation rights, OS/build compatibility and the selected COM/CLSID context before using the retained lab recipe.

**Next check:** Check the chosen build and privilege/error details; do not infer compatibility from the shared Potato name or use broad CLSID brute force as a default.
