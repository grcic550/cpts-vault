## Parse an offline SAM and SYSTEM pair

**Run in:** Kali. **Requires:** Matching SAM and SYSTEM hives already obtained in the lab; these are local files, not remote targets.

```bash
impacket-secretsdump -sam sam.save -system system.save LOCAL
```

**What the result establishes:** Distinguish local SAM/LSA extraction, an offline hive operation and directory replication; record exactly which artifact was returned.

**Next check:** Verify acquisition and file pairing; label returned material as local account hashes rather than domain replication results.

## Commands

**Kali**

```bash
impacket-secretsdump -sam sam.save -system system.save LOCAL
# DCSync: requires directory replication rights
impacket-secretsdump -just-dc 'DOMAIN/USER:PASSWORD@DC_IP'
```

## If it fails

| Symptom | Check |
| --- | --- |
| Parsing fails or the files do not correspond to the same machine | Local administrator rights do not automatically grant DCSync rights, and an NT hash is not a captured NetNTLM challenge/response. |
