**Windows — cmd.exe**

```cmd

```

## Inspect a directory

**Windows — cmd.exe**

```cmd
icacls "C:\PATH\DIRECTORY"
```

F = full control, M = modify, RX = read/execute, W = write, (I) = inherited. Evaluate the current user and group memberships too.
