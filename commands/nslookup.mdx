## Locate domain Kerberos service records

**Run in:** Kali or Windows command prompt. **Requires:** Domain DNS name and an appropriate internal resolver.

```bash
nslookup -type=SRV _kerberos._tcp.DOMAIN_FQDN DC_IP
```

**What the result establishes:** Confirm the selected DNS server and whether you asked for an address, reverse lookup or another record type.

**Next check:** Resolve the returned service hostnames and confirm reachability rather than treating the DNS response as authentication.

## Commands

**Kali**

```bash
nslookup MS01.DOMAIN DC_IP
nslookup -type=SRV _kerberos._tcp.DOMAIN DC_IP
```

## If it fails

| Symptom | Check |
| --- | --- |
| No SRV records or an unexpected DNS server | The default resolver may be inappropriate for the lab domain; an external DNS answer does not describe an internal AD zone. |
