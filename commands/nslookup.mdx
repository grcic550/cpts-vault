## nslookup: choose the operation and read the result

Resolve a hostname using DNS.

### What the result establishes

Confirm the selected DNS server and whether you asked for an address, reverse lookup or another record type.

### Prerequisites and common failures

The default resolver may be inappropriate for the lab domain; an external DNS answer does not describe an internal AD zone.

### Example 1: Commands

Run in: **Kali**.

```bash
nslookup MS01.DOMAIN DC_IP
nslookup -type=SRV _kerberos._tcp.DOMAIN DC_IP
```

### Example 2: DNS and Active Directory

Run in: **Saved lab example**.

```bash
dig SRV _ldap._tcp.dc._msdcs.<domain> @<IP>        # locate domain controllers
nslookup -type=SRV _kerberos._tcp.<domain> <IP>    # locate the KDC (Kerberos)
```
