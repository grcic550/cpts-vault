## Get-FileHash: choose the operation and read the result

Verify that a transferred file matches the original.

### What the result establishes

Compare the same algorithm over the actual source and destination bytes.

### Prerequisites and common failures

Matching filenames or sizes are weaker checks; an algorithm mismatch or modified line endings can explain different digests.

### Example 1: Commands

Run in: **Windows PowerShell**.

```powershell
Get-FileHash C:\Users\Public\file.zip -Algorithm SHA256
```
