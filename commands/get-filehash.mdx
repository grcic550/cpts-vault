## Compare a transferred file's SHA-256

**Run in:** Windows PowerShell. **Requires:** Read access to the received file and a digest from the original bytes.

```powershell
Get-FileHash -Path 'C:\Users\Public\file.bin' -Algorithm SHA256
```

**What the result establishes:** Compare the same algorithm over the actual source and destination bytes.

**Next check:** Check the source version, transfer completeness and accidental text conversion; filename equality is not content equality.

## Commands

**Windows PowerShell**

```powershell
Get-FileHash C:\Users\Public\file.zip -Algorithm SHA256
```

## If it fails

| Symptom | Check |
| --- | --- |
| Hashes differ despite matching filenames | Matching filenames or sizes are weaker checks; an algorithm mismatch or modified line endings can explain different digests. |
