## Current operation: List registered RPC interfaces

**Run in:** Kali. **Requires:** A reachable endpoint mapper; access restrictions can limit returned endpoints.

```bash
impacket-rpcdump @TARGET_IP
```

**Read the result:** Read interface UUIDs and endpoint bindings as evidence of exposed RPC services.

**If The endpoint mapper responds but a later RPC call fails:** An advertised endpoint does not prove an exploitable method or adequate caller permissions; dynamic RPC ports must also be reachable.
