## List registered RPC interfaces

**Run in:** Kali. **Requires:** A reachable endpoint mapper; access restrictions can limit returned endpoints.

```bash
impacket-rpcdump @TARGET_IP
```

**What the result establishes:** Read interface UUIDs and endpoint bindings as evidence of exposed RPC services.

**Next check:** Use the interface UUID and endpoint as a lead; separately verify dynamic-port reachability and operation permissions.

## Enumerating for MS-RPRN

**Notebook example**

```shellsession
grcic550@htb[/htb]$ rpcdump.py @172.16.5.5 | egrep 'MS-RPRN|MS-PAR'

Protocol: [MS-PAR]: Print System Asynchronous Remote Protocol
Protocol: [MS-RPRN]: Print System Remote Protocol
```
