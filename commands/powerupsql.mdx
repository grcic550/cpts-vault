## Read SQL instance identity with an integrated session

**Run in:** Windows PowerShell. **Requires:** PowerUpSQL and a Windows identity permitted to authenticate to the selected SQL instance.

```powershell
Import-Module .\PowerUpSQL.ps1
Get-SQLQuery -Instance 'HOST_FQDN,1433' -Query 'SELECT SYSTEM_USER, DB_NAME();'
```

**What the result establishes:** Establish SQL instance discovery, login context, roles and impersonation/linked-server relationships as separate findings.

**Next check:** Establish the accepted SQL/Windows login context, then inspect roles and object permissions before following linked-server or impersonation leads.

## If it fails

| Symptom | Check |
| --- | --- |
| The instance is discoverable but the query cannot authenticate | A reachable instance or database login does not imply sysadmin; actions that change server configuration need a verified prerequisite. |
