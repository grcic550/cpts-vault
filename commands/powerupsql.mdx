## PowerUpSQL: choose the operation and read the result

Commands and examples collected from your PowerUpSQL notes.

### What the result establishes

Establish SQL instance discovery, login context, roles and impersonation/linked-server relationships as separate findings.

### Prerequisites and common failures

A reachable instance or database login does not imply sysadmin; actions that change server configuration need a verified prerequisite.

### Example 1: Enumerating MSSQL Instances with PowerUpSQL

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```powershell
PS C:\htb>  Get-SQLQuery -Verbose -Instance "172.16.5.150,1433" -username "inlanefreight\damundsen" -password "SQL1234!" -query 'Select @@version'

VERBOSE: 172.16.5.150,1433 : Connection Success.

Column1
-------
Microsoft SQL Server 2017 (RTM) - 14.0.1000.169 (X64) ...
```
