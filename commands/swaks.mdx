## Check SMTP recipient acceptance without sending a body

**Run in:** Kali. **Requires:** A lab SMTP endpoint and test addresses you are allowed to check.

```bash
swaks --server TARGET_IP --from sender@LAB_DOMAIN --to recipient@LAB_DOMAIN --quit-after RCPT
```

**What the result establishes:** Read the SMTP dialogue stage by stage: connection, EHLO, TLS, authentication, sender, recipient and message acceptance.

**Next check:** Record the SMTP status and relay context; RCPT acceptance alone does not prove final delivery or inbox access.

## If it fails

| Symptom | Check |
| --- | --- |
| RCPT is rejected or accepted without message delivery | Recipient acceptance is not proof of mailbox delivery; server policy can reject or reroute a message after an earlier successful command. |
