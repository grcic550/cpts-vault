## Map Linux listeners and owning processes

**Run in:** Linux shell. **Requires:** A shell on the host being inspected; process details may require additional permission.

```bash
ss -lntup
```

**What the result establishes:** Distinguish listeners and established sockets, then correlate visible process information.

**Next check:** Keep the listener evidence, inspect permitted process details and test the endpoint from its actual source network.

## TCP and UDP listeners

**Kali / Linux**

```bash
ss -tulpn
```

-t TCP, -u UDP, -l listening, -p processes, -n numeric addresses.

## Established TCP connections

**Kali / Linux**

```bash
ss -tpn state established
```

## If it fails

| Symptom | Check |
| --- | --- |
| Socket rows appear without process names | Process details may require additional rights; a socket bound to loopback or a specific namespace has limited reachability. |
| Process name is missing | You may lack permission to inspect another user’s process. Re-run with sudo only when that access is available. |
