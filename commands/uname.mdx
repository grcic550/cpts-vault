## Record kernel release and machine architecture

**Run in:** Linux target. **Requires:** A Linux command session; container output may describe the shared host kernel.

```bash
uname -a
uname -m
```

**What the result establishes:** Use kernel, architecture and system information to guide compatible tools and further host inspection.

**Next check:** Check distribution patches, configuration and vulnerable subsystem availability before drawing a conclusion from the version string.

| Symptom | Check |
