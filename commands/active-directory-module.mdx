## Establish the domain naming and DC context

**Run in:** Windows PowerShell. **Requires:** RSAT/ActiveDirectory module availability and a domain authentication/network context.

```powershell
Import-Module ActiveDirectory
Get-ADDomain
Get-ADDomainController -Discover
```

**What the result establishes:** Use object properties and distinguished names to connect users, groups, computers and policy; request non-default attributes explicitly.

**Next check:** Check server selection, DNS and authentication; use the observed naming context for subsequent object queries.
