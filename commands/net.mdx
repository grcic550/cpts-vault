## Inspect the domain password policy

**Run in:** Windows cmd.exe. **Requires:** A domain-aware Windows session and connectivity to the domain; this is a domain query, not a local one.

```console
net accounts /domain
```

**What the result establishes:** Separate local machine queries from /domain queries and inspect the resulting account/group context.

**Next check:** Keep the scope of the returned policy; establish account-specific effective limits before choosing any authentication test.

## Commands

**Windows cmd.exe**

```bash
net user /domain
net user USER /domain
net group "Domain Admins" /domain
net accounts /domain
```

## If it fails

| Symptom | Check |
| --- | --- |
| The policy query fails or a fine-grained policy applies to an account | Display names can be localized, and a command's successful query does not establish rights to modify the returned objects. |
