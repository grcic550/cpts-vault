## net.exe: choose the operation and read the result

Query Windows users, groups and account policy.

### What the result establishes

Separate local machine queries from /domain queries and inspect the resulting account/group context.

### Prerequisites and common failures

Display names can be localized, and a command's successful query does not establish rights to modify the returned objects.
