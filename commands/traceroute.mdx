## traceroute: choose the operation and read the result

Commands and examples collected from your traceroute notes.

### What the result establishes

Use returned hops and latency to investigate the path from the current network position.

### Prerequisites and common failures

Intermediate routers may suppress replies; missing hops do not necessarily indicate where application traffic is blocked.

### Example 1: Service & version detection (-sV) and OS detection (-O)

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```bash
sudo nmap -sV <target>             # probe each open port for product + version
sudo nmap -O <target>              # guess OS from TCP/IP stack fingerprint
sudo nmap -A <target>              # aggressive: -sV + -O + default scripts + traceroute
```
