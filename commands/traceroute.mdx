## Current operation: Inspect the path visible to Linux probes

**Run in:** Linux shell. **Requires:** The traceroute utility and a route from this host; intermediate responses depend on filtering.

```bash
traceroute -n TARGET_IP
```

**Read the result:** Use returned hops and latency to investigate the path from the current network position.

**If Some hops show asterisks:** Intermediate routers may suppress replies; missing hops do not necessarily indicate where application traffic is blocked.

**Next check:** Compare the selected local route and destination service reachability; missing hop replies are not proof of a broken end-to-end path.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
