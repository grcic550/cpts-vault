## Inspect the path visible to Linux probes

**Run in:** Linux shell. **Requires:** The traceroute utility and a route from this host; intermediate responses depend on filtering.

```bash
traceroute -n TARGET_IP
```

**What the result establishes:** Use returned hops and latency to investigate the path from the current network position.

**Next check:** Compare the selected local route and destination service reachability; missing hop replies are not proof of a broken end-to-end path.

## Service & version detection (-sV) and OS detection (-O)

**Notebook example**

```bash
sudo nmap -sV <target>             # probe each open port for product + version
sudo nmap -O <target>              # guess OS from TCP/IP stack fingerprint
sudo nmap -A <target>              # aggressive: -sV + -O + default scripts + traceroute
```
