## Collect passive hostname candidates

**Run in:** Kali. **Requires:** A target domain and working data providers; some providers require configured API keys.

```bash
subfinder -d DOMAIN_FQDN -silent -o subdomains.txt
```

**What the result establishes:** Resolve discovered names and associate them with the authorized domain before testing services.

**Next check:** Record which sources ran, resolve candidate names separately, and confirm which discovered applications are in scope.

## If it fails

| Symptom | Check |
| --- | --- |
| Sources return no data or rate-limit requests | Passive results can be stale, wildcarded or owned by a different service operator; a name alone proves neither reachability nor scope. |
