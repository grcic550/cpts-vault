## Get-LocalUser: choose the operation and read the result

Commands and examples collected from your Get-LocalUser notes.

### What the result establishes

Distinguish local account state and identifiers from similarly named domain accounts.

### Prerequisites and common failures

Local-user enumeration is not domain enumeration; enabled status does not establish a valid password or remote logon right.

### Example 1: User Enumeration

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```powershell
net localgroup
Get-LocalGroup | ft Name
```
