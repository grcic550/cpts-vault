## Current operation: Check username validity against a chosen realm

**Run in:** Kali. **Requires:** A correct Kerberos realm/DC and a bounded username list; this mode is distinct from password testing.

```bash
kerbrute userenum -d DOMAIN_FQDN --dc DC_IP users.txt
```

**Read the result:** Distinguish a username-validity response from a successful password authentication result.

**If Unknown-principal, preauthentication and network responses differ:** Username enumeration and password guessing are different modes; account lockout behavior and the selected realm/DC must be understood before credential attempts.

**Next check:** Keep candidate identities with their response type; do not record a username-validity result as a working password.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
