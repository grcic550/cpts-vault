## Check username validity against a chosen realm

**Run in:** Kali. **Requires:** A correct Kerberos realm/DC and a bounded username list; this mode is distinct from password testing.

```bash
kerbrute userenum -d DOMAIN_FQDN --dc DC_IP users.txt
```

**What the result establishes:** Distinguish a username-validity response from a successful password authentication result.

**Next check:** Keep candidate identities with their response type; do not record a username-validity result as a working password.

## Commands

**Kali**

```bash
kerbrute userenum -d DOMAIN --dc DC_IP users.txt
```

## If it fails

| Symptom | Check |
| --- | --- |
| Unknown-principal, preauthentication and network responses differ | Username enumeration and password guessing are different modes; account lockout behavior and the selected realm/DC must be understood before credential attempts. |
