## Current operation: Inspect accessible legacy LAPS computer records

**Run in:** Windows PowerShell. **Requires:** The LAPSToolkit module and its dependencies, directory connectivity and a legacy Microsoft LAPS deployment.

```powershell
Import-Module .\LAPSToolkit.ps1
Get-LAPSComputers
```

**Read the result:** Match the managed local administrator credential to the specific computer and its expiration information.

**If Computer records are visible but password attributes are not:** Legacy Microsoft LAPS and Windows LAPS store different attributes and use different access protections; inspect which deployment exists.

**Next check:** Check delegated read rights and expiration on the specific host; use Windows LAPS tooling for the newer schema and encryption model.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
