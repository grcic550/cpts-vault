## Inspect accessible legacy LAPS computer records

**Run in:** Windows PowerShell. **Requires:** The LAPSToolkit module and its dependencies, directory connectivity and a legacy Microsoft LAPS deployment.

```powershell
Import-Module .\LAPSToolkit.ps1
Get-LAPSComputers
```

**What the result establishes:** Match the managed local administrator credential to the specific computer and its expiration information.

**Next check:** Check delegated read rights and expiration on the specific host; use Windows LAPS tooling for the newer schema and encryption model.

## If it fails

| Symptom | Check |
| --- | --- |
| Computer records are visible but password attributes are not | Legacy Microsoft LAPS and Windows LAPS store different attributes and use different access protections; inspect which deployment exists. |
