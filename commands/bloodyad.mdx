**Requires:** Domain credentials and LDAP connectivity to the DC. For Kerberos, use the options supported by your installed version.

## Read an object

**Kali**

```bash
bloodyAD --host DC_FQDN -d DOMAIN_FQDN -u USER -p 'PASSWORD' get object TARGET_OBJECT
```

## Find writable objects

**Kali**

```bash
bloodyAD --host DC_FQDN -d DOMAIN_FQDN -u USER -p 'PASSWORD' get writable
```

A writable attribute or object is a specific permission, not automatic domain administrator access.

## Inspect memberships

**Kali**

```bash
bloodyAD --host DC_FQDN -d DOMAIN_FQDN -u USER -p 'PASSWORD' get membership USER
```
