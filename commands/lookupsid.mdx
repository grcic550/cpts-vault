## Resolve domain identity names through SID lookups

**Run in:** Kali. **Requires:** RPC/SMB reachability and an identity accepted for the lookup; the password is prompted.

```bash
impacket-lookupsid 'DOMAIN/USER@TARGET_IP'
```

**What the result establishes:** Keep the domain SID and RID-derived object names together when building a user/group map.

**Next check:** Record the domain SID and returned names, then use directory queries to verify account state and memberships.

## Commands

**Kali**

```bash
impacket-lookupsid 'DOMAIN/USER@DC_IP'
```

## If it fails

| Symptom | Check |
| --- | --- |
| Only part of the RID space resolves | A SID lookup result is an identity lead, not a verified password or a complete membership graph; RPC policy may limit enumeration. |
