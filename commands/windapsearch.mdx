## List directory users with the Python implementation

**Run in:** Kali. **Requires:** The ropnop Python implementation and directory access; its options differ from Go implementations.

```bash
python3 windapsearch.py --dc-ip DC_IP -u USER@DOMAIN_FQDN -p 'PASSWORD' -U
```

**What the result establishes:** Use returned users, groups or computers to answer a defined directory question and retain the query context.

**Next check:** Check this implementation's help, then validate the bind and search base before interpreting the results.

## Commands

**Kali**

```bash
python3 windapsearch.py --dc-ip DC_IP -u USER@DOMAIN -p 'PASSWORD' --da
```

| Symptom | Check |
