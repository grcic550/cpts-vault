## windapsearch: choose the operation and read the result

Enumerate AD objects through LDAP.

### What the result establishes

Use returned users, groups or computers to answer a defined directory question and retain the query context.

### Prerequisites and common failures

Different implementations expose different flags; authentication and search-base errors can produce empty output without proving the objects are absent.

Run in: **Kali**.

