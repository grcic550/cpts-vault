## Inspect available and loaded PowerShell modules

**Run in:** Windows PowerShell. **Requires:** A PowerShell session with access to its module search paths.

```powershell
Get-Module
Get-Module -ListAvailable
```

**What the result establishes:** Confirm available modules and exported commands before using module-specific examples.

**Next check:** Inspect the script's module/function definitions, load the intended local file, and check Get-Command before invoking a function from an unrelated implementation.
