**Requires:** The ActiveDirectory PowerShell module and connectivity/authentication to AD. For DNS alone, use Resolve-DnsName.

## Resolve one computer object

**Windows PowerShell**

```powershell
Import-Module ActiveDirectory
Get-ADComputer -Identity MS01 -Properties DNSHostName,IPv4Address | Select-Object Name,DNSHostName,IPv4Address
```

## List computer names

**Windows PowerShell**

```powershell
Get-ADComputer -Filter * -Properties DNSHostName | Select-Object Name,DNSHostName
```
