## Current operation: Find configuration files in a specific application directory

**Run in:** Windows PowerShell. **Requires:** A real application directory and sufficient read/list permissions; retain access errors instead of assuming complete coverage.

```powershell
Get-ChildItem -Path 'C:\APP' -Recurse -File -Include *.config,*.xml,*.ini -Force
```

**Read the result:** Use path, recursion, file attributes and access errors to understand what the current identity can enumerate.

**If Some directories are denied or no matching files appear:** A directory listing can omit protected paths; recursive traversal and reparse points can broaden scope unexpectedly.

**Next check:** Check the chosen path and extension filter, then inspect relevant readable files and their ACLs without treating a recursive search as exhaustive.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
