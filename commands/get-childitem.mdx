## List a folder

**Windows PowerShell**

```powershell
Get-ChildItem -Path C:\PATH -Force
```

## Find configuration files

**Windows PowerShell**

```powershell
Get-ChildItem -Path C:\PATH -Recurse -File -Include *.config,*.xml,*.ini -ErrorAction SilentlyContinue
```
