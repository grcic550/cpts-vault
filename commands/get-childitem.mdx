## Find configuration files in a specific application directory

**Run in:** Windows PowerShell. **Requires:** A real application directory and sufficient read/list permissions; retain access errors instead of assuming complete coverage.

```powershell
Get-ChildItem -Path 'C:\APP' -Recurse -File -Include *.config,*.xml,*.ini -Force
```

**What the result establishes:** Use path, recursion, file attributes and access errors to understand what the current identity can enumerate.

**Next check:** Check the chosen path and extension filter, then inspect relevant readable files and their ACLs without treating a recursive search as exhaustive.

## List a folder

**Windows PowerShell**

```powershell
Get-ChildItem -Path C:\PATH -Force
```

## Find configuration files

**Windows PowerShell**

```powershell
Get-ChildItem -Path C:\PATH -Recurse -File -Include *.config,*.xml,*.ini -ErrorAction SilentlyContinue
```

## If it fails

| Symptom | Check |
| --- | --- |
| Some directories are denied or no matching files appear | A directory listing can omit protected paths; recursive traversal and reparse points can broaden scope unexpectedly. |
