## Record Windows build and host configuration

**Run in:** Windows cmd.exe. **Requires:** A local Windows command session with access to system information.

```console
systeminfo
```

**What the result establishes:** Use OS/build, architecture, domain and update information to establish host context.

**Next check:** Verify edition, architecture, patch applicability and vulnerable component state before choosing any exploit; keep the exact output with the finding.

## Save the output

**Windows — cmd.exe**

```cmd
systeminfo > systeminfo.txt
```

Output may contain host and network details. Use it as evidence, not proof of exploitability.

## If it fails

| Symptom | Check |
| --- | --- |
| A build number or hotfix list seems to match an exploit | A version/build lead alone does not prove a CVE applies; edition, configuration, mitigation and patch state need confirmation. |

### The box & the users

**Windows Post-Exploitation: Field Reference**

