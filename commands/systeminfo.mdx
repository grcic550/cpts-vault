## systeminfo: choose the operation and read the result

Show Windows version, architecture, hotfixes and host details.

### What the result establishes

Use OS/build, architecture, domain and update information to establish host context.

### Prerequisites and common failures

A version/build lead alone does not prove a CVE applies; edition, configuration, mitigation and patch state need confirmation.

### Example 1: Host and OS details

Run in: **Windows — cmd.exe**.

```cmd
systeminfo
```

### Example 2: Save the output

Run in: **Windows — cmd.exe**. Output may contain host and network details. Use it as evidence, not proof of exploitability.

```cmd
systeminfo > systeminfo.txt
```

### The box & the users

**Windows Post-Exploitation: Field Reference**

```cmd
systeminfo                                   :: OS build/patch level (for kernel exploits)
hostname & ver
net user                                     :: local users
net user <name>                              :: groups + last logon of a user
net localgroup administrators                :: who is local admin
net localgroup "Remote Desktop Users"        :: who can RDP
net localgroup "Remote Management Users"     :: who can WinRM
query user                                   :: WHO IS LOGGED IN RIGHT NOW (jump-host gold)
```
