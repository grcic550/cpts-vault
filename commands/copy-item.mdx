## Commands

**Windows PowerShell**

```powershell
$Session = New-PSSession -ComputerName MS01
Copy-Item -Path C:\file.txt -ToSession $Session -Destination C:\Users\Public\file.txt
Copy-Item -Path C:\Users\Public\file.txt -FromSession $Session -Destination C:\file.txt
```

The remote session uses your current account unless you supply credentials.

### PowerShell Remoting (WinRM) Transfers

**File Transfers for Linux and Windows**

```powershell
# Test connectivity
Test-NetConnection -ComputerName DATABASE01 -Port 5985

# Create a session
$Session = New-PSSession -ComputerName DATABASE01

# Copy file TO remote machine
Copy-Item -Path C:\samplefile.txt -ToSession $Session -Destination C:\Users\Administrator\Desktop\

# Copy file FROM remote machine
Copy-Item -Path "C:\Users\Administrator\Desktop\DATABASE.txt" -Destination C:\ -FromSession $Session
```
