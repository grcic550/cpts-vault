## Current operation: Copy a file through an existing PowerShell session

**Run in:** Windows PowerShell. **Requires:** A permitted PowerShell remoting session, local source file and writable destination.

```powershell
$s = New-PSSession -ComputerName HOST_FQDN -Credential DOMAIN\USER
Copy-Item -Path .\file.bin -Destination 'C:\Users\Public\file.bin' -ToSession $s
Remove-PSSession $s
```

**Read the result:** Distinguish local filesystem copies, UNC access and copies through an explicit PowerShell session.

**If The session opens but the copy is denied:** A remote shell's token may not authenticate to a second share; use the intended session and check read/write permissions separately.

**Next check:** Check the remote token and destination path; compare Get-FileHash on both hosts before using the copied file.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
