### FinalRecon

**DNS and Web Reconnaissance: Full Workflow**

```bash
# Install
git clone https://github.com/thewhiteh4t/FinalRecon.git
cd FinalRecon
pip3 install -r requirements.txt
chmod +x ./finalrecon.py

# Header info + Whois
./finalrecon.py --headers --whois --url http://<target>

# Full recon
./finalrecon.py --full --url http://<target>

# Individual modules
./finalrecon.py --headers --url http://<target>   # Headers
./finalrecon.py --sslinfo --url http://<target>   # SSL cert info
./finalrecon.py --whois --url http://<target>     # Whois lookup
./finalrecon.py --crawl --url http://<target>     # Crawl site
./finalrecon.py --dns --url http://<target>       # DNS enumeration (40+ record types)
./finalrecon.py --sub --url http://<target>       # Subdomain enum (crt.sh, AnubisDB, etc.)
./finalrecon.py --dir --url http://<target>       # Directory brute force
./finalrecon.py --wayback --url http://<target>   # Wayback Machine URLs
./finalrecon.py --ps --url http://<target>        # Port scan
```
