## Decode a captured Base64 blob into a file

**Run in:** Kali with GNU coreutils. **Requires:** A Base64 text file with the intended alphabet and complete encoded data; output path must be writable.

```bash
base64 --decode input.b64 > output.bin
```

**What the result establishes:** Use encoding for transport through a text channel, then decode to a file and verify the result.

**Next check:** Check padding, wrapping and whether the source is URL-safe Base64; identify and hash the decoded file rather than executing it blindly.

## Commands

**Kali/Linux**

```bash
base64 -w 0 file.zip
# Decode pasted data into a file
printf '%s' 'BASE64_TEXT' | base64 -d > file.zip
```

## If it fails

| Symptom | Check |
| --- | --- |
| Decoding reports invalid input or output is not the expected format | Base64 is not encryption. Wrapping, clipboard truncation, newline handling and PowerShell text encoding can alter the bytes. |
