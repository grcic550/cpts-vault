## Get-ScheduledTask: choose the operation and read the result

Commands and examples collected from your Get-ScheduledTask notes.

### What the result establishes

Inspect task actions, triggers, principal and run level, then check access to the referenced executable/script.

### Prerequisites and common failures

A privileged task is only a lead; the current identity must control a relevant dependency or task setting for a writable-path hypothesis.

### Example 1: EoP - Processes Enumeration and Tasks

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```powershell
schtasks /query /fo LIST 2>nul | findstr TaskName
schtasks /query /fo LIST /v > schtasks.txt; cat schtask.txt | grep "SYSTEM\|Task To Run" | grep -B 1 SYSTEM
Get-ScheduledTask | where {$_.TaskPath -notlike "\Microsoft*"} | ft TaskName,TaskPath,State
```
