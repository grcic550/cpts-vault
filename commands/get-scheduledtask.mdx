## Current operation: Inspect a task's action, principal and trigger

**Run in:** Windows PowerShell. **Requires:** ScheduledTasks module and read access to the named task.

```powershell
Get-ScheduledTask -TaskPath '\' -TaskName 'TASK_NAME' | Format-List TaskName,TaskPath,Actions,Principal,Triggers
```

**Read the result:** Inspect task actions, triggers, principal and run level, then check access to the referenced executable/script.

**If The task exists but its last execution failed:** A privileged task is only a lead; the current identity must control a relevant dependency or task setting for a writable-path hypothesis.

**Next check:** Use Get-ScheduledTaskInfo for its last result, then inspect action paths, credentials and trigger conditions before relying on it.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
