## Collect Windows privilege-escalation leads

**Run in:** Windows PowerShell. **Requires:** A matching executable architecture, the intended collection build and a Windows token whose accessible configuration you want to inspect.

```powershell
.\winPEASx64.exe
```

**What the result establishes:** Use its highlighted findings to select manual checks of the exact file, service, privilege or configuration.

**Next check:** Verify one finding manually: object, writable permission, privileged consumer and trigger. Preserve collection errors and token context.

## If it fails

| Symptom | Check |
| --- | --- |
| Highlighted findings do not produce a usable escalation path | Color/highlighted output is a lead, not proof of exploitation; verify permissions and execution triggers under your current token. |
