## List services

**Windows — cmd.exe or PowerShell**

```cmd
sc.exe query state= all
```

Keep the space after state=.

## Inspect service configuration

**Windows — cmd.exe or PowerShell**

```cmd
sc.exe qc SERVICE_NAME
```

BINARY_PATH_NAME is the command line; SERVICE_START_NAME is the service account.

## Read service permissions

**Windows — cmd.exe or PowerShell**

```cmd
sc.exe sdshow SERVICE_NAME
```

Displays SDDL for the service object; the binary file has separate permissions.

## If it fails

| Symptom | Check |
| --- | --- |
| sc behaves like a file-writing command in PowerShell | Use sc.exe explicitly. In Windows PowerShell, sc can resolve to the Set-Content alias. |
