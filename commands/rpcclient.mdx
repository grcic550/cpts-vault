### Connecting

**rpcclient: Users, Groups, and Domain Policy**

<Accordion title="Typical null-session workflow">

### Typical null-session workflow

**rpcclient: Users, Groups, and Domain Policy**

```bash
rpcclient -U "" -N <target>
# then, at the prompt:
querydominfo          # orient: what domain/role is this?
enumdomusers          # grab the username list
getdompwinfo          # check lockout BEFORE any spraying
enumdomgroups         # find privileged groups
querygroupmem 0x200   # 0x200 = 512 = Domain Admins → who's an admin?
netshareenumall       # where are the shares?
```

**rpcclient: Users, Groups, and Domain Policy**

```bash
rpcclient -U "" -N <target> -c "enumdomusers"
rpcclient -U 'user%pass' <target> -c "querygroupmem 0x200"
```

</Accordion>
