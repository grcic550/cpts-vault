## Current operation: Query domain information over authenticated RPC

**Run in:** Kali. **Requires:** RPC over SMB reachability and an account allowed to query the requested information; password prompted.

```bash
rpcclient -U 'DOMAIN/USER' TARGET_IP -c 'querydominfo; enumdomusers'
```

**Read the result:** Use server, domain, user and group responses to build an identity map; retain RIDs/SIDs with their domain context.

**If One RPC query succeeds while another is denied:** Null sessions and authenticated RPC have different permissions; a denied enumeration call does not invalidate every RPC capability.

**Next check:** Record which interface and query worked, then use directory enumeration for missing object properties.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
