## Query domain information over authenticated RPC

**Run in:** Kali. **Requires:** RPC over SMB reachability and an account allowed to query the requested information; password prompted.

```bash
rpcclient -U 'DOMAIN/USER' TARGET_IP -c 'querydominfo; enumdomusers'
```

**What the result establishes:** Use server, domain, user and group responses to build an identity map; retain RIDs/SIDs with their domain context.

**Next check:** Record which interface and query worked, then use directory enumeration for missing object properties.

## Commands

**Kali / rpcclient prompt**

```bash
rpcclient -U 'DOMAIN/USER' TARGET_IP
# Inside rpcclient
enumdomusers
enumdomgroups
querydominfo
```

## If it fails

| Symptom | Check |
| --- | --- |
| One RPC query succeeds while another is denied | Null sessions and authenticated RPC have different permissions; a denied enumeration call does not invalidate every RPC capability. |
