## Inspect browser credentials available in the current context

**Run in:** Windows PowerShell. **Requires:** The intended LaZagne build and access to the relevant browser profiles and decryption context.

```powershell
.\LaZagne.exe browsers
```

**What the result establishes:** Read each application's result and the identity under which it was collected.

**Next check:** Check user context and profile/protection changes; a path match alone does not prove usable credentials.

## All supported applications

**Windows PowerShell**

```powershell
.\LaZagne.exe all
```

## If it fails

| Symptom | Check |
| --- | --- |
| A profile is found but its secrets cannot be decrypted | A stored credential may be encrypted for a different user or require a logged-on context; absent output does not prove no applications store secrets. |
