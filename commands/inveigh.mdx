## Inspect capture events from a Windows lab position

**Run in:** Windows PowerShell. **Requires:** The intended Inveigh implementation, lab network position and permitted listener/poisoning scope; default modes vary by build.

```powershell
.\Inveigh.exe
```

**What the result establishes:** Distinguish name-resolution events, authentication exchanges and usable captured artifacts in the logs.

**Next check:** Check binding and the actual client traffic; interpret captured challenge/response material separately from a successful login.

## If it fails

| Symptom | Check |
| --- | --- |
| Listeners start but no usable authentication artifact appears | Listener binding, network position and client behavior determine visibility; a capture is not a plaintext password or automatic admin session. |
