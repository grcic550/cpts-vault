## Current operation: Read a computer's allowed-to-act descriptor

**Run in:** Kali. **Requires:** A directory identity that can read the target computer; the password is prompted. This example does not write the descriptor.

```bash
impacket-rbcd -delegate-to 'TARGET$' -action read -dc-ip DC_IP 'DOMAIN_FQDN/USER'
```

**Read the result:** Read the target computer's allowed-to-act descriptor and resolve the principals it authorizes.

**If The descriptor is empty or a listed principal is not controlled:** Writing the attribute requires an applicable object right, and the controlled principal must meet the delegation flow's prerequisites.

**Next check:** Resolve each SID and verify the controlled identity's prerequisites before considering any delegated service request.
