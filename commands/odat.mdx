## Test Oracle service identifiers

**Run in:** Kali. **Requires:** Installed ODAT and an in-scope Oracle listener; guesses generate connection attempts.

```bash
odat sidguesser -s TARGET_IP
```

**What the result establishes:** Tie each module result to the identified Oracle service, supplied account and database privilege.

**Next check:** Compare discovered identifiers with listener information, then test an explicitly known account against the matching service.

## If it fails

| Symptom | Check |
