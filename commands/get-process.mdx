## Inspect one process's identity fields and image path

**Run in:** Windows PowerShell. **Requires:** A process name without .exe and rights to read its details.

```powershell
Get-Process -Name 'PROCESS_NAME' | Select-Object Id,ProcessName,Path,StartTime
```

**What the result establishes:** Associate processes with executable paths, owners and privileges when those properties are readable.

**Next check:** Treat missing fields as an access limitation; correlate the PID with service configuration and available process-owner information.

## Create the memory dump

**Notebook example**

```powershell
Get-Process lsass                       # PowerShell: PID is the Id field
rundll32 C:\windows\system32\comsvcs.dll, MiniDump <PID> C:\lsass.dmp full
```

## If it fails

| Symptom | Check |
| --- | --- |
| Path or start time is unavailable for a protected process | Process names alone are weak evidence, and access-denied properties reflect the current token rather than absence of the process. |
