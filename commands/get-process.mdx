## Current operation: Inspect one process's identity fields and image path

**Run in:** Windows PowerShell. **Requires:** A process name without .exe and rights to read its details.

```powershell
Get-Process -Name 'PROCESS_NAME' | Select-Object Id,ProcessName,Path,StartTime
```

**Read the result:** Associate processes with executable paths, owners and privileges when those properties are readable.

**If Path or start time is unavailable for a protected process:** Process names alone are weak evidence, and access-denied properties reflect the current token rather than absence of the process.

**Next check:** Treat missing fields as an access limitation; correlate the PID with service configuration and available process-owner information.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
