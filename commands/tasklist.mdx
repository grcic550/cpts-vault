## Current operation: Map running processes to hosted services

**Run in:** Windows cmd.exe. **Requires:** Windows process enumeration access; protected processes may expose limited information.

```console
tasklist /svc
```

**Read the result:** Associate a process with its PID, user/session and relevant service before drawing privilege conclusions.

**If A process name is recognized but its service or owner is unclear:** Process visibility is permission-dependent, and a running process name does not reveal writable files or a usable execution path.

**Next check:** Use service configuration and process details to resolve the executable and account, then inspect relevant file permissions.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.

## tasklist: choose the operation and read the result

List Windows processes and identify services hosted by a process.

### Prerequisites and common failures

### Example 1: Processes with details

Run in: **Windows — cmd.exe**.

```cmd
tasklist /v
```

### Example 2: Services per process

Run in: **Windows — cmd.exe**. Match the PID with netstat output.

```cmd
tasklist /svc
```

### Example 3: Inspect one PID

Run in: **Windows — cmd.exe**. Replace PID_NUMBER with the numeric PID.

```cmd
tasklist /fi "PID eq PID_NUMBER"
```
