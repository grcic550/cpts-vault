## Map running processes to hosted services

**Run in:** Windows cmd.exe. **Requires:** Windows process enumeration access; protected processes may expose limited information.

```console
tasklist /svc
```

**What the result establishes:** Associate a process with its PID, user/session and relevant service before drawing privilege conclusions.

**Next check:** Use service configuration and process details to resolve the executable and account, then inspect relevant file permissions.

## Processes with details

**Windows — cmd.exe**

```cmd
tasklist /v
```

## Inspect one PID

**Windows — cmd.exe**

```cmd
tasklist /fi "PID eq PID_NUMBER"
```

Replace PID_NUMBER with the numeric PID.

## If it fails

| Symptom | Check |
| --- | --- |
| A process name is recognized but its service or owner is unclear | Process visibility is permission-dependent, and a running process name does not reveal writable files or a usable execution path. |
