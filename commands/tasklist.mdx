## Processes with details

**Windows — cmd.exe**

```cmd
tasklist /v
```

## Services per process

**Windows — cmd.exe**

```cmd
tasklist /svc
```

Match the PID with netstat output.

## Inspect one PID

**Windows — cmd.exe**

```cmd
tasklist /fi "PID eq PID_NUMBER"
```

Replace PID_NUMBER with the numeric PID.
