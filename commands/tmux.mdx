### Start / attach / detach

**Kali Terminal, tmux, zsh, and Vim**

```bash
tmux                      # start a new session
tmux new -s recon         # new named session "recon"
tmux ls                   # list sessions
tmux attach -t recon      # re-attach to "recon"
tmux kill-session -t recon
```

</Accordion>
