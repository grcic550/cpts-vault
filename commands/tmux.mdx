## Current operation: Keep a lab terminal session available across disconnects

**Run in:** Kali. **Requires:** An interactive terminal and a unique session name.

```bash
tmux new-session -s lab
```

**Read the result:** Keep listeners, notes and remote sessions in named windows/panes so terminal loss does not discard the workflow.

**If The terminal disconnects and the session seems lost:** The tmux prefix is a key chord, not shell text; server-side sessions and the lifetime of processes inside them are separate.

**Next check:** List sessions with tmux ls and reattach with tmux attach -t lab; detach deliberately using Ctrl-b then d.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
