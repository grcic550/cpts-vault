## Keep a lab terminal session available across disconnects

**Run in:** Kali. **Requires:** An interactive terminal and a unique session name.

```bash
tmux new-session -s lab
```

**What the result establishes:** Keep listeners, notes and remote sessions in named windows/panes so terminal loss does not discard the workflow.

**Next check:** List sessions with tmux ls and reattach with tmux attach -t lab; detach deliberately using Ctrl-b then d.

## Commands

**Kali**

```bash
tmux new -s lab
tmux ls
tmux attach -t lab
# Detach: Ctrl-b, then d
```

## If it fails

| Symptom | Check |
| --- | --- |
| The terminal disconnects and the session seems lost | The tmux prefix is a key chord, not shell text; server-side sessions and the lifetime of processes inside them are separate. |

### Start / attach / detach

**Kali Terminal, tmux, zsh, and Vim**

```bash
tmux                      # start a new session
tmux new -s recon         # new named session "recon"
tmux ls                   # list sessions
tmux attach -t recon      # re-attach to "recon"
tmux kill-session -t recon
```
