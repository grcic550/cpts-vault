## Observe recurring process executions without root

**Run in:** Linux target. **Requires:** An architecture-compatible pspy build and executable permissions; this observes what the current environment exposes.

```bash
./pspy64 -pf -i 1000
```

**What the result establishes:** Associate observed command lines with users, timing and the files they reference.

**Next check:** Observe across the job's schedule and correlate commands with file ownership and cron/systemd configuration; process observation alone does not grant write access.

## Cron jobs

**Notebook example**

```powershell
# print both commands and file system events and scan procfs every 1000 ms (=1sec)
```
