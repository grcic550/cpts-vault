## Inspect a named rsync module before transfer

**Run in:** Kali. **Requires:** An rsync daemon endpoint and, for the second command, an observed module name.

```bash
rsync rsync://TARGET_IP/
rsync --list-only rsync://TARGET_IP/MODULE/
```

**What the result establishes:** List the available module and readable paths, then choose a specific source and destination for a controlled transfer.

**Next check:** Check module authentication and path permissions; copy selected files only after understanding what the listing exposes.

## Commands

**Kali**

```bash
rsync rsync://TARGET_IP/
rsync -av --list-only rsync://TARGET_IP/MODULE
rsync -av rsync://TARGET_IP/MODULE ./received/
```

## If it fails

| Symptom | Check |
| --- | --- |
| A module is advertised but listing is denied | Trailing slashes change copy layout, and --delete can remove destination files; a module listing is not write permission. |
