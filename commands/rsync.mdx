## rsync: choose the operation and read the result

List modules or copy files through rsync.

### What the result establishes

List the available module and readable paths, then choose a specific source and destination for a controlled transfer.

### Prerequisites and common failures

Trailing slashes change copy layout, and --delete can remove destination files; a module listing is not write permission.

### Example 1: Commands

Run in: **Kali**.

```bash
rsync rsync://TARGET_IP/
rsync -av --list-only rsync://TARGET_IP/MODULE
rsync -av rsync://TARGET_IP/MODULE ./received/
```

### Example 2: Rsync

Run in: **Saved lab example**.

```bash
sudo nmap -sV -p 873 <IP>
nc -nv <IP> 873          # then send: @RSYNCD: 31.0  /  #list   to enumerate modules

rsync -av --list-only rsync://<IP>/<share>     # list a share's contents
rsync -av rsync://<IP>/<share> ./loot/          # download everything
rsync -av -e "ssh -p2222" rsync://<IP>/<share> ./loot/   # over SSH, custom port
```
