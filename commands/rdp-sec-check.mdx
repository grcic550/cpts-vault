### Prerequisites and common failures

### Security check & connecting

**Windows Remote Access: RDP, WinRM, and WMI**

```bash
# Check encryption / NLA posture
git clone https://github.com/CiscoCXSecurity/rdp-sec-check.git && cd rdp-sec-check
./rdp-sec-check.pl <IP>      # look for PROTOCOL_RDP:TRUE (weak) vs PROTOCOL_HYBRID:TRUE (NLA)

# Connect (Linux)
xfreerdp /u:<user> /p:"<pass>" /v:<IP> /cert:ignore
xfreerdp /u:<user> /p:"<pass>" /v:<IP> /dynamic-resolution
rdesktop -u <user> -p <pass> <IP>
```
