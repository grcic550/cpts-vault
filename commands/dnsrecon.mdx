## The headline attack: DNS Zone Transfer (AXFR)

**Notebook example**

```bash
dig axfr <domain> @<nameserver-IP>            # request a full zone transfer
dig axfr internal.target.com @10.10.10.5      # internal zones are the real jackpot

# Alternatives
host -l <domain> <nameserver-IP>              # -l = list zone (attempt AXFR)
fierce --domain <domain>                       # tries AXFR, then falls back to brute force
dnsrecon -d <domain> -t axfr                   # zone transfer attempt
```

### When AXFR is blocked: enumerate the hard way

**DNS Enumeration and Zone Transfers**

```bash
# Individual record lookups
dig A target.com @<IP>            # host → IPv4
dig MX target.com @<IP>           # mail servers
dig NS target.com @<IP>           # name servers
dig TXT target.com @<IP>          # SPF/DKIM/verification strings
dig ANY target.com @<IP>          # everything the server will return at once

# Reverse lookups across a subnet (PTR records → hostnames)
dnsrecon -r 10.10.10.0/24 -n <IP>

# Subdomain brute force (guess names, keep the ones that resolve)
dnsenum --dnsserver <IP> -f /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt <domain>
gobuster dns -d <domain> -r <IP> -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt
```
