## Current operation: Identify the Linux route to a destination

**Run in:** Linux shell. **Requires:** A shell on the actual source host and the destination address.

```bash
ip -br address
ip route get TARGET_IP
```

**Read the result:** Read addresses, prefixes and the selected route together; use route get to identify the actual egress decision.

**If The selected interface or source address is unexpected:** Multiple interfaces and overlapping VPN/internal subnets can select an unexpected route even when the destination address looks correct.

**Next check:** Compare VPN and internal prefixes; test the service from the chosen interface before introducing a tunnel.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
