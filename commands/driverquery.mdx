## Inventory drivers with the built-in Windows utility

**Run in:** Windows cmd.exe. **Requires:** Windows driverquery.exe; this is not the separate third-party DriverQuery tool that accepts --no-msft.

```console
driverquery /v /fo csv
```

**What the result establishes:** Use driver names, paths and versions as leads for checking installed components.

**Next check:** Use switches for the actual executable; verify a candidate driver's path, version, signature and loaded state before assessing an escalation lead.
