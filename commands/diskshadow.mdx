## diskshadow: choose the operation and read the result

Commands and examples collected from your diskshadow notes.

### What the result establishes

Understand the volume, snapshot context and exposed path before interpreting a shadow-copy result.

### Prerequisites and common failures

Creating or exposing snapshots requires the relevant privileges and service support; a snapshot is not automatically a readable credential artifact.

### EoP - Abusing Shadow Copies

**Windows Privilege Escalation: Full Checklist**

```powershell
# List shadow copies using vssadmin (Needs Admnistrator Access)
vssadmin list shadows
  
# List shadow copies using diskshadow
diskshadow list shadows all
  
# Make a symlink to the shadow copy and access it
mklink /d c:\shadowcopy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\
```
