<Accordion title="Enumeration Workflow">

### Enumeration Workflow

**Windows Remote Access: RDP, WinRM, and WMI**

```text
1. Port scan → 3389, 5985, 5986, 135
2. RDP open?   → nmap rdp* (hostname/domain/NLA) → rdp-sec-check.pl (encryption)
3. WinRM open? → evil-winrm with found creds (or -H hash)
4. WMI (135)?  → wmiexec.py with creds → stealthy command exec
5. Got creds?  → try ALL three + test password reuse across hosts
```

<Accordion title="WMI (Windows Management Instrumentation)">

### WMI (Windows Management Instrumentation)

**Windows Remote Access: RDP, WinRM, and WMI**

Context from the notebook: WMI is Windows' built-in management framework — it can answer almost any question about a system (OS, processes, installed software, services) and  create processes remotely . Attackers love it because execution via WMI is  fileless and stealthy  (no service installed, blends into normal admin activity), which is why  wmiexec.py  is a favourite.
