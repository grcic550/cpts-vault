## Current operation: Inspect the local neighbor cache

**Run in:** Linux or Windows shell. **Requires:** A host shell on the relevant network segment; the cache reflects recent local observations.

```bash
arp -a
```

**Read the result:** Associate neighbor entries with the local link and interface, checking whether the entry is dynamic or stale.

**If The remote subnet's host is absent:** ARP only describes local-layer adjacency for IPv4; it is not a discovery method for arbitrary routed subnets.

**Next check:** Check routing and the gateway rather than expecting every routed destination to have its own local ARP entry.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
