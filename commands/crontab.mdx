## Current operation: Read the current user's scheduled commands

**Run in:** Linux target. **Requires:** A host with cron/crontab and access to the current user's crontab.

```bash

```

**Read the result:** Distinguish the current user's crontab from system schedules and other users' jobs.

**If No user crontab exists but recurring privileged work is visible:** A visible privileged job is a lead only if an executable, input or dependency is controllable and the job actually runs.

**Next check:** Inspect /etc/crontab, relevant /etc/cron.d files and systemd timers separately, then verify the executing identity and referenced file permissions.
