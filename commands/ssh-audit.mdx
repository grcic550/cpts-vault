## Inspect an SSH server's offered algorithms

**Run in:** Kali. **Requires:** The installed ssh-audit executable and an SSH endpoint; confirm its invocation name on this installation.

```bash
ssh-audit TARGET_IP
```

**What the result establishes:** Use identified algorithms and implementation details to prioritize configuration review.

**Next check:** Record offered algorithms and versions; validate applicability separately before selecting authentication or vulnerability checks.
