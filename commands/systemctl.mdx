## Current operation: Read a systemd service's effective unit configuration

**Run in:** Linux target. **Requires:** A systemd host, a valid unit name and access to its unit configuration.

```bash
systemctl status SERVICE_NAME.service --no-pager
systemctl cat SERVICE_NAME.service
```

**Read the result:** Read unit definitions, drop-ins, execution identity and current state before investigating service permissions.

**If The service is visible but restart or modification is denied:** Permission to view or restart a unit differs from permission to modify its executable, configuration or environment.

**Next check:** Read the service user, ExecStart and drop-ins, then inspect file permissions and any restart authority separately.

**Scope of these examples:** The operations above provide the current starting checks. The complete earlier guide, variants and lab transcripts remain below; they retain their original assumptions.
