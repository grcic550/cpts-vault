## Test a compatible impersonation path with one command

**Run in:** Windows PowerShell. **Requires:** The matching .NET build, required impersonation capability and an OS/configuration supported by this implementation.

```powershell
.\GodPotato-NET4.exe -cmd "cmd /c whoami"
```

**What the result establishes:** Match the implementation's prerequisites to the current Windows build and token, then verify the returned identity.

**Next check:** Compare the actual token, runtime and reported COM/RPC error with this build's prerequisites; verify the resulting identity instead of assuming success.
