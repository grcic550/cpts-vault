## List user distinguished names in the domain

**Run in:** Windows cmd.exe. **Requires:** AD command-line tools and a domain context that can query users.

```console
dsquery user -limit 0
```

**What the result establishes:** Choose the directory object type and scope, then preserve distinguished names for later exact-object checks.

**Next check:** Use an available directory client and retain the exact DNs for subsequent object-specific queries.

## Commands

**Windows cmd.exe**

```bash
dsquery user
dsquery computer
```
