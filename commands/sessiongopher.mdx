## Inspect saved connection profiles available locally

**Run in:** Windows PowerShell. **Requires:** The intended module and permissions for the local user profiles/registry hives it inspects.

```powershell
Import-Module .\SessionGopher.ps1
Invoke-SessionGopher
```

**What the result establishes:** Associate discovered remote-session configuration with the owning user profile and application.

**Next check:** Treat the result as a connection lead; verify credential availability and the intended service separately.
