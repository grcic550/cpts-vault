## Current operation: Query SAMR account information

**Run in:** Kali. **Requires:** SMB/SAMR reachability and an identity allowed to enumerate; password is prompted.

```bash
impacket-samrdump 'DOMAIN/USER@TARGET_IP'
```

**Read the result:** Associate enumerated users and RIDs with the target domain or local account database.

**If Authentication works but SAMR enumeration is denied:** RPC enumeration permissions vary; a denied query does not prove that SMB is unreachable or that the supplied identity is invalid.

**Next check:** Record the restriction and use permitted LDAP or native domain queries instead of interpreting denial as no accounts.
