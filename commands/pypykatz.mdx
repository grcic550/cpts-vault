**Requires:** An LSASS minidump already obtained from your lab host; this command does not collect one.

## Read a saved dump

**Kali**

```bash
pypykatz lsa minidump LSASS_DUMP
```

Replace LSASS_DUMP with the local dump file path. Missing secrets can reflect the source host protections or logon type.
