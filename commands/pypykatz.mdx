## Parse a lab LSASS minidump offline

**Run in:** Kali. **Requires:** A readable complete minidump already acquired in the lab and parser support for its Windows structures.

```bash
pypykatz lsa minidump lsass.dmp
```

**What the result establishes:** Identify the dump/hive source and recovered credential type, then keep artifacts associated with their original host.

**Next check:** Check dump integrity and version support; distinguish unavailable material from invalid credentials and retain the associated logon identity with each result.

## Read a saved dump

**Kali**

```bash
pypykatz lsa minidump LSASS_DUMP
```

Replace LSASS_DUMP with the local dump file path. Missing secrets can reflect the source host protections or logon type.

## If it fails

| Symptom | Check |
| --- | --- |
| Parsing produces missing packages or no plaintext values | An LSASS parser needs an appropriate captured artifact; protected-process behavior, architecture and dump completeness affect parsing. |
