## Find local references for an identified product and version

**Run in:** Kali. **Requires:** A locally available Exploit-DB index and a product/version fingerprint with supporting evidence.

```bash
searchsploit 'PRODUCT_NAME' 'VERSION'
```

**What the result establishes:** Use results to locate candidate exploit descriptions and inspect their exact product/version/prerequisites.

**Next check:** Read the exploit and original advisory, compare affected version/configuration and choose a bounded verification before running any code.

## Finding & using public exploits

**Notebook example**

```bash
searchsploit <product> <version>        # offline Exploit-DB
searchsploit -m <id>                     # copy an exploit locally to edit
# also: exploit-db.com, GitHub, the CVE write-up itself
```
