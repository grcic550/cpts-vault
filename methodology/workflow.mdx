A concrete order of operations for a single host.

```bash
# 1) Full port sweep, then targeted service scan
nmap -p- --min-rate 5000 -T4 $IP -oA nmap/all
nmap -sVC -p <open-ports> $IP -oA nmap/svc
# 2) Web ports: enumerate content + vhosts (add hostnames to /etc/hosts)
# 3) Every service: check anonymous/default access first
```

## Checklist1. **Recon** — Full TCP + UDP top ports, service versions, add hostnames to `/etc/hosts`.
2. **Enumerate each service** — Anonymous access, default creds, known-version CVEs (`searchsploit`).
3. **Foothold** — Lowest-effort path first — creds reuse, misconfig, then exploit.
4. **Local enum** — Run `linpeas`/`winpeas`; check sudo, SUID, services, cron, creds in files.
5. **Privesc** — Verify by hand; grab `root.txt`/`proof.txt` + screenshot.
6. **Post / pivot** — Dump creds, check for new subnets/hosts, repeat.



> Don't tunnel-vision on the first shiny port. Finish enumerating **all** services before committing to an exploit path.
